## 当前结论

EPW 仅构建 `epw_phonon`、`epw_wannier`、`epw_superconductivity` 三个独立程序，旧 `epwflow` 可执行入口已移除。三个程序共用配置、固定快照、预算与状态。默认生成本阶段 Slurm 脚本，不启动科学程序或预留预算；`-s` 提交，`-r` 需要已登记分配，`--resume -w` 使用固定快照恢复。源码、构建和默认安装分别核对，本次未覆盖默认安装。

epw_phonon 直接调用 qeflow 的 nosplit Rust 库（[说明](../qeflow/qe_phonon_nosplit.md)），执行 SCF→PH→q2r→matdyn 和声子图，启用 EPW 原始数据归档。SCF 完成、PH 之前保存独立快照，再由 EPW 准备完整均匀 NSCF 和严格数据清单。固定 KPATH、q2r／matdyn、显式原子质量及 SCF 网格位移均传递并校验；后处理失败恢复会重验请求、脚本和 SCF 检查点，复用已完成 SCF／PH。该恢复行为已由独立进程回归验证；新的真实链已有 SCF／PH／q2r 完成证据，第一阶段整体仍未验收。

粗／细原生尝试在 native-attempts 保存固定请求、物化输入和成功输出指纹。显式恢复可重验归集完整输出，或将失败现场归档后按原参数重试；成功展宽不重复执行。质量失败仍阻断，来源或证据变化拒绝恢复。阶段清单已发布但工作流完成状态未登记时，可重验后补登记。恢复回归使用独立进程测试替身，不替代真实科学验收。

粗网格阶段独立发布 `wannier/manifest.json`，没有细网格或谱；细网格在第三阶段重验前者后另行发布 `interpolation/manifest.json`，绑定原粗清单哈希，保持其不变。进程回归证明阶段顺序、原生格式角色和失败阻断；缺省独立参考已自动生成；四类比较图的自动生成已接入；真实 PBE 全链与两模式 Tc 交付尚未完成。首条主路径采用 nosplit，不要求三来源六组合完成才交付。

最终交付在工作流结果根目录先收集、再出图；结果清单已存在而图表未完成时，显式恢复仍交由 F5 接续，不重新执行已验证的科学阶段。该根目录的原生结果／比较结果／两类图像锁复用现有 owner 与 Slurm 终态校验，不能清除未知锁。原生图与比较图共用同源格式保留逻辑；SVG 重绘保留已登记的 PNG／PDF，原生来源改变须重绘全部已有格式或新目录，比较来源改变须新目录。已由文件级与公开进程故障检查验证。

F4 已发布合法 partial 清单时，公开显式恢复会重验固定来源、配置、模式、搜索记录和产物，再交回现有 Engine；成功模式不重算，原失败目录与次数保留，新尝试追加。缺失搜索文件、变化来源或损坏证据拒绝，合法零尝试模式从当前 F3 核验绑定，不由检查补建状态。该行为与后续仅恢复最终交付已由同一公开进程链验证；不代表真实 PBE／完整 Tc 验收。当前边界见 [0008 连续验证](../../specs/0008-epwflow-foundation/public-chain-validation.md)。

生成脚本和内部提交脚本共用环境加载段，兼容 oneAPI 对可选变量的读取：仅加载期间关闭 nounset，成功后恢复，加载失败继续阻断。该行为已由实际生成脚本与本机真实环境加载验证；不代表 QE／EPW 科学阶段已完成。

启动使用 scontrol 严格核对唯一作业身份、RUNNING 和固定节点数；RUNNING 零节点仅有限等待。终态计费仍仅使用 sacct，不从控制器启动结果推算用量，账表未知时保留预留。身份／资源冲突拒绝、账表滞后与完整公开续算链已通过隔离回归。真实 PBE nosplit 第一阶段已完成 SCF／PH／q2r、两类 matdyn、共享声子图、save 和完整 32 k／16 带 NSCF；公开严格清单检查 valid，14 份已有科学文件复用不变。第二阶段、细网格与完整 Tc 仍须各自验收。

## 显式纯能量选窗

## 第二阶段自动比较

公开第二阶段使用已冻结 KPATH 展开同路径点，DOS 采用 F2 的完整均匀 NSCF 网格。程序从 SCF 副本生成路径电子参考，在原始 PH 副本上施加同源 Γ onsite 与 QE Hermitian 平均后运行 q2r／matdyn，再隔离重读原 EPW 粗网格；不重做 SCF／已有 PH，不提前执行细网格 EPC。实际原子顺序用于校验 3N，缺投影继续明确标记。

来源与原生尝试保存在 `comparison-native/`；比较表位于 `interpolation/comparison/`，自包含数据和五类三格式图位于 `results/`。粗阶段清单绑定这些交付，质量失败仍可生成诊断图，但不发布粗阶段成功标记。可选 `[comparison]` 固定每边区间数和两种高斯核宽，缺省为 20、0.1 eV 和 10 cm⁻¹，见[模块手册](../../../epwflow/README.md)。
