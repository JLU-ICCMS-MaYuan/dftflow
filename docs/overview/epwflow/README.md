# epwflow 当前入口与验证边界

当前科学门已按最新指令改为最大 50／RMS 20 cm⁻¹；原五点实测 49.448071／8.075133，已由新代码只读复核通过。后文旧门失败段落保留历史语境，不能作为当前下游门限。原生代码收尾与尚缺的真实 Tc 证据见[原生超导适配](native-superconductivity.md)。最新真实阶段已完成 LDA 40³/20³ EPC，λ_integral=0.6853853、λ_sum=0.6853511；iso 原生线性化 Tc 区间为 36.71～37.06 K，两模式非线性能隙与完整 Tc 验收仍未通过。下文早期未运行细网格的记录保留历史语境，当前事实以本段及原生超导适配页为准。

## 当前结论

EPW 仅构建 `epw_phonon`、`epw_wannier`、`epw_superconductivity` 三个独立程序，旧 `epwflow` 可执行入口已移除。三个程序共用配置、固定快照、预算与状态。默认生成本阶段 Slurm 脚本，不启动科学程序或预留预算；`-s` 提交，`-r` 需要已登记分配，`--resume -w` 使用固定快照恢复。源码、构建和默认安装分别核对，本次未覆盖默认安装。

epw_phonon 直接调用 qeflow 的 nosplit Rust 库（[说明](../qeflow/qe_phonon_nosplit.md)），执行 SCF→PH→q2r→matdyn 和声子图，启用 EPW 原始数据归档。SCF 完成、PH 之前保存独立快照，再由 EPW 准备完整均匀 NSCF 和严格数据清单。固定 KPATH、q2r／matdyn、显式原子质量及 SCF 网格位移均传递并校验；后处理失败恢复会重验请求、脚本和 SCF 检查点，复用已完成 SCF／PH。该恢复行为已由独立进程回归验证，尚未执行新的真实科学链。

粗网格阶段独立发布 `wannier/manifest.json`，没有细网格或谱；细网格在第三阶段重验前者后另行发布 `interpolation/manifest.json`，绑定原粗清单哈希，保持其不变。进程回归证明阶段顺序、原生格式角色和失败阻断；独立参考与四类比较图的自动生成、真实两模式 Tc 交付尚未完成。首条主路径采用 nosplit，不要求三来源六组合完成才交付。

## 高对称路径横轴

电子能带与声子色散的高对称点符号位于底部横轴下方，按实际路径位置居中；不显示路径距离的数值刻度、k path／q path 标题或图内顶部的重复标签。G 显示为 Γ，其他符号沿用元数据。独立图和 2×2 总览共用该规则，电子／声子 DOS 保留能量／频率数值刻度。绘图只改变展示，不改写路径与科学结果表。

## 能带与电子 DOS 的实际窗口边界

比较来源中的 `wannier_wout` 同时读取实际 Outer／Inner，以绝对 eV 保存 `disentanglement_window_ev`、`frozen_window_ev`；冻结窗必须有限、递增且包含于外窗。旧比较包没有冻结窗时仍可重绘，并明确未记录，不从显示窗猜测边界。

`plot` 在电子能带画水平虚线、电子 DOS 画竖直虚线，独立图和总览一致：蓝色为 `dis_win_min`，青色为 `dis_win_max`，橙色为 `dis_froz_min`，紫红色为 `dis_froz_max`。图例给出变量名和相对共同 E_F 的能量，图题保留绝对值。重合边界用交错颜色保留同一真实位置；高对称路径符号仍在底部轴下。

真实 MgB₂ 的两个下边界均为 −4.90710 eV，冻结窗上界为 8.80000 eV，外窗上界为 32.23753 eV；共同 E_F=7.497269413025949 eV。本次只标注实际计算窗口，不修改物理输入。带冻结窗元数据的新包通过原有 `collect`／`plot` 命令绘制；旧包若需补全边界，应在独立目录使用带指纹的原始 `.wout` 重新 `interpolation export-comparison`，不能手改旧清单。

源码与数据校验见 `interpolation/comparison.rs`、`comparison_data.rs`，绘图见 `delivery/comparison_plot.rs`；7 项比较回归及真实三格式核验见 [0014 验收记录](../../specs/0014-epwflow-delivery/acceptance.md)。投影暂缓、宽窗缺态及科学质量失败状态保留。


## 默认组合选窗

新生成路径与 wannierflow 共用 `qf-wannier`，采用固定 AiiDA 工作流的默认能量冻结＋投影解纠缠。F2 绑定传递实际 NSCF 本征值和共同 E_F；默认冻结上界由运行时平移值＋2 eV 出发，再按排除后的第 N／N+1 带限制，默认投影阈值为 0.01／0.95。未设置的其他边界保留原生默认；显式能量覆盖仍经过同一上限处理。

独立 `.win` 与 EPW 的 `wdata` 都写投影阈值及标准 W90 所需的 `dis_froz_proj=true`；实际投影由原生程序读取。执行路径保存 `window-selection.json`，缺本征值或无法核验实际独立／内嵌 W90 必要参数支持时拒绝，不沿用旧固定窗或带号启发式。关键字检查是保守必要条件，不等于原生组合方法已经运行成功。

本机现有 W90／EPW 尚未核验到这三项参数支持，未升级程序或执行新窗口科学计算；现有历史结果和窗口日志不改写。源码接入、上游数值差分与新窗口科学质量分别报告，声子 RMS 失败及下游质量门不变。使用和证据见 [0016 使用说明](../../specs/0016-wannier-window-selection/quickstart.md) 与 [验收](../../specs/0016-wannier-window-selection/acceptance.md)。
