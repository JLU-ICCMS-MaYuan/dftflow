# NSCF 网格与 FFT 接续

当前工作树的 NSCF 配置为 `stages."2.qe-nscf".pw.K_POINTS = [A, B, C]`，只接受三个正整数。SCF 原卡片形式保留，但维度必须相同且零位移。Rust 共用生成器按官方 kmesh.pl 的 x 外层、y 中层、z 内层顺序生成 i/N，坐标八位小数、等权重六位小数科学计数法；带权重输出经过六种网格的官方脚本逐字对照。

NSCF 完成、编号阶段复用和版本 2 QE 清单交付时，读取实际输入和输出，核对输入声明点数、坐标行数、输出 nks 和电子态记录数，检查坐标、点序、重复点与归一化权重。SCF 的不可约点数不参与相等比较，16 与 36 可以合法共存。实际 nscf.in 以 nscf_input 角色纳入哈希交付，导入后仍检查；旧清单缺该角色时明确拒绝。

第 2 阶段允许 pw.x 的 nscf 和 bands 两种 calculation。点表核验失败时停止，不发布新完成回执，并建议用户显式改为 calculation='bands' 后恢复 NSCF；不自动换模式或重试。bands.x 是电子能带后处理，不是该恢复计算程序。

SCF、NSCF 的 SYSTEM 可以分别设置密度 nr1/nr2/nr3 和平滑 nr1s/nr2s/nr3s，每套必须是完整的正整数三元组；未设置时由 QE 决定，不从其他阶段静默复制。两份实际 XML 的 fft_grid 与 fft_smooth 都以 nr1/nr2/nr3 属性记录尺寸；任一不一致就报告来源和双方维度并停止。PH 交付保留既有 SCF 快照来源、文件身份、几何及响应尺寸验证，不从字节数单独猜测三维 FFT。

验证为隔离进程替身及历史 SiP₂ XML 只读检查，不是新科学计算。源码受控测试已通过；仅共享生成器已提交 f83a641，其余配置和接续改动依赖尚未提交的 0059 工作树，尚未独立提交或安装。没有重算 PH、导入外部 SiP₂ save 或改写历史输入／输出。证据和完整边界见 [0060 验收](../../specs/0060-epw-nscf-grid-contract/acceptance.md)。

上述 FFT／网格一致性检查只解析 XML，不核对原始电荷密度和波函数的内容、大小、非空、存在性或集合。当前排除规则见 [0067](../../specs/0067-unchecked-density-wavefunctions/spec.md)。
