## 一句话结论

为使用 DFTFlow 的材料计算用户新增 Rust `epwflow`：从结构、赝势和配置一次启动 QE → Wannier → EPW → 超导求解，支持各向同性和各向异性、受限的 Tc 搜索、数据复用、故障恢复及可检查的图表结果。

## 背景与目标

### 已确认事实

- 参考是 `external/epwpy` 固定提交 `b54bb53d4f5de665ed08958cb6194be8efdf645d`，不是运行期 Python 依赖。其 `EPWpy/flow/transport.py` 串联 SCF、NSCF、PH 和两阶段 EPW；`utilities/epw_pp.py` 归集 PH 数据；许可见子模块 `License`。
- [官方 MgB₂ 教程](https://epwpy.org/doc/notebooks/supercond_aniso_v1.2.html)展示 Wannier 表示、细网格插值和各向异性超导求解，小网格教学结果不代表物理收敛。
- [0006 当前行为](../overview/qeflow/phonon-workflow.md)包含一次 SCF、正常结束的 PH 初始化、index/coords、独立保存树、Slurm 依赖和失败恢复；其验收未验证 EPW 对响应势的消费。
- 现有 `scflow` 根据 QE EPC 结果计算谱函数与 Tc，不能作为 EPW 各向异性求解器替代品。
- 本机指定 QE 7.4.1 安装中存在 EPW 可执行文件，配套源码声明 EPW 5.9；实际运行版本和计算节点兼容性尚需核验。该版本输入与 EPWpy 当前版本有差异，例如源码输入声明没有 `a2f_iso`。
- 本机 EPW 5.9 源码的各向同性驱动调用 `crit_temp_iso`，各向异性驱动调用非线性虚频轴求解器；不能假设两个模式均支持同一线性化 Tc 接口。
- 仓库目前是五个 Rust 家族二进制；新增 epwflow 是本规划明确的扩展。独立 dyn0 工具和 MatterSim 的既有边界保持。

### 要解决的问题

手工连接 PH、均匀网格电子态、Wannier 化、EPW 矩阵元、不同温度的超导求解容易混用保存文件和计算参数；作业退出也不能证明每个温度已收敛。需要明确数据依赖、预算、失败状态与可复核结果。

### 目标与成功信号

| 目标 | 成功信号 | 验证方式 |
| --- | --- | --- |
| 一次入口完成工作流 | 无需人工提交中间阶段；各向同性、各向异性均有结果与图表 | 模拟调度和真实 MgB₂ |
| 结果正确且可追溯 | α²F、λ、能隙和 Tc 对照满足预设容差 | 同版本、同输入、同并行设置的独立手动 EPW 参考 |
| 复用与续算可靠 | 相同输入跳过成功项，改变依赖后不误复用，失败不启动下游 | 状态、哈希、失败注入和跨进程测试 |
| 资源受控 | 所有真实试算、对照和重试共同遵守用户预算 | Slurm 账本、预算预留及存储核查 |
| 用户知道执行什么 | 提供直接 CLI、底层输入输出与阶段说明 | Quickstart 与安装入口验证 |

### 明确不做

- 首版不包含结构优化、材料参数收敛研究、自动选择投影/能窗、自动扫描网格/展宽。
- 不包含磁性、SOC、全带宽模型和显式库仑矩阵；采用给定 μ* 的常规费米面附近模型。
- 不重写 QE、Wannier90 或 EPW 科学求解器，不将现有 scflow 的 Tc 冒充 EPW 结果。
- 不在本次承诺 inspur/chem 的真实验收；可沿用配置模板，但不伪造机器参数或证据。
- 不操作线上 Gitee Issue，不自行推送，不覆盖历史计算目录。

## 关键流程与异常路径

1. 检查结构、赝势、配置、支持模型、科学程序版本及资源预算，绑定独立运行目录。
2. 运行一次 SCF；为 PH 和完整均匀网格电子态准备隔离保存数据，避免 NSCF 覆盖 PH 所依赖的 SCF。
3. PH 正常初始化获得真实 q 列表；三种模式归集相同顺序的数据，核对动力学矩阵、响应势和扰动模式。
4. 完成 Wannier 化、粗网格矩阵元和细网格插值；检查插值结果及数据完整性。
5. 求解所选超导模式，逐温度验证收敛；根据指定温度范围、精度和次数约束定位 Tc。
6. 输出表格、图像、数值状态和计算来源；仅全部必要结果通过校验才标记完成。
7. 任一计算失败、缺文件、数据不匹配或未收敛时，记录具体阶段并阻止受影响下游。未收敛不等于正常态；找不到转变或耗尽预算不生成伪造的 Tc。
8. 再次运行时查询已提交任务、核对输入与中间数据，复用有效结果；参数改变只允许有依据的阶段失效与重算，不能复用不兼容旧数据。

## 数据与信息边界

| 数据 | 来源与归属 | 生命周期 | 质量与治理 |
| --- | --- | --- | --- |
| 结构、赝势、物理配置 | 用户 | 输入归档至用户主动清理 | 内容哈希、单位和支持范围校验 |

| Wannier 与 EPW 矩阵元 | 外部科学程序 | 允许后续温度求解复用 | 与结构、网格、版本、投影、能窗及并行兼容性绑定 |
| 任务、温度及预算记录 | epwflow / Slurm | 跨退出、续算保留 | 原子更新、并发保护；调度未知状态不等于可重复提交 |
| 表格、图片、验收证据 | 解析与对照 | 保留来源和状态 | 数值与图像可读性检查；无结果时不画伪成功图 |
| 机器路径与运行证据 | 本机用户 | 本地保存 | 使用忽略目录；新增 examples 继续忽略，不强行入库 |

原始日志、用户输入与已有目录不自动删除；默认 outdir 为 `./tmp`，显式设置继续生效。复制前检查可用空间，达到存储限制时停止追加计算，不通过删除用户结果维持运行。

### 关键架构决策

| 决策 | 选择 | 原因 | 代价与备选 |
| --- | --- | --- | --- |
| 语言和交付 | Rust 家族二进制 epwflow，Bash 作业脚本 | 用户明确要求，与现有项目一致 | 不复刻 Python API，不依赖运行时 EPWpy |
| 科学计算 | 调用外部 QE/Wannier90/EPW | 保留成熟科学实现及可对照性 | 必须处理程序版本差异 |

| 调度 | 原生 Slurm 依赖、阶段状态、受控后继任务 | 一次入口与失败阻断，避免占计算节点轮询 | 动态 Tc 搜索和小作业额度需有界调度 |

| 版本 | 优先验证指定 QE 7.4.1 / 配套 EPW | 与本机计算环境一致 | 不能照搬 EPWpy 新参数或默认值 |

### 跨功能质量要求

- **权限**：用户级安装，不改系统环境，不读取认证文件；机器信息不写跟踪文档。
- **可靠性**：成功需包含程序结束、必要数值收敛和完整产物；所有失败可定位并保留现场。
- **容量**：每作业最多 1 节点、64 MPI、2 小时；同时运行最多 2 个作业；累计 8 节点小时；运行数据最多 100 GiB。参考对照、预检试算和失败重试均计入同一验收预算。提交前预留预算，避免仅在完成后统计造成超支。
- **性能**：复用有效 SCF、响应数据及矩阵元；不承诺未经测量的速度提升。
- **可维护性**：固定参考版本；输入、状态、输出解析各司其职；详细路径和 API 在 Feature Spec 中确定。
- **平台**：沿用 Linux x86_64 / macOS arm64 分离构建；本次真实数值验收在 sugon-amd。没有 macOS 运行环境时明确记录未实测。
- **兼容**：不改变已有 qeflow/scflow CLI 的公开语义；独立 dyn0 工具保持独立。新支持能力必须有测试依据。

## 运营与治理

- 用户决定物理参数和预算；维护者负责实现、可复查证据和如实报告，不能以预算不足为由降低标准。
- 安装遵循用户在 0011 后续确认的固定 `current/bin` 覆盖方式，默认不保留旧版本或入口备份；取代先前版本目录与回滚入口的规划。覆盖前验证制品与入口，在无活动计算链时更新；核对源码、制品和实际入口，不只检查构建成功。
- 状态命令报告当前阶段、作业、失败原因、温度状态和预算；原日志仍可直接查看。
- 需求新增独立 Epic，与 0006 关联；继续使用本地 Issue 草稿，不伪造线上编号或关闭线上 Issue。
- 不引入独立管理服务、服务可用性 SLA 或个人数据业务；这些治理项目不适用用户级批处理 CLI。

| 风险 | 触发条件 | 影响 | 验证与应对 | 责任方 |
| --- | --- | --- | --- | --- |

| 预算或队列不足 | 任务较慢或提交额度有限 | 验收不能一次完成 | 预留预算、有界并发、保存续算状态；不扩额不冒充通过 | 实现者 |
| 原始保存格式受并行设置影响 | 不兼容的 pool/MPI 或缺少波函数 | 旧数据不可复用 | 在数据契约中检查相容性；真实同配置对照 | 实现者 |
| 历史环境存在旧 glibc | 登录节点产物无法在计算节点运行 | 安装入口不可用 | 复用现有打包方式并在目标节点验证 | 实现者 |

- 配套源码声明与本机 EPW 可执行版本相符；尚无运行证据，阶段 1 核验，失败则停止依赖该适配的任务。

- 本次优先使用已经配置的 sugon-amd；其他机器不视为已验收。

## 决策记录

### 2026-10-14

- Q1–Q3 确认 Rust 完整链路，两种求解模式，从结构开始并可复用；物理参数固定。
- Q4 在上述固定参数范围内允许受预算限制的温度自适应，属于对“全自动”的细化，不扩展为网格/展宽扫描。
