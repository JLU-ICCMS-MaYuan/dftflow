# 声子谱输入契约

- 输入 KPATH：各路径顶点为倒格子基矢下的三个分数坐标，沿用现有解析格式。
- 输出 `matdyn_phband.in`：`&input` 中恰有一个 `q_in_cryst_coord = .true.`；坐标数值不变。
- `q_in_band_form` 沿用旧行为，不能代替坐标声明；权重、标签索引与路径距离算法保持不变。
- `matdyn_phdos.in` 不增加此参数，也不改变 DOS 网格、采样或输出命名。
- 不新增 CLI/配置项，不自动写入或迁移历史归档。
- 已用旧生成器计算的结果需先核查输入；不能靠改标签或重新绘图修复错误计算路径。必要时另行重算 matdyn。
