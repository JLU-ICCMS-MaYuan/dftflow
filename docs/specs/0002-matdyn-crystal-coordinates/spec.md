# 规格：matdyn 声子谱晶体坐标声明

**Issue**：0002（Gitee：[IKHSA0](https://gitee.com/mayuan_JLUPHY/dftflow/issues/IKHSA0)，type-bug）

**日期**：2026-09-22

**状态**：实现及本地测试通过；未推送，未执行真实后处理。见 [acceptance.md](acceptance.md)。

## 背景与目标

路径文件使用倒格子基矢下的分数坐标；当前生成的声子谱输入没有说明坐标类型，QE 默认按笛卡尔坐标解释。需要让路径标签对应实际计算路径，尤其避免非立方晶胞上的错误。

## 用户场景与验收

### US1：按输入路径计算声子谱（P1）

用户提供 KPATH 和计算晶胞后，生成的输入应使 QE 沿指定的高对称路径计算，而不是沿被误解的坐标计算。独立验收使用不等轴正交晶胞和斜晶胞，核对声明、坐标、权重及距离。

1. 假如提供晶体分数坐标路径，当生成输入时，那么坐标类型明确为晶体坐标，原坐标和采样约定不变。
2. 假如晶胞不是立方晶胞，那么标签距离与同一组晶体坐标的倒空间路径一致。

## 功能需求

- **FR-001**：声子谱输入必须明确采用晶体分数坐标；无需新开关或新命令。
- **FR-002**：保留路径坐标、权重、标签、输出文件名与现有分段规则，不额外变换坐标。
- **FR-003**：DOS 输入、绘图、计算数据和工作流结构保持不变；不自动重算历史结果。
- **FR-004**：说明坐标契约及历史结果核查边界，记录可复现验收证据。

## 成功标准

- **SC-001**：非立方晶胞回归先因缺少坐标声明失败，修复后通过；验证至少两个非立方晶胞与多轴路径。
- **SC-002**：现有声子测试及联合绘图测试通过，DOS 输入兼容测试通过。
- **SC-003**：生产代码变更仅限声子谱输入生成器；原计算目录不发生写入。

## 边界、依赖与确认

- 坐标声明与路径是否插值是不同概念，声明不依赖 q_in_band_form 是否开启；不改变该开关现有行为。
- 不支持把笛卡尔路径伪装成现有 KPATH；不新增坐标模式切换。
- 文件缺失及解析错误保持原行为。外部 QE 的安装和运行依赖与单元测试分开验收。
- 2026-09-22 用户明确同意本方案；沿用现有 Python 输入生成器。ISIF2/ISIF3 实际后处理与 PPT 更新不属于本修复，SC-07 暂不处理。
