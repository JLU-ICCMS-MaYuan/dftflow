# Feature 规格：声子谱与态密度联合绘图

**Issue**：0003（Gitee：[IKHQNI](https://gitee.com/mayuan_JLUPHY/dftflow/issues/IKHQNI)）
**创建日期**：2026-09-22
**状态**：实现与本地验收完成；远端代码尚未推送

## 背景与目标

现有 `qe_process_phonon` 已能同时读取声子谱和 DOS，但只能输出两张独立 PNG。
用户需要在一张 JPG 中直接比较相同频率处的色散与总 DOS、元素分波，避免在 PPT 中拼接两张不同轴范围的图片。

## 用户场景与验收

### US1：从已有归档生成联合图（P1）

假如工作区具有有效色散、标签和 DOS，执行现有绘图命令后，应额外得到一张左色散、右 DOS、共享频率轴的 JPG；已有 PNG 和 CSV 保持可用。
独立验收：真实 CLI 执行成功，联合图片可解码，两个坐标轴真正共享 y 轴且包含完整负频范围。

### 边界与异常

- 色散与 DOS 频率范围不同：联合轴覆盖两者并集，不裁去任一数据。
- 没有负频时不制造负频曲线；有负频时不裁剪、不取绝对值。
- 输入缺失或损坏：沿用现有读取失败语义，不伪造缺少的图。
- 原有 `--plot` 要求两类归档同时存在；本功能不新增单独绘图模式。
- 绘图失败必须向调用者传播，图对象在保存失败时也应关闭。

## 功能需求

- **FR-001**：现有同时绘图路径额外输出工作区根目录 `phonon_band_dos.jpg`，不新增 CLI 或参数。
- **FR-002**：左侧完整声子谱、右侧 TDOS 与元素分波共享相同的频率 y 轴，只在左侧显示频率刻度及单位 cm⁻¹。
- **FR-003**：使用现有数据表与原路径标签，保留所有数值、负频率，不改变 DOS 归一化或平滑数据。
- **FR-004**：原有 PNG、CSV、CLI 参数、归档输入契约和历史工作流状态判定保持兼容。
- **FR-005**：只新增生成文件，不修改输入，不调用 QE，不把缺失数据绘成零曲线。
- **FR-006**：提供用法、项目内 skill 和自动化回归；错误不得静默吞掉。

## 成功标准

- **SC-001**：小样本与真实归档均成功生成可解码 JPG，图中线条与输入频率及 DOS 一致。
- **SC-002**：两个面板共享 y 轴，覆盖色散与 DOS 全部频率，右侧不重复显示频率刻度。
- **SC-003**：原有绘图文件继续生成，历史完成工作区不因缺少新增 JPG 被判为未完成。
- **SC-004**：相关 QE 测试通过，真实数据处理前后输入哈希不变。

## 假设与依赖

继续使用现有 Python、numpy、matplotlib。无新运行依赖；绘图环境本来就需要 matplotlib。
调用方负责将旧目录文件适配为现有 phband/phdos 契约。

## 范围外事项

不新增自动寻找目录、单项绘图、单位切换或 PPT 生成 API；不修订稳定性和 Tc 结论；不改变计算流程。
SiP2 的批量绘图和三部分 PPT 为本功能真实应用验证，保存在调用方 Vault，而不是 qeflow 包内。
