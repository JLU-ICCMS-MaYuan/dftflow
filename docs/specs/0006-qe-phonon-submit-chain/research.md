## 实际部署发现与修复

登录节点 glibc 2.28、计算节点旧版，原生制品无法启动。使用用户级 patchelf 将制品 interpreter 指向共享原生前缀里的同版 glibc 加载器，打包 libc/libm/pthread 等配套库；不修改系统、不设置全局 LD_LIBRARY_PATH。源与打包制品分别记录 SHA-256。该部署差异不改变计算或工作流设计，musl 通用静态交付路线保留。

## 调度账户额度

实际三模式同时启动触发 AssocMaxSubmitJobLimit，前置阶段非零退出，下游依赖自动取消，记录保留；依次重试复用已有 SCF。sacctmgr 只读查询确认账户存在 MaxSubmitJobs=4/8 的限制。该边界沿用已批准的提交失败处理，不隐式改为占用节点轮询、批次控制器或其他作业拓扑；更多不可约 q 点要求足够提交额度。

## 工具拆分决策

主流程已由 only_init 获取真实 q 列表；独立算法仍供用户离线读取 SCF XML 使用，故保留算法但移出 workspace。拒绝保留主程序对子工具的隐式调用。主项目保留 bg 读取，不再因坐标转换要求旋转矩阵/时间反演信息。独立工具仍完整解析对称性，不扩大其物理适用范围。
--dyn0 单步初始化与分 q 前置共享输入和完成检查；仅得到 dyn0 不代表声子计算完成。初始化输入使用 ldisp/only_init/lqdir=true、recover/only_wfc=false 并清除 start_q/last_q/start_irr/last_irr 限制。

## 默认保存目录

用户指定 ./tmp；电子输入当前已使用该默认值，声子仍有 ./out 的默认配置及多个回退点。同步所有生产读取点，避免写 tmp 却检查/合并 out。显式用户目录仍覆盖缺省值；不自动搜索或搬迁旧 out，以免把不同运行数据混合。

## US5：参数缺失归因

属于主路径接口实现缺失：结构上下文已支持显式文件，但 nosplit CLI 未声明 input 且调用固定传 None。复用现有读取职责；不修改配置所有权、目录解析或续算设计。采用与 split 一致的四种拼写，不新增配置键。

## US6：输出差异

nosplit 使用历史逐文件清单及多条提交提示，split 仅报告前置作业。采用同类状态统一措辞，分别保留两种真实作业拓扑，不把 nosplit 描述为多作业链。未引入静默错误或全局屏蔽 stdout。

## 追加实施设计

配置快照保留用户配置字段，将 work_dir 和赝势目录固定为绝对路径，结构原字节复制。快照清单校验配置与结构内容，阶段命令读固定路径；原绑定继续阻止同目录更换计算输入。旧无快照目录仅在显式重新准备时生成，不后台迁移或重提真实作业。

覆盖上述追加 FR/SC；顺序为文档、实现、生产 CLI 回归、安装、记录。

并行边界：各 q 检查会从结构快照恢复共享 POSCAR，采用进程独立临时文件加原子 rename，避免并行读到截断中的结构；验收同时启动两个 q 脚本。
