## 目标与用户价值

新增 Rust `epwflow` 家族入口，参考 `external/epwpy` 提交 `b54bb53d4f5de665ed08958cb6194be8efdf645d`，让用户从结构、赝势和配置一次启动 QE → Wannier → EPW → 两种超导求解 → 受限 Tc 搜索 → 表格和绘图。

现有 qeflow 负责的声子工作流与 scflow 后处理提供部分基础，但其已有验收不能证明 EPW 响应势接入与各向异性求解正确。本 Epic 独立交付这些能力。

## 本次范围

- 采用 Rust 编排、解析及绘图，调用 QE/Wannier90/EPW 科学程序；EPWpy 是设计参考，不是运行时依赖。
- 支持各向同性和各向异性；首版为非磁性、无 SOC、给定 μ* 的常规模型。
- 从准备好的结构和配置开始；已有数据必须经过来源、参数和完整性检查才可复用。
- PH 支持 nosplit、index、coords；一次 SCF，独立保存树，完整电子态准备，不将普通能带路径当作均匀网格输入。
- 完成 Wannier 化、粗/细网格 EPW 数据衔接，明确插值质量检查。
- 固定物理参数，只在指定温度范围、精度和次数上限内自适应搜索 Tc。
- Slurm 一次入口、有界调度、幂等提交、失败阻断和断点续算；不占用计算节点轮询等待。
- 输出 α²F、λ、能隙随温度变化、Tc 及其状态、表格、图像和来源记录。
- 默认 outdir 为 ./tmp；历史计算保留。跨目录启动与显式配置可复现。
- 提供直接 CLI 手册、输入输出解释、算例、固定 current 安装、覆盖前验证及制品来源核验。

## 范围外事项

结构优化、材料参数收敛研究、自动扫描网格/展宽、自动 Wannier 调参、磁性、SOC、全带宽和显式库仑矩阵不进入首版；作为后续候选保留。无需新增在线服务或数据库。

本次不承诺其他集群真实验收，不操作线上 Gitee，不自动推送，不把旧 scflow 的 Tc 代替 EPW 结果。

安装条款按用户在 0011 已确认的较新要求更新：覆盖固定 `current/bin`，默认不保存旧版本或入口备份；取代本 Epic 原先的版本目录与回滚入口要求，其他功能范围不变。

## 共享约束

- 真实试算统一受限：每作业最多 1 节点、64 MPI、2 小时；同时运行最多 2 个作业；累计最多 8 节点小时；运行数据最多 100 GiB。参考、失败和重试均计入；提交前预留预算，限额耗尽停止追加并保留现场。
- 运行成功至少包括外部程序成功、必要数值收敛和产物完整；未收敛不当作正常态，未找到转变不报告虚假 Tc。
- 首先核验指定 QE 7.4.1 配套 EPW 运行版本。配套源码声明 5.9，但不以源码版本代替可执行证据，也不直接照搬 EPWpy 新版输入。
- 保持现有 CLI 语义；Linux x86_64/macOS arm64 构建配置继续分离，目标集群需核验实际入口。
- 真实路径、任务日志和计算数据只保存在忽略目录；新增 examples 内容继续遵守忽略规则。
