## 背景与目标

当前 Rust 独立谱图及联合图以 labels.get(qi) 获取每个频率采样点横坐标，超过标签数量后回退为零。真实 MgB₂ 有 183 个采样点、12 条端点记录，导致大多数曲线折回原点。频率轴固定从零开始会裁掉负频；横轴混用数值刻度与图内文本使标签重叠。

以 origin/python 的 qeflow 路径生成、表格插值与绘图链为参考，重写 Rust 绘图的数据组织及布局，不照搬已有错误。

## 用户场景与验收

### US1：从已有 QE 结果生成正确声子谱（P1）

用户执行既有后处理绘图入口，得到以高对称点路径为横轴、频率为纵轴的完整色散图；独立 PNG 与联合 JPG 左面板一致，联合图右面板保持 DOS 横轴、频率纵轴。

### 边界与异常

保留虚频和重复端点；路径跳段不能跨段连线。空频率、非有限数值、标签索引越界或点数不匹配应明确报错，禁止默默回退到零。VASPKit 使用标准化原胞的坐标，核对其与 QE 晶胞基底的一致性，不能自动替换计算结构。

## 功能需求

- FR-001：逐采样点的累计路径距离与频率一一对应，CSV 与绘图共用已验证的数据模型；段长使用晶胞倒格矢度量。
- FR-002：横轴只标高对称点标签，GAMMA 显示 Γ；连续段共享端点，断段使用清晰组合刻度（如 A|L），不跨跳段连线。
- FR-003：纵轴为 Frequency (cm⁻¹)，显示完整正负频率并留边距，绘制零频参考线。
- FR-004：独立声子谱与联合图共用绘制逻辑；联合图谱/DOS 共用频率范围，布局参考 Python 约 3:1，刻度不重叠、不过密。
- FR-005：保留既有 CLI 和输出文件名；复用已有计算结果，不重跑 SCF/PH/q2r/matdyn。错误保留，科学频率值不得被修改。
- FR-006：核对 VASPKit KPATH.in 的成对端点、连续段合并、跳段权重、matdyn 晶体坐标声明与标签索引，记录与 Python 的一致性及有理由的修正。

## 关键实体

路径：有序连续分段、采样点索引、分数坐标、累计距离及端点标签；频率：每个采样点对应的所有模式，单位 cm⁻¹；刻度：端点距离与展示标签，与采样数据分离。

- SC-002：非立方晶胞、断段/同位置不同标签、负频和非法输入回归通过；断段无连线且标签清楚。
