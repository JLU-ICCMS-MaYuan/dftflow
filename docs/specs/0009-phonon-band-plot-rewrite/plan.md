# 0009 实施方案

## 已确认范围

遵循 [Spec](spec.md) FR-001～006、SC-001～004，使用现有 Rust/plotters，无新运行时依赖。

## 数据与职责

新增共享 BandData：解析归档优先的 labelinfo/频率，严格校验索引、完整点数、有限数值；按标签索引逐点插值得到距离及坐标。相同距离、相邻索引而坐标不同表示跳段，绘图分段，刻度合并为 A|L。表格与图只消费这一数据模型，不从高对称点行号推断采样点。

plot 模块提供共用声子谱绘制器，手动绘制横轴标签到坐标轴下方，禁止普通数值横轴刻度；灰色端点分隔线与稀疏水平网格，蓝色细曲线。频率范围扫描完整数据并包含零，留 5%/至少 1 cm⁻¹ 边距。联合图 3:1，两图相同上下边距及频率映射；右图 DOS 横轴，频率纵轴。DOS 元素分波复用现有表格聚合，不误把原子列称为元素。

## 路径基底与参考

固定 Python 提交 7a172fed4b48c408bc7a8d509071254a225ae637，仅导出必要源码到本地证据目录独立调用。比较 KPATH.in → matdyn 输入/标签 → 插值/频率/CSV。核对 MgB₂ 的原胞与 POSCAR 晶格；不更换结构，不更改既有 matdyn 频率。标准化基底不一致时解释限制，不自动猜变换。

## 验证与安装

用合成非立方、跳段、虚频、无效索引/数量回归共享数据及实际渲染；隔离复制真实 MgB₂ 后处理资产，以真实 CLI --plot 生成 CSV/PNG/JPG，检查每个频率及坐标与 Python 一致；保存 Python 参考图和前后图并实际查看。原目录只读，输入哈希前后相同。测试后编译 qeflow，既有加载器打包并备份切换入口，核验已安装 CLI 重绘，不提交队列任务。
