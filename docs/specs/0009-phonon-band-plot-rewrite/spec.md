## 背景与目标

当前 Rust 独立谱图及联合图以 labels.get(qi) 获取每个频率采样点横坐标，超过标签数量后回退为零。真实 MgB₂ 有 183 个采样点、12 条端点记录，导致大多数曲线折回原点。频率轴固定从零开始会裁掉负频；横轴混用数值刻度与图内文本使标签重叠。

以 origin/python 的 qeflow 路径生成、表格插值与绘图链为参考，重写 Rust 绘图的数据组织及布局，不照搬已有错误。

## 用户场景与验收

### US1：从已有 QE 结果生成正确声子谱（P1）

用户执行既有后处理绘图入口，得到以高对称点路径为横轴、频率为纵轴的完整色散图；独立 PNG 与联合 JPG 左面板一致，联合图右面板保持 DOS 横轴、频率纵轴。

### 边界与异常

保留虚频和重复端点；路径跳段不能跨段连线。空频率、非有限数值、标签索引越界或点数不匹配应明确报错，禁止默默回退到零。VASPKit 使用标准化原胞的坐标，核对其与 QE 晶胞基底的一致性，不能自动替换计算结构。
