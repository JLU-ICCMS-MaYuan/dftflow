## CLI 与自动执行流程

- 在现有 `epw_phonon` 增加 `--import-phonon SAVE`，不新增独立程序。配置文件仍通过 `--config` 指定，文件名不限。
- `-s` 提交一个阶段作业，内部自动完成全部步骤，无需反复调用推进命令。`--check` 只读检查；不带执行选项时仅准备；失败后使用相同命令追加 `--resume`。
- 自动识别 prefix、文本/XML 动力学矩阵、q 网格、不可约 q 列表、响应势和 phsave。科学设置、路径、ASR、DOS 网格及资源来自 TOML。
- 要求当前 SCF、NSCF 已完成且可验证；缺失时明确报错。**导入路径绝不调用 SCF、NSCF、PH 或 PH 初始化，也不在失败时退回重算声子。**

流程固定为：

**读取配置与 save → 核验与归集 → 格式转换 → q2r → 色散 matdyn → DOS matdyn → 绘图 → 发布声子交付和完成记录。**
