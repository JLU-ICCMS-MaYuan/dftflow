## 目标与用户价值

用户从结构、赝势和配置获得经过校验的完整电子态与声子响应数据，供后续 EPW 使用；可选择 nosplit/index/coords，可复用一致的已有结果，失败后可续算。一次 SCF 后的非自洽电子态准备是必要的独立步骤，不是第二次 SCF，也不是逐 q 重跑 SCF。

## 事实与复用边界

现有 0006 已有正常结束的 only_init 初始化、分 q 任务和声子合并；新增输入快照能力也可作为复用基础。但当前合并函数只检查部分日志、dyn 与 patterns，再按文件名复制 dvscf，不能凭声子谱成功证明 EPW 数据完备。

现有一个声子 NSCF 构造函数把 nosym 放入 CONTROL，并继续使用 SCF 的 automatic 网格；不能直接作为 EPW 完整均匀网格的生成器。实现时应明确正确配置段、k 点列表及输出校验，不扩展成与本功能无关的全库修复。

## 本次范围

1. **固定输入并运行一次 SCF**：保存有效配置、原始结构名加 -init 的快照及赝势来源；后续阶段读取固定输入。校验 SCF 收敛、程序正常结束及 XML、电荷密度、波函数等所需保存数据，再生成可复用的数据快照。
2. **电子态准备与隔离**：按 EPW 要求准备完整、无缺点和重复点的均匀 k 网格及波函数，明确坐标、权重、带数和 k/q 网格相容性；核对实际输出而非只检查输入。PH、电子态准备和各 q 任务使用独立可写保存目录，NSCF 不得覆盖 PH 的 SCF 数据。
3. **三种声子模式**：nosplit 由一个 PH 任务处理整个网格；index 用网格中的 start_q/last_q 序号；coords 用同一列表的 QE 笛卡尔坐标，单位 2π/alat。分 q 列表来自 ph.x 的 only_init 正常结束，子任务关闭初始化专用设置并仅运行 PH。
4. **统一映射**：保留网格、不可约 q 数量、顺序、坐标和数字目录的对应关系；非正交晶胞正确转换。单点 coords 目录中的局部 q=1 不能混同整个网格的第一个点；归集后动力学矩阵、响应势、扰动模式和全局列表须对应同一个物理 q 点。
5. **完整归集**：根据实际 outdir 定位并校验 dyn、dvscf、phsave 及目标版本需要的元数据；正确处理 Γ 点、一般 q 点、串行/并行文件布局。缺文件、空文件、错 q 点或不支持的保存格式必须阻止交付；不能仅改名或看见 JOB DONE 就放行。
6. **数据交付与复用**：向下一阶段提供可核查的数据清单、物理参数、版本、并行条件及输入/输出指纹。核对文件完整性和来源一致性；不共享可写来源，不混用不同结构、赝势、网格或版本结果。未验证的归集结果不得对下游标记为可用。
7. **统一执行边界**：接入 F1 状态、预算、调度和防重复机制；一次入口安排必要阶段。失败、未知作业状态或数据无效阻断下游，续算跳过仍有效的完成项。默认 outdir 为 ./tmp，显式设置优先；跨工作目录启动保持相同输入语义。
8. **直接操作说明**：文档列出三种模式的直接 epwflow 命令、SCF/初始化/PH/电子态的输入输出与保存目录，不只提供 prepare.sh 包装。具体 CLI 与数据清单格式在 Spec 中确定。

## 用户场景与验收

| 场景 | 必须得到的结果 |
| --- | --- |
| 同一体系分别从空目录运行三模式 | 每套流程只执行一次 SCF；分 q 子任务不再执行 SCF；数据可按同一 q 列表对照 |
| 非正交晶胞、非 Γ 点和 coords 局部编号 | 坐标转换与全局映射一致，响应势和模式文件不会串点 |
| 完整均匀电子态准备 | 输出 k 点数量、坐标、权重、带数和波函数满足 EPW 契约；普通能带路径或不可约网格被拒绝 |
| 自定义 outdir 或从其他目录启动 | 按同一配置定位数据；不依赖写死的 tmp 路径 |
| 文件齐名但内容缺失、坐标错误或数据被修改 | 报告具体问题，拒绝归集成功及下游启动 |
| PH/电子态任务失败或未收敛 | 保留现场、失败原因和已完成项，续算不误复用失败数据 |
| 修改外部原始配置或结构 | 已提交任务仍读取固定快照；篡改快照则报错，不能静默改变物理输入 |
| 导入已有 SCF/PH/电子态 | 校验来源与兼容性后复用；缺少关键依据或产物则明确拒绝 |
