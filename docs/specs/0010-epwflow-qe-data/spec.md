## 背景、目标与取舍

从固定的结构、赝势和配置，自动获得后续 EPW 可使用的电子态、动力学矩阵、响应势与扰动模式。用户选择 nosplit、index 或 coords；三者交付同一数据契约，具备来源检查、失败阻断和恢复能力。

正常新流程只执行一次 SCF。后续 NSCF 提供 EPW 所需的完整均匀网格电子态，属于必要的独立步骤；分 q 子任务不重复 SCF。PH 自身需要的电子态准备保留并记录。若导入有效 SCF，允许本次不再执行 SCF；失败 SCF 的显式重试须单独记录并计入预算。

沿用 Rust/Bash、非磁性、无 SOC 的范围。默认 outdir 为 `./tmp`，采用 0008 已确认的“配置目录解析后的保存目录基址”语义，再按运行与阶段派生独立目录。保留历史计算，不迁移或覆盖原有 qeflow 运行。

## 用户场景与验收

### US1：一次准备完整电子态与 PH 输入（P1）

**价值**：用户不必手工衔接 SCF、均匀网格 NSCF 与 PH 数据。

**独立验收**：模拟实际 CLI 执行链，核对 SCF 次数、NSCF 输出网格与独立保存树。

1. 假如输入有效且目录为空，当运行到 qe-data 阶段，那么 SCF 正常完成一次，后续电子态和 PH 使用独立保存目录。
2. 假如电子态输出缺 k 点、波函数或能带，那么阶段失败，不交付可用清单。
3. 假如外部原始输入在提交后变化，那么已提交阶段继续使用固定快照；快照被篡改则拒绝执行。

### US2：用三种 PH 模式获得一致的数据（P1）

**价值**：用户可以选择整网格或分 q 调度，后续 EPW 接口保持一致。

**独立验收**：同一非正交晶胞覆盖 Γ 和非 Γ 点，对照实际 q 列表、数字目录与动力学矩阵。

1. 假如选择 index 或 coords，那么初始化正常结束后从 dyn0 获取完整列表，不等待完整 PH，也不杀死 MPI 获取列表。
2. 假如选择 coords，那么局部第 1 个 q 点仍映射到正确的全局序号，响应势与模式文件不会串点。
3. 假如任一 q 失败或缺产物，那么归集及依赖下游被阻断。

### US3：检查和复用已有数据（P1）

**价值**：避免重算有效数据，同时拒绝貌似齐全但来源不一致的输入。

**独立验收**：导入有效来源后所需已完成阶段执行次数为零；更改赝势、网格或文件内容会被检出。

1. 假如已有数据的来源、参数和内容完整匹配，那么复制到隔离目录并复用。
2. 假如旧目录只有成功日志而缺响应势或来源证据，那么说明缺项，拒绝标记可用于 EPW。
3. 假如导入后运行新阶段，那么来源文件内容保持不变。

### US4：从失败处继续并控制资源（P1）

**价值**：部分 q 已完成时无需重做整套计算。

**独立验收**：模拟中断、部分提交失败和预算不足，验证有效阶段不重复、未知作业不重提、共用账本不归零。

1. 假如失败项已确认且额度允许，当显式 resume，那么只重试必要阶段。
2. 假如活动作业或提交结果尚未查清，那么保留记录，不复制任务。
3. 假如复制或下一阶段将超出空间或计算预算，那么开始前拒绝并保留现有数据。

### US5：知道执行了什么、文件在哪里（P2）

**价值**：直接使用 epwflow 命令，并能检查底层 QE 输入输出。

**独立验收**：依手册从其他工作目录准备、运行和检查同一配置，定位结果一致。

1. 假如执行 prepare，那么显示工作目录、实际保存目录和阶段计划，不启动科学程序。
2. 假如 qe-data 完成，那么显示数据清单与检查结果；不得把它表述成完整超导计算完成。

### 边界与异常

覆盖单 q、超过两位数的 q 编号、非正交晶胞、局部与全局编号不同、不同波函数布局、截断响应文件、空文件、错误元素顺序、未知格式、网格不相容、来源被修改、自定义 outdir、路径含空格、旧逐 q SCF 目录和作业状态未知。不能可靠解释的数据明确拒绝，不通过猜文件名补齐证据。

## 功能需求

### FR-001：公开命令与阶段边界

沿用 0008 的统一入口，增加可独立验收的 qe-data 阶段边界：

| 命令 | 行为 |
| --- | --- |
| `epwflow check -c C` | 只读检查本阶段配置和输入；不启动 QE/EPW |
| `epwflow prepare -c C` | 固定输入并生成本阶段计划和可确定的输入文件；未知 q 的任务在初始化后物化 |
| `epwflow submit -c C --until qe-data` | 自动安排到 QE 数据交付为止的关联作业 |
| `epwflow run -c C --until qe-data` | 在已登记资源中顺序完成到该边界 |
| `epwflow resume -w W -s 或 -r --until qe-data` | 使用固定快照续算；两种执行方式互斥 |
| `epwflow qe-data check -w W [--json]` | 只读核查本地数据、来源与清单；不启动 EPW 读取测试 |
| `epwflow qe-data import -c C --source M` | 校验来源清单，准备隔离副本并登记可复用阶段；不提交计算 |

C 是配置，W 是运行目录，M 是带来源与文件身份的清单。三种 PH 模式由配置选择，例如分别执行 `epwflow submit -c index.toml --until qe-data`、coords.toml 或 nosplit.toml；无需依赖 prepare.sh 才能操作。

已绑定目录不得更换模式或物理输入。完整 submit 的后续阶段尚未接入时必须明确报错；不能静默截短后报告整个工作流完成。

### FR-002：科学配置与单位

本阶段纳入 F1 的单一版本化 TOML 契约。具体分组为 `qe`、`qe.scf`、`qe.nscf`、`phonon`，复用共同的结构、赝势、程序、资源、预算、work_dir 和 outdir 字段。

至少包含：

- `qe.prefix`、`qe.ecutwfc_ry`、`qe.ecutrho_ry`、占据方式、适用时的展宽类型和 `qe.degauss_ry`。
- `qe.scf.k_grid`、`qe.scf.k_shift`、`qe.scf.conv_thr_ry`。
- `qe.nscf.k_grid`、`qe.nscf.nbnd` 和适用的电子态求解收敛设置。
- `phonon.mode`（nosplit/index/coords，缺省 index）、`phonon.q_grid`、`phonon.tr2_ph`；响应势基名由受控生成器统一管理。

能量显式标为 Ry，网格是三个正整数；SCF 移位按 QE automatic 网格约定验证。EPW 所用粗 NSCF 网格和 PH q 网格采用包含 Γ 的完整均匀网格，并检查 k+q 闭合。SCF 网格可独立设置，不要求与 NSCF 网格相同。

物理精度参数和 nbnd 必须明确配置，不根据材料名猜值。前置能带数约束与 F3 的排除能带、Wannier 数目联检；不接受任意 namelist 透传绕过模型、路径、保存和预算约束。未知字段、冲突参数、磁性或 SOC 设置须明确报错。

### FR-003：一次 SCF 与完整快照

检查 SCF 数值收敛、正常终止、结构和保存数据后才允许依赖阶段启动。快照必须覆盖目标版本后续步骤实际需要的 XML、电荷密度、波函数及相关文件，不能只复制 prefix.save 而漏掉树外波函数。

正常新流程只执行一次 SCF；各 q 子任务仅执行 PH。记录实际 SCF 尝试次数及成功次数，失败后的授权续算不伪装成从未重试。复用有效 SCF 可以跳过本次 SCF。

SCF 快照保持不可写来源。PH 初始化、整网格 PH、各 q 和 NSCF 各有独立可写保存树，不使用共享可写链接；复制完成后核对内容身份。空间预留须包含必要副本。

### FR-004：完整均匀 NSCF 电子态

生成 EPW 要求的显式完整均匀 k 点列表，明确晶体坐标、权重与带数，不能把普通能带路径或不可约 k 网格交付为完整电子态。

配置段和对称性设置必须经目标版本验证，既得到完整所需电子态，也保留后续 EPW 所需的对称性信息；不直接复用未经检查的旧 PH-NSCF 生成器。

核对实际输出的 k 点数、逐点坐标、权重、nbnd、波函数集合、电子态收敛、结构与赝势身份。记录原始权重约定，再按明确规则归一化比较，不能误把自旋简并导致的权重约定差异当成缺点。粗 k/q 网格必须支持所需 k+q 映射。

NSCF 使用 SCF 的隔离副本，不覆盖 PH 所用 SCF 电荷密度和保存文件。

### FR-005：三种 PH 行为

- **nosplit**：一个 PH 任务计算完整 q 网格；校验其产生的 dyn0 与全部对应数据，不强制增加一遍分 q 初始化。
- **index**：先用 `ldisp=true`、`only_init=true`、`lqdir=true` 正常初始化；从实际 dyn0 获取不可约 q 数量及顺序。各子任务 `ldisp=true`，`start_q=last_q=i`。
- **coords**：使用与 index 相同的初始化列表；各子任务 `ldisp=false`，输入对应的 QE 笛卡尔 q 坐标，单位 `2π/alat`。

初始化必须正常结束且产物完整；不杀进程截取列表。子任务显式关闭 only_init，采用与其阶段相容的恢复设置，不能继承初始化专用选项导致没有实际求解。

分 q 子任务从已验证的 SCF 快照准备自己的 outdir，不重复 SCF。PH 内部合法的电子态准备保留。三种模式的物理参数一致，模式差异只影响任务拆分和文件映射。

### FR-006：q 点映射

dyn0 声明的数量必须与解析到的记录一致。保存原文件身份、q 网格、全局 1 起始序号、晶体坐标、QE 笛卡尔坐标、alat/倒格矢约定、数字目录和局部 q 编号。

数字目录至少两位，超过 99 点时能无歧义扩展。非正交晶胞使用完整基底转换，不能逐分量除晶格长度。

coords 的局部 q=1 必须显式关联全局 i。坐标比较可按倒格矢周期判断同一采样点，但不能据此无条件交换 q、−q 或替换响应数据的相位、扰动基底。索引相同但物理坐标不同必须拒绝。

### FR-007：响应数据完整归集

根据各阶段实际 outdir 定位数据，不写死 tmp。校验并归集 dyn、dvscf、phsave、扰动模式和目标版本所需元数据；支持经验证的 Γ/非 Γ、串行/并行保存布局。

必须保持每个响应势与实际产生它的扰动模式配对。coords 局部模式转换为全局编号时，文件名和内部元数据须一致；不能直接用初始化阶段的另一套扰动基底覆盖子任务结果。需要基底转换时必须有可验证的转换，否则阻断交付。

全局 phsave 元数据须描述完整 q 列表，不能把某个单 q 目录的数量 1 当成全局数量。EPW 消费目录按目标版本要求形成 dyn_q、dvscf_q 和 phsave 等文件布局，编号格式由适配器校验。

检查动力学矩阵的原子/元素顺序、维度、q 点和有限性；响应文件的记录数、尺寸和扰动数必须与对应元数据匹配。空文件、截断、缺模式、错 q 或未知格式不得放行。

赝势类型所需附加数据必须列入兼容性检查。不能仅因为普通 PH 可算就声称该赝势及保存格式可用于 EPW；真实 MgB₂ 所用赝势必须纳入验收。禁止删除源波函数或其他历史数据以方便归集。

### FR-008：可定位的输入输出与交付清单

运行目录至少明确提供如下逻辑位置，并在 prepare/status 中报告实际路径：

- `scf/scf.in`、`scf/scf.out`。
- 分 q 模式的 `ph_init/ph_init.in`、`ph_init/ph_init.out` 与初始化 dyn0。
- `ph/nosplit/ph.in`、`ph.out`，或 `ph/NN/ph.in`、`ph.out`。
- `nscf/nscf.in`、`nscf/nscf.out`。
- `qe-data/q_index_map.json`、`qe-data/manifest.json` 及 EPW 消费文件集合。

这些工作目录与 F1 派生的实际保存目录分别记录；QE 输入中写入对应实际路径，跨目录启动不改变定位。

清单带格式版本，至少包含运行/阶段身份、结构和赝势指纹、程序身份及已验证版本、并行布局、物理参数、实际 k/q 列表、带数、文件角色/大小/哈希、原子与扰动基底映射、校验结论和执行次数。

只有全部必需本地校验通过才发布可供下一阶段消费的清单。生产阶段的本地完整性检查与验收中的实际 EPW 读取证据分别记录，不将前者冒充后者。

### FR-009：导入、复用与旧目录

已有 SCF、PH 或 NSCF 数据只有来源、物理参数、版本、布局及内容均通过检查，才能登记为可复用阶段；只核对目录名或 JOB DONE 不足以复用。

导入操作保留来源只读，在本运行的隔离保存树使用数据。完整来源清单能导入部分有效阶段；缺少关键依据则明确拒绝，不自动编造历史来源。

识别 0006 的分 q 目录及更早含逐 q SCF 的目录用于诊断和定向适配。旧声子目录不自动宣称 EPW 数据完整；缺响应文件或版本依据时给出需补齐的内容。不得改写旧目录来使检查通过。

原绑定物理输入改变时建立新运行，不能静默覆盖。恢复时逐项核对依赖和产物，复用有效结果，不沿用已失效的成功标记。

### FR-010：依赖、预算与失败

使用 F1 的原生 Slurm 提交、阶段校验、持久状态、并发控制及共享预算；初始化完成并物化 q 输入后，自动安排子任务和归集依赖，不占计算节点等待其他任务完成。

任一必需阶段失败、未知或数据校验不通过，受影响下游不执行。部分提交失败保留已有作业记录；重复入口不重复提交活动项。显式续算只重试确认失败或尚未执行的必要阶段。

所有复制、科学运行、独立参考及最小 EPW 读取测试共用 Epic 的 8 节点小时和 100 GiB 上限，并遵守每作业 1 节点/64 MPI/2 小时、最多 2 个运行作业；不能给 F2 另开预算。

### FR-011：预先固定的数据与数值对照标准

以下是本版提出的验收标准，确认后实施前固定，失败后不得临时放宽。采用相同结构、赝势、输入精度、程序版本和并行条件，使用足够精度的机器可读数据；不能拿舍入后的屏幕输出证明更高精度一致。

| 比较项 | 规则与容差 |
| --- | --- |
| k/q 数量、维度、带数、必要文件集合 | 整数及集合精确一致，无缺失或重复 |
| k/q 坐标 | 转为同一晶体倒空间基底，按周期唯一匹配；逐分量最大差 ≤ 10⁻⁸ |
| k 权重 | 记录原始约定后归一化；对应权重与总和的误差均 ≤ 10⁻¹⁰ |
| SCF 总能 | 自动流程与独立参考绝对差 ≤ 10⁻⁷ Ry/计算晶胞 |
| NSCF 本征能量与 Fermi 能 | 同一能量参考、同一 k 点，能带按能量及简并组匹配；最大绝对差 ≤ 10⁻⁵ eV，不用任意拟合平移掩盖差异 |
| 动力学矩阵 | 统一原子顺序与笛卡尔基底，比较未质量加权的力常数；逐元素最大绝对差 ≤ 10⁻⁷ Ry/Bohr² |
| 声子频率 | 同 q、同一 ASR 处理，覆盖全部 3N 模；保留虚频符号，按频率及简并组匹配；最大绝对差 ≤ 0.1 cm⁻¹ |
| 快照和来源保护 | 复制内容身份正确；来源文件执行前后哈希不变 |

不同 PH 模式的 dvscf 可以因扰动基底和相位而不同，不要求原始字节一致；必须核对基底映射并用实际 EPW 读取及后续物理对照验证。α²F、λ、能隙和 Tc 的标准由 F3–F5 固定，F2 文件校验不能替代这些验收。

MgB₂ 在三种 PH 模式下，与独立手动 QE 运行和归集参考比较，覆盖 Γ 与非 Γ 点，并满足 FR-011。
