## 用户场景与验收

### US1：查找并理解清理方法（P1）

使用者通过 README 导航到指南，区分旧安装副本、缓存、运行库和计算数据。

优先级理由：清理前必须理解目录用途。

独立验收：README 可打开指南；指南包含保留和删除条件。

1. 假如使用者要释放磁盘空间，当阅读指南，那么能判断哪些是候选，哪些必须保留。
2. 假如旧版本仍被排队作业调用，当检查引用，那么指南要求等待作业结束后再判断是否清理。

### 边界与异常场景

- 本机路径、版本及容量会变化，历史清单仅作示例。
- 没有 Slurm 的机器不执行 Slurm 查询，但仍检查入口和脚本引用。
- 多个计算根目录逐一检查，磁盘脚本不能替代调度器保存脚本的核查。
