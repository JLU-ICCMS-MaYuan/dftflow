# 第二阶段自动比较设计

本设计落实 T056、FR-014/015、SC-009/010 的总量比较部分；元素／轨道投影继续暂缓。实施与验证记录写入验收文档后才更新当前功能总览。

## 执行与数据

公开第二阶段使用已冻结的 KPATH。复用共享路径解析器，按每条边固定分段数展开，保留不连续段身份；距离按绑定倒格矢计算。可选 `[comparison]` 固定 `points_per_edge`、`electronic_sigma_ev`、`phonon_sigma_cm1`，缺省为 20、0.1 eV、10 cm⁻¹。DOS 使用 F2 完整均匀 NSCF 网格，不使用能带路径或超导细网格。

在 `comparison-native/` 固定请求和程序身份，并执行三个隔离任务：

1. 从冻结 SCF 副本计算 QE 路径 NSCF，保持原物理参数和带数；DOS 直接复用原 F2 NSCF XML。
2. 对已校验原始 PH 的全部 q 星施加与 EPW 相同的 Γ onsite 修正，保留全部星。上三角修正后，按 QE `rigid.f90::dyndiag` 的上下三角 Hermitian 平均构造 onsite，供 q2r 傅里叶变换；不能直接用上三角覆盖下三角。`q2r zasr=no`、`matdyn asr=no`，显式相同原子质量；路径和 DOS 点在同一频率文件中按固定顺序保存。原始 PH 不变，不执行新 PH。
3. 隔离重读同一 Wannier 粗网格，在路径加 DOS 网格上生成 EPW 电子和声子数据。`epwread=true`、`wannierize=false`，不重新选窗、不执行细网格 EPC。

q2r 和 matdyn 使用 PH 同目录且在 F1 冻结的程序。每个原生任务沿用持久尝试检查点：成功任务重验后复用，显式恢复只归档失败任务，未知目录／输入变化／成功证据篡改拒绝。请求绑定 F2、粗网格角色、KPATH、配置、程序和生成程序身份。

QE XML q2r 的 `write_dyn_mat_header` 在 `flfrc` 基名后追加 `.xml`；输入使用 `reference.fc`，实际检查 `reference.fc.xml`，matdyn 按同一基名读取。显式点输入每行三坐标，原生 matdyn 频率输出每个点是三坐标加第四列 q 权重；解析器保留该格式要求。

## 发布与阶段门

来源清单保存全部输入输出哈希、共同 Fermi、实际 Wannier Outer／Inner、点序、倒格矢、网格和核。复用 comparison 导出、0014 收集和四张独立图加总览的 PNG／SVG／PDF 输出。比较适配器按实际 XML 原子顺序检查 3N，元素按首次出现顺序生成；不推断原子轨道投影。

质量配对先完成，自动比较和图表在第二阶段成功清单之前完成。质量失败仍可导出诊断图，随后返回质量失败，禁止细网格和超导。成功粗网格清单绑定比较数据和图表，恢复时必须重新验证。没有 KPATH 的旧内部调用保持原接口；公开第一阶段本已强制绑定 KPATH。

比较数据通过独立请求绑定发布，已有成功数据只读重验；图表沿用已有发布日志。收集／重绘继续不运行科学程序，移动后可独立重绘。全链仍在同一已登记资源分配和原共享预算内，不引入参数扫描或新提交入口。

## 需求到验证

| 需求 | 组件／数据 | 任务与验证 |
| --- | --- | --- |
| FR-014、SC-009 | 固定路径、F2 网格、原生比较请求／来源 | T056：非正交路径、断点、点序、单位、来源篡改和同路径执行 |
| FR-014、FR-009 | 全星 Γ onsite、共同质量／Fermi | T056：ASR 矩阵单测；质量失败只出诊断、无下游成功标记 |
| FR-015、SC-010 暂缓后的总量部分 | 原子顺序、3N、缺投影状态 | T056：不同体系模式数、总量图及缺投影明确标记；严格投影任务不勾选 |
| FR-010/011、SC-004/005 | 原生尝试／来源身份／发布 | T056：失败后仅重试失败任务、未知现场与篡改拒绝、移动重绘无科学调用 |

进程替身验证执行与文件契约，不能代替真实 PBE 科学验收。真实运行、三来源及 iso/aniso Tc 仍按 0015 和原预算逐项验收。
