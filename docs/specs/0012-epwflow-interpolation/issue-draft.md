## 目标与用户价值

用户给定 Wannier 投影、能窗和粗细网格后，可自动得到经过质量检查的 Wannier 表象数据、EPW 插值结果，以及各向同性和各向异性超导求解所需的数据。已通过检查的中间结果可恢复或复用，温度搜索无需重复 Wannier 化或矩阵元生成。

## 事实与参考边界

参考 `external/epwpy` 固定提交 `b54bb53d4f5de665ed08958cb6194be8efdf645d` 的首次计算、重读 Wannier 数据和细网格计算分阶段设计；EPWpy 不作为运行时依赖。QE 7.4.1 配套源码声明 EPW 5.9，仍须通过 F1 核对实际可执行版本。

本地目标版本的 `EPW/src/readin.f90` 区分 `epbread/epbwrite` 与 `epwread/epwwrite`，并限制重新 Wannier 化与重读数据的组合；`ephwrite` 要求相容的均匀细网格。当前 EPWpy 中的新版 `a2f_iso` 输入开关不在该版本 namelist 中，不能直接照搬。具体兼容参数、文件集合和检查方式在详细 Spec 中固定，并用真实程序验证。

## 本次范围

1. **消费已校验的 QE 数据**：读取 F2 的电子态、PH 数据清单及固定输入，核对结构、赝势、粗网格、能带数、q 点映射与程序来源。缺失、篡改或不兼容即停止；只在独立工作目录写入，不覆盖来源数据。
2. **按配置完成 Wannier 化**：调用目标 EPW 所用的 Wannier90 接口，校验投影、Wannier 函数数目、排除能带、解纠缠与冻结能窗的适用组合；明确能量单位、参考零点及 Fermi 能来源。检查实际迭代、收敛和产物，不以进程退出成功代替数值成功。错误时给出相关输入和诊断，不自动调整投影或能窗。
3. **生成可重读的粗网格数据**：保存一致的 Wannier 旋转矩阵及电子、声子和电子声子耦合数据；按目标版本记录完整必需文件、尺寸、索引和指纹。区分首次生成、已完成结果重读及中断恢复，禁止不同 Wannier 基底的数据混用。
4. **插值质量检查**：在明确的验证点和能量范围内，对照 QE 电子能量与 PH 声子频率，报告误差、单位、能量对齐方式和所用参考。检查 Wannier 收敛及异常数值；不能只凭展宽值或一张能带图判定通过。验证点或路径与超导用均匀细网格分别管理，质量检查未通过则阻断下游；缺少参考时不得标记已通过。
5. **细网格计算与两种求解的数据交付**：按固定的细 k/q 网格、费米面能量窗口、展宽及相关参数生成 α²F、λ 和目标版本各向异性求解所需的矩阵元与索引数据。校验网格相容性、实际输出维度、权重、单位和有限性；根据模式记录必需产物，不能用 α²F 文件存在替代各向异性数据完整性。向 F4 交付可追溯、可读取的数据，F4 再执行温度相关的超导求解。
6. **分阶段复用与恢复**：按数据依赖判断有效性。结构、赝势、粗网格、投影或能窗变化必须使相关 Wannier 及下游结果失效；细网格或展宽变化重新生成受影响的细网格结果，但经核验仍有效的粗网格数据可复用；仅改变求解温度不重新生成与温度无关的数据。不支持的二进制格式、版本或并行布局复用应明确拒绝，不猜测兼容。
7. **一次入口与受控执行**：接入 F1 的 Slurm 依赖、预算、状态、防重复提交和失败恢复。只有必需产物与质量检查通过才允许下游执行；预算不足、超出存储限额或未知作业状态停止追加任务并保留现场。默认 outdir 为 ./tmp，显式配置优先，跨工作目录启动使用同一配置语义。
8. **可直接使用的说明**：列出准备、执行、检查和复用本阶段的直接 epwflow 命令，以及各输入、日志、质量报告和数据清单的用途；不只给出算例包装脚本。具体 CLI、输出格式和数值阈值在详细 Spec 中审查。

## 用户场景与验收

| 场景 | 必须得到的结果 |
| --- | --- |
| 三种 PH 模式产生的有效 F2 数据进入本阶段 | 均能由同一版本 EPW 读取，并在同参数下获得可比较的插值及电子声子结果 |
| 从空目录首次运行，再重读已完成数据 | 首次完成 Wannier 化；后续复用经过检查的数据，不重复运行有效阶段 |
| 投影、能窗或能带设置不相容，或 Wannier 未收敛 | 报告具体失败，不标记可用，也不继续超导求解 |
| 插值误差超限或缺少验证参考 | 输出检查结果并阻断下游，不自动调参或临时放宽容差 |
| 将能带路径误作细网格，或 k/q 网格不相容 | 在运行前拒绝；实际输出仍核对网格、索引与维度 |
| 重读数据缺文件、被截断、被篡改或来源不匹配 | 拒绝复用，报告缺失或不匹配项；完整旧数据保留 |
| 改变细网格、展宽或求解温度 | 按依赖重做必要阶段；不会误用旧细网格结果，也不因温度变化重做无关计算 |
| 阶段中断、重复启动或预算不足 | 保留证据，跳过有效完成项；不重复提交，不消耗新的一份预算 |

## 验证与关闭标准

- 模拟外部程序与真实 CLI 验证首次生成、复用、阶段依赖、失败阻断、预算拒绝和续算；检查执行次数及产物，不仅比较输入文本。
- 固定输出样本覆盖 Wannier 未收敛、版本不匹配、能量单位与参考、非有限值、缺失或截断矩阵数据，以及不相容网格和索引；拒绝错误数据的测试必须实际触发检查。
- MgB₂ 使用相同参数、程序版本和并行条件，与独立手动 EPW 参考流程对照插值电子能量、声子频率、α²F 和 λ；核验首次计算与重读结果一致。三种 PH 模式都覆盖；不要求不同基底或相位的原始矩阵元逐字节相同。
- 物理插值质量阈值与自动流程/手动参考的一致性容差分别定义，在详细 Spec 实施前固定，包括比较范围、单位、能带匹配和误差统计；失败后不得临时放宽。
- 各向异性数据通过独立最小 EPW 读取检查，不依赖尚未实现的 F4 编排才能完成本项接口验收；能隙和 Tc 的完整求解与对照由 F4–F5 承接。
- 使用 Epic 共用的真实试算上限：每作业最多 1 节点、64 MPI、2 小时，同时最多 2 个，累计 8 节点小时、运行数据 100 GiB。验证参考、额外验证点计算、失败与重试均计入；预算不足时记录未完成项，不声称真实验收通过。
