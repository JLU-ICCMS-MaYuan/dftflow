## 背景、目标与取舍

用户给定投影、能窗、粗细网格和展宽后，自动获得经过检查的 Wannier 表象、电子声子插值、α²F、λ，以及后续两种 Eliashberg 求解需要的数据。有效粗网格数据和细网格矩阵元可复用，修改温度不重新执行这些阶段。

本项分别检查两件事：插值相对独立 QE 参考的质量，以及自动流程相对独立手动 EPW 流程的一致性。两者使用不同容差，不能用“自动与手动都得到同一个差插值”证明质量合格。

首版采用目标版本可验证的共同细网格数据路径：准备可重读的细网格矩阵元及索引，再生成 α²F/λ；iso 消费谱函数，aniso 消费完整矩阵元集合。只选 iso 也可能需要这一公共准备步骤，资源按实际数据预留，不假设其没有矩阵元存储成本。

保持非磁性、无 SOC、给定 μ* 的常规模型范围。固定材料参数，不自动搜索投影、能窗、网格或展宽。程序打印的经验 Tc 估计不作为 F4 的 Eliashberg Tc 结果。

## 用户场景与验收

### US1：自动完成 Wannier 化并检查结果（P1）

**价值**：将经过验证的 QE 电子态和 PH 数据连接到 EPW，及时发现不合适的投影和能窗。

**独立验收**：真实 CLI 驱动模拟程序，核对正确参数、迭代收敛证据及产物；未收敛必须阻断后续。

1. 假如 F2 清单有效且投影、能窗相容，那么完成 Wannier 化并记录迭代与展宽泛函收敛证据。
2. 假如冻结窗包含的态数超过可用 Wannier 子空间，或外窗不足，那么报告具体点和设置，不自动改能窗。
3. 假如程序正常退出但达到迭代上限仍未收敛，那么不标记成功。

### US2：用独立参考判断插值质量（P1）

**价值**：避免将不可靠的插值传入超导计算。

**独立验收**：在已固定的粗网格内外验证点上，对比 QE 电子能量与 PH 频率，产生逐点误差和汇总。

1. 假如所需参考齐全且全部阈值满足，那么允许细网格数据交付。
2. 假如缺参考、能带匹配不完整或误差超限，那么输出原因并阻断下游。
3. 假如某条能带在目标能量范围内但没有对应 Wannier 态，那么不得通过删除该能带降低误差。

### US3：获得两种超导模式所需数据（P1）

**价值**：同一套有效插值数据支持 iso、aniso 或 both，无需用户手动改名搬运。

**独立验收**：验证 α²F、λ、细网格电子/声子数据、矩阵元及 k/q/能带索引，并实际重读。

1. 假如选择 iso，那么交付谱函数、单位和所选展宽身份。
2. 假如选择 aniso 或 both，那么除谱函数外还必须交付完整矩阵元及权重映射。
3. 假如只剩 α²F 或部分矩阵文件，那么不得标记各向异性数据可用。

### US4：复用数据并从失败处继续（P1）

**价值**：节约计算，同时避免参数变化后误用旧结果。

**独立验收**：用执行次数、文件指纹和跨进程恢复验证依赖失效规则。

1. 假如仅求解温度变化，那么继续复用有效 F3 数据，不重做 Wannier 化和细网格矩阵元。
2. 假如改变投影或能窗，那么旧 Wannier 与相关下游结果不得复用。
3. 假如只改变细网格，那么可导入仍相容的粗网格数据，但必须重新计算相关细网格结果。
4. 假如提交状态未知，那么保留记录，不重复提交。

### US5：直接使用命令并检查底层文件（P2）

**价值**：用户能独立执行、检查和复用本阶段，不依赖算例包装脚本。

**独立验收**：按文档从其他目录执行直接命令，定位一致，检查命令不启动科学程序。

### 边界与异常

覆盖无解纠缠和有解纠缠、投影数不符、排除带冲突、冻结窗不被外窗包含、缺验证参考、交叉/简并能带、极低频和虚频、错误单位、非有限值、空谱函数、矩阵元截断、并行布局不兼容、来源被修改、预算耗尽和存储不足。错误保留原始数据，不能悄悄调整物理输入使流程通过。

## 功能需求

### FR-001：直接 CLI 与阶段边界

沿用 F1/F2 的准备、执行和状态接口，增加以下边界：

| 命令 | 行为 |
| --- | --- |
| `epwflow check -c C` | 只读检查本阶段配置、已有清单及兼容性，不启动科学程序 |
| `epwflow prepare -c C` | 固定输入和阶段计划，不执行计算 |
| `epwflow submit -c C --until interpolation` | 自动安排必要前置、Wannier 化、质量验证、细网格与数据交付 |
| `epwflow run -c C --until interpolation` | 在已登记资源内完成到该边界 |
| `epwflow resume -w W -s 或 -r --until interpolation` | 使用固定快照续算；两种方式互斥 |
| `epwflow interpolation check -w W [--json]` | 只读核查已有产物、质量报告和交付清单，不启动新参考计算 |
| `epwflow interpolation import -c C --source M` | 验证来源清单，在新绑定中隔离复用有效阶段，不提交计算 |

C 为配置，W 为运行目录，M 为粗网格或完整 F3 来源清单。缺少参考时，check 报告缺项；实际生成参考只发生于明确的 run/submit/resume，且纳入预算。

`interpolation` 完成仅表示本项数据就绪。F4/F5 尚未接入时，不能把它当作完整超导工作流成功。

### FR-002：统一配置与明确的能量参考

在 F1 的版本化 TOML 中增加 `wannier`、`interpolation` 和 `interpolation.quality` 分组，复用 F2 粗网格与电子态身份，不建立第二套结构或赝势来源。

必要字段包括：

- `wannier.num_wann`、显式 `projections`、按 QE 原始能带 1 起始编号的 `exclude_bands`。
- 可选解纠缠外窗与冻结窗，均使用带 `_ev` 单位标识的上下界；冻结窗须包含于外窗。
- `wannier.energy_reference`：明确选择 QE 电子能量零点或相对绑定的 F2 Fermi 能；生成底层输入时记录实际换算值。
- 局域化及适用时解纠缠的迭代上限、收敛阈值和连续迭代窗口；阈值单位与对应泛函一致并在契约中标明。
- `interpolation.k_grid`、`q_grid`、电子展宽及类型、声子谱展宽、谱采样点数、`fsthick_ev`、声学低频截断 `eps_acoustic_cm1`。
- 明确的 Fermi 能来源：使用绑定值，或由指定细网格按固定电子数重新确定；不得无记录切换来源。前后差异进入报告。
- 质量检查的独立 k/q 点、目标能量区间、参考来源或生成计划，以及误差阈值。

窗口参考与插值对照参考分开记录。不同 Fermi 来源不得被分别平移到各自零点以掩盖误差；也不使用拟合出的额外平移。

拒绝未知字段、非有限值、非法窗口与网格。投影显式给出，不默认为随机投影或自动投影；必要的底层参数由受控适配器生成，不开放任意 wdata/namelist 文本绕过检查。

### FR-003：绑定 F2 数据与程序版本

进入本阶段前重新核对 F2 清单中的结构、赝势、电子态、q 映射、响应势与扰动模式身份。三种 PH 来源均使用同一契约，不因来源是 nosplit 而免检。

首个适配目标为指定 QE 7.4.1 配套 EPW，实际可执行身份和运行版本由 F1 证据确定。生成参数必须属于该版本；不能直接照搬新版 EPWpy 开关。

区分 Bloch 表象数据重读、Wannier 表象数据重读和重新 Wannier 化；不允许互相冲突的底层开关组合。格式或并行布局无法证明兼容时拒绝复用。

来源只读，运行在独立工作和保存目录。沿用默认 outdir `./tmp` 基址语义，check/prepare 展示派生实际路径。

### FR-004：Wannier 数值成功

在实际 k 点上检查排除能带后剩余态数、外窗可用态数、冻结态数与 num_wann 的相容性。投影展开后的数量必须与所求子空间匹配；不把投影字符串条数直接等同轨道数。

保存生成的 EPW 输入、Wannier 输入、完整日志、最终展宽、迭代次数和适用的旋转矩阵。解纠缠和局域化分别判定收敛；无需解纠缠的情况明确标为不适用。

成功须包括外部程序成功、所需数值迭代收敛及完整有限产物。只有最终状态、输出文件或固定次数迭代完成均不足以证明收敛。缺少可判定证据时报告未验证并阻断下游，不自动加大迭代上限或改变投影和能窗。

### FR-005：可复用的粗网格数据

生成与同一 Wannier 基底一致的电子、声子及电子声子数据，记录旋转/解纠缠变换、维度、索引、粗网格、原子顺序、版本和文件指纹。

目标版本完整必需文件集合在正式契约中逐项列出并用真实重读验证；不能仅凭一个 epwdata 文件存在就认定数据完整。首次生成、重读成功数据与未完成检查点分开登记；检查点不作为完成产物导出。

不要求不同 PH 模式的原始矩阵元逐字节相同；相位或基底差异必须通过一致映射和物理量验证，不能混用一套旋转矩阵与另一套矩阵元。

### FR-006：独立插值质量检查

质量参考必须来自实际 QE 电子计算与 PH 计算，或者来源完整且参数相容的已有结果。验证点和能量区间在计算前固定，不能根据误差结果删点或缩小能窗。

至少覆盖已有粗网格点和粗网格之外的独立点。MgB₂ 验收另含不少于 4 个不等价的粗 k 网格外点、2 个不等价的粗 q 网格外点，以及 Γ、一般 q 点和费米面附近相关能带；点列表与输入一起固定。额外参考使用有效 SCF 数据进行所需电子态/PH 计算，不额外默认重做 SCF。

对每个验证 k 点，在固定目标能量区间核对参考能带是否均可映射到 Wannier 子空间；使用固定的能量排序和简并组匹配规则，匹配不全视为失败。报告逐点误差、最大误差、均方根误差、覆盖率及能量对齐依据。

声子比较使用相同原子/质量和 ASR 约定，保留虚频符号，覆盖全部 3N 模。质量未通过或参考缺失时，阻断细网格数据交付及超导求解。允许生成诊断结果，不自动调参。

### FR-007：细网格与矩阵元交付

细 k/q 网格必须满足目标版本的均匀网格、映射和整除等要求；首版使用包含 Γ 的均匀网格，不接受随机网格或能带路径替代超导网格。

运行后核对实际网格、Fermi 窗口内的态、权重、能带/模式数、k+q 映射、矩阵记录和文件大小。窗口内无态、映射不完整、缺记录、截断或非有限值均拒绝。只检查输入网格合法不够。

共同准备的数据应支持目标版本的谱函数生成及各向异性重读。交付包括电子能量、声子频率、k/q 权重、能带和动量索引、矩阵元及必要格式元数据。实际文件集合和并行布局在适配契约中固定；重读不得悄悄重新生成缺失数据。

温度不进入温度无关矩阵元的身份。若某项数据实际依赖温度或其他求解设置，必须单独声明依赖，不能错误归入共同缓存。

### FR-008：α²F、λ 与低频处理

使用目标 EPW 支持的谱函数计算路径，从已验证细网格数据生成 α²F 和 λ。本阶段不运行温度相关能隙求解；目标程序附带打印的经验 Tc 仅保留在原始日志，不能写成已求得的 Eliashberg Tc。

统一交付的谱表以声子能量 meV 为横轴，记录原始单位和转换。每个展宽有独立身份，保留 α²F、累计积分耦合和总 λ；F4 使用配置明确选中的谱，不默选最后一列。λ 无量纲。

按目标版本实际离散求积规则复核 `2∫α²F(ω)/ω dω`，保留 λ_integral 与直接求和 λ_sum 的区别。二者可能受谱离散和展宽影响，不强行改值使其相等；报告差异，自动与手动对应量分别对照。

零频及声学截断遵循预先配置并记录的规则，不直接除零。原始虚频保留；首版常规超导交付若存在低于 −1 cm⁻¹ 的声子模式，则报告结构动力学不稳定并阻断交付。位于 [−1,0) cm⁻¹ 的微小负值必须单独列出，只能按已声明的低频排除规则处理，不取绝对值伪造正频。验收前固定声学截断，失败后不通过增大截断隐藏问题。

### FR-009：质量阈值与数值一致性容差

以下为本版提出的 MgB₂ 验收标准，确认后实施前固定。其他运行可在开始前显式设置质量阈值，但不能用于追认本次失败验收。

**A. 插值相对独立 QE/PH 参考的质量：**

| 项目 | 固定标准 |
| --- | --- |
| 电子能量 | 在预先固定的区间内，覆盖所选 Fermi 能左右至少各 0.5 eV，且包含全部实际 Fermi 窗口；最大绝对误差 ≤ 0.05 eV，均方根误差 ≤ 0.02 eV |
| 声子频率 | 在全部验证点、全部模式上，最大绝对误差 ≤ 50 cm⁻¹，均方根误差 ≤ 20 cm⁻¹（2026-10-19 用户最新变更；原 5、15 cm⁻¹ 的历史记录保留）；同时满足 FR-008 的虚频规则 |
| 覆盖率 | 所有规定点与目标态均有参考及有效匹配；不能靠忽略未匹配项通过 |
| Wannier 收敛 | 每个适用优化阶段满足输入中已固定的收敛阈值与连续迭代要求；未收敛即失败，不用较好的能带图替代 |

这些阈值只检验本工作流的插值适用性，不证明材料网格、展宽和物理参数已经收敛。

**B. 自动流程与独立手动 EPW、三种 PH 来源及首次/重读之间的一致性：**

| 项目 | 固定标准 |
| --- | --- |
| 插值电子能量、Fermi 能 | 相同点和能量参考，最大绝对差 ≤ 10⁻⁵ eV |
| 插值声子频率 | 同点、同 ASR，最大绝对差 ≤ 0.1 cm⁻¹ |
| α²F | 相同能量网格与展宽；归一化 L1 差 ≤ 10⁻³，最大点差除以参考峰值 ≤ 10⁻² |
| λ_integral、λ_sum | 对每个对应量，绝对差 ≤ 10⁻⁶ + 10⁻³ × 参考绝对值 |
| 从谱表复核其累计 λ | 使用相同离散规则；绝对差 ≤ 10⁻⁶ + 10⁻⁶ × 参考绝对值 |
| 索引、数量与文件身份 | 整数、必要集合和同一来源的内容身份精确一致；跨模式不要求矩阵元字节相同 |

α²F 的 L1 差定义为同一网格积分的 `∫|A−R| / ∫|R|`；参考非零时使用该式。参考全零时不得除零：要求样本绝对值均 ≤ 10⁻¹²（采用本契约谱函数归一化），并标明零耦合数据；MgB₂ 正向验收必须具有非零谱权重。

比较使用足够精度数据，先统一单位，不通过平滑、重采样、自由平移或选择有利子集降低误差。无法取得足够输出精度时标记该项无法验证，不声称更高精度通过。上述质量阈值与一致性容差不得混用，也不得在失败后临时放宽。

### FR-010：分阶段复用、失效与恢复

运行绑定不可静默改变。配置发生变化时建立新运行，再显式导入相容阶段；原始配置和历史结果保留。

| 变化 | 必须重新验证或计算的范围 |
| --- | --- |
| 结构、赝势、粗网格或相关电子态 | 受影响的 F2、Wannier 和全部相关下游 |
| 投影、排除带、能窗、num_wann | Wannier 与相关质量检查、细网格和求解数据 |
| 细网格、Fermi 窗口、Fermi 来源、电子展宽 | 相关细网格及谱函数/求解数据；相容的粗网格可复用 |
| 谱展宽或谱采样 | 重新生成受影响谱及检查；只有证明细网格原始数据不依赖该项时才复用 |
| 验证点或质量标准 | 重新取得必要参考并判定质量；不能沿用旧报告冒充新检查 |
| 仅温度或 μ* | 复用已验证的温度无关、μ* 无关数据；F4 重新绑定和处理求解依赖 |

导入前核对全部必需文件、版本、输入指纹和布局兼容性。缺文件或检查点不能作为完整缓存。正常恢复跳过仍有效的完成项，显式重试失败项；活动或未知任务不重复提交。

### FR-014：QE 与插值的共同参考数据

为 [0014 叠图交付](../0014-epwflow-delivery/spec.md) 提供电子能带、声子色散及总量和元素／轨道分辨 DOS 的成对数据，作为 epwflow 插值阶段的一部分。路径和 DOS 均匀网格分别配置、计算前固定；不得将少量离散质量点连成完整高对称路径，也不得把能带路径当作 DOS 采样网格。

电子能带参考来自 QE 直接电子态计算；两侧使用同一实际 k 点路径、倒格子距离和绑定的 Fermi 能零点。采用用户确认的共同有效能窗，至少覆盖 Fermi 能上下各 0.5 eV 及全部实际 Fermi 窗口；检查能窗及展宽所需边界态覆盖。覆盖不足时报告不能比较，不自动扩大 Wannier 子空间，也不将局部子空间 DOS 标为完整总 DOS。

声子连续参考采用已有有效 PH 网格经 QE q2r/matdyn 产生的曲线，另提供独立 ph.x 直接计算点；清单分别标记 qe_matdyn 与 qe_ph_direct，前者不能充当网格外直接参考。两侧使用相同 q 路径、晶胞、原子质量和 ASR 约定，保留虚频符号。原 FR-006 的独立点覆盖与 FR-009 数值门保持不变。

电子 DOS 的 QE 参考来自均匀网格电子态及 dos/projwfc 后处理，声子 DOS 的 QE 参考来自 q2r/matdyn。两侧使用相同积分网格、权重、展宽核与宽度、输出采样轴和每计算晶胞归一化；使用独立数据源计算，不把一侧曲线复制为另一侧。配置差异、缺失参考、单位不明或身份不匹配均须拒绝比较。

### FR-015：可核查的元素／轨道 DOS 与诊断交付

电子侧交付总 DOS、按元素汇总的 PDOS，以及已确认的轨道分辨 PDOS；两侧必须对应同一原子投影定义、原子顺序、能带与轨道映射。键中心 Wannier 函数或对若干 Wannier 函数的投影不能直接标为 Mg/B 原子 PDOS。投影不完备程度单独报告，不强行缩放元素 PDOS 使其等于总 DOS。缺少可靠映射时该项保持不可用，不用总 DOS 替代。

声子侧从质量加权动力学矩阵的归一本征矢获得原子振动权重，再按元素求和。必须区分模式分辨与元素分辨；EPW 5.9 的 phdos_proj 不能直接作为元素分辨数据。逐点元素贡献之和应等于总声子 DOS，全频积分核对 3N，并记录频率范围、虚频、低频规则及有限展宽尾部；不能用截断后的积分冒充完整归一。

规范化数据同时保存原始单位、共同采样轴、参考类别、投影定义、参数与文件指纹，以及成对数值差异和适用状态。质量失败仍可向 0014 交付标明失败原因的诊断数据；其数据可绘制不等于插值质量通过，不发布可供 F4 使用的成功标记，不绕过细网格 EPC／超导的质量门。额外参考和纯插值诊断仍共用原预算，不授权自动调参。
