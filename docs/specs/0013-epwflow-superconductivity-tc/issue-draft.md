## 目标与用户价值

用户一次启动后，可获得各向同性、各向异性或两者的 EPW 超导求解结果，查看逐温度能隙及收敛状态，并在给定温度范围、精度和次数上限内自动定位 Tc。搜索无法完成时保留已验证结果，明确原因和现有界限；不能以未收敛、空文件或过小初始能隙推断正常态。

## 事实与参考边界

参考 `external/epwpy` 固定提交 `b54bb53d4f5de665ed08958cb6194be8efdf645d` 的求解输入与结果解析，使用 Rust 编排实际 EPW 求解器。目标 QE 7.4.1 配套源码声明 EPW 5.9，实际可执行版本仍由 F1 核验。

该版本 `EPW/src/supercond_driver.f90` 在各向同性虚频轴模式下区分线性化 Tc 求解和非线性能隙求解；各向异性使用其非线性虚频轴求解器，不能把各向同性的线性接口直接套用。`supercond_iso.f90` 在达到迭代上限但未收敛时仍可能写出能隙文件，因此文件存在、程序正常结束都不足以证明数值有效。具体求解方法、日志语法与判据在详细 Spec 中固定并验证。

## 本次范围

1. **两种求解与数据绑定**：消费 F3 通过检查的数据，支持单独选择各向同性、各向异性或同时运行两者。固定 μ*、频率截断、网格、展宽及其他物理参数；按模式核对 α²F 或矩阵元数据、单位、版本及指纹。首版沿用非磁性、无 SOC、常规费米面附近模型，超出范围明确拒绝。
2. **逐温度数值校验**：为每个模式和实际温度记录输入、输出、迭代次数、残差、收敛结论、作业及来源。核对要求的温度确实计算、输出完整且有限；区分程序失败、求解未收敛、无法判定和有效结果。能隙文件不得从其他温度或历史失败作业误取，多个温度输出不能只检查最后一行。
3. **能隙结果语义**：保留各向异性结果的能带、动量和权重映射及必要频率信息，提供可复核的统计与逐温度数值，不能只交付一个平均值。明确虚频轴能隙、实频轴延拓结果及能隙边缘的定义和单位，不能将最低 Matsubara 频率上的值无标注地当作实频能隙。具体首版输出量和必要求解步骤在 Spec 中约定。
4. **受限 Tc 搜索**：检查温度范围、目标温度精度和求解次数上限；在范围内选择温度点，建立有效的转变区间，再按已验证判据细化。两种模式分别保留搜索状态，不要求二者 Tc 相同。只调整温度，不自动改变 μ*、网格、展宽、投影或能窗；不越界扩展温度范围。
5. **可靠判定与停止条件**：将求解收敛阈值、正常态/超导态判据和 Tc 温度精度分开。针对小初值、近转变慢收敛、各向异性多能隙及符号抵消设计检查，不能用带符号平均能隙接近零证明全部能隙消失。未收敛或证据不足的温度不参与区间更新；出现矛盾或非单调判定时停止自动推断并报告。只有有效区间达到精度才报告已定位的 Tc，并同时保留区间、判据和方法；否则分别报告范围内未夹住转变、次数耗尽、资源受限或求解失败。
6. **动态调度与共享预算**：接入 F1 的原生 Slurm 提交、状态、并发与预算账本。后继温度由已验证结果驱动，一次入口无需人工逐次提交，不占计算节点轮询等待。初始温度、追加温度、判定复核和失败重试均受已声明次数约束及 Epic 资源上限控制；提交前预留，部分提交失败保留已有记录，禁止无限重试或另开预算。
7. **恢复与幂等**：按模式、温度、求解设置和 F3 数据来源标识计算；重复启动检查活动任务并跳过有效完成项。中断后恢复温度记录、有效区间和预算，既有任务不能重复计入或漏计预算；未知调度状态不视为可重新提交。重启文件仅在明确兼容时使用，不能将正常态零解无检查地用于低温求解；与温度无关的有效 Wannier/矩阵元继续复用。
8. **结果交付与直接命令**：输出供 F5 使用的结构化逐温度数据、Tc 区间/估计及状态、停止理由、收敛证据和来源。有效部分结果保留；选择两种模式而仅一种成功时，不将整个需求标记成功。说明直接 epwflow 求解、状态和续算命令及底层输入输出，具体 CLI 与文件格式在 Spec 中确定。

## 用户场景与验收

| 场景 | 必须得到的结果 |
| --- | --- |
| 有效 F3 数据分别运行各向同性、各向异性及两者 | 产生对应模式的有效能隙数据和独立 Tc 搜索记录，不混用状态或文件 |
| 范围覆盖转变且预算充足 | 自动选点、建立有效区间并细化至预设温度精度，保留端点证据 |
| 全部有效温度均在同一状态，未夹住转变 | 报告未定位及可支持的界限，不外推一个精确 Tc，也不擅自扩范围 |
| 能隙文件存在但迭代未收敛，或缺少某个温度 | 判定无效并阻断受影响搜索，不将其作为正常态端点 |
| 初值过小、零解重启、平均值抵消或分类相互矛盾 | 按预定检查拒绝错误分类，必要复核计入次数和预算；不能验证则报告无法判定 |
| 次数、节点小时或存储额度耗尽 | 停止追加，保留区间与已计算数据，明确结果未达到目标精度 |
| 提交中断、重复启动或恢复已有任务 | 不重复提交有效/活动温度，不重跑有效矩阵元，预算账本保持一致 |
| 两种模式中一种失败，或求解参数/来源改变 | 分别报告状态，拒绝不兼容复用；整体不冒充全部完成 |

## 验证与关闭标准

- 用模拟 EPW/Slurm 和真实 CLI 验证完整温度调度、两模式独立状态、精度/范围/次数限制、预算预留、提交失败、未知状态及跨进程续算；不只单测数学搜索函数。
- 解析测试覆盖正常结束但未收敛、日志中否定的收敛信息、缺失温度、截断文件、重复/冲突记录、非有限数、单位换算及各向异性映射。温度文件名的舍入不得导致不同温度共用结果。
- 搜索测试覆盖已知转变、范围外转变、边界温度、近阈值不确定、非单调/矛盾分类、小初值及零解重启；未收敛不能改变有效区间，达到上限后不能继续提交。
- MgB₂ 两种求解均与独立手动 EPW 参考在相同输入、版本、并行条件和温度点下比较能隙与 Tc 区间；在转变附近使用独立温度点复核判据。F2/F3 三种 PH 来源的最终端到端对照由 F5 汇总，不以某一种来源的成功代替全部覆盖。
- 在详细 Spec 实施前固定能隙误差、温度精度、收敛/分类判据、复核规则和 Tc 对照标准，区分数值搜索精度与物理预测精度；失败后不得放宽。小网格验收不代表材料参数收敛或与实验相符。
- 本项所有真实求解、参考、复核与失败重试共用 Epic 预算：每作业最多 1 节点、64 MPI、2 小时，同时最多 2 个，累计 8 节点小时、运行数据 100 GiB。预算不足时真实验收保持未完成，不以模拟通过替代。
