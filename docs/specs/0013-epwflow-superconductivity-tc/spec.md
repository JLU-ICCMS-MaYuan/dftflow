## 背景、目标与取舍

从 F3 已验证数据一次启动所选超导模式，得到逐温度的收敛证据、能隙数据，以及给定范围内可验证的 Tc 区间。两种模式分别计算和记录，不要求 Tc 相同。

首版必需输出采用虚频轴 Eliashberg 能隙 Δ(iωₙ,T) 与重整化函数 Z(iωₙ,T)。各向异性保留能带和动量索引；最低正 Matsubara 频率上的能隙用于温度曲线，并明确标注。实频轴求解、解析延拓与实频能隙边缘不纳入首版必需交付，不能把虚频轴数据标成隧穿谱能隙。

各向同性 Tc 采用目标 EPW 的线性化判据，另用非线性求解获得配置温度点的能隙；各向异性 Tc 采用经过收敛和双初值复核的非线性结果。后者给出的是声明阈值下的数值转变区间，不能隐去判据后宣称无限精度的热力学 Tc。

资源或判据不足时保留有效部分结果，明确未定位原因。未收敛、零文件、平均能隙抵消、过小初值都不能作为正常态证据。

## 用户场景与验收

### US1：计算两种模式的有效能隙（P1）

**价值**：用户可选择 iso、aniso 或 both，并检查每个温度实际求解了什么。

**独立验收**：真实 CLI 驱动模拟 EPW，检查温度、模式、收敛状态和完整能隙数组。

1. 假如所需 F3 数据完整，那么每个温度绑定正确来源并产生对应模式的结果。
2. 假如日志明确未收敛，即使存在能隙文件，也不得标记数值有效。
3. 假如 both 中只有一种成功，那么保留该结果，同时报告整体未完成。

### US2：在限定范围内自动定位 Tc（P1）

**价值**：一次提交后由有效结果决定后续温度，无需人工补交。

**独立验收**：已知转变的模拟数据自动建立区间、细化到精度，并停止追加。

1. 假如两端状态有效且夹住转变，那么在范围内继续选点并更新区间。
2. 假如某点状态无法判断，那么不能把它当作任何一侧的端点。
3. 假如没有夹住转变，那么报告未定位及已知证据，不外推精确 Tc。

### US3：识别初值、临界点与多能隙陷阱（P1）

**价值**：避免得到貌似完整但物理含义错误的 Tc。

**独立验收**：覆盖小初值、符号抵消、近临界未收敛、双初值矛盾及不完整动量映射。

1. 假如各向异性平均值接近零但某些态能隙仍非零，那么不能判定正常态。
2. 假如两份独立非零初值给出不相容结果，那么报告判据不确定，不任选有利结果。
3. 假如低温使用来自正常态的零解，那么不允许该结果未经复核参与分类。

### US4：在次数与资源上限内恢复（P1）

**价值**：中断或重启不会清零预算，也不会重复计算有效温度。

**独立验收**：跨进程恢复与并发入口验证温度身份、活动作业、计数和账本一致。

1. 假如相同温度与尝试已活动，那么返回原任务，不再提交。
2. 假如次数或节点时间不足，那么停止追加并保存已确认区间。
3. 假如来源或求解参数改变，那么不得复用旧温度记录。

### US5：理解结果和未完成原因（P2）

**价值**：用户能区分能隙收敛、Tc 已定位、范围不足和资源受限。

**独立验收**：直接命令和结构化结果中状态、单位、方法与输入输出一致；无结果不填零。

### 边界与异常

覆盖 T≤0、温度精度不可表示、极低温频率网格导致资源超限、重复温度、不同温度文件名碰撞、缺频率或能带/动量记录、非有限残差、正常结束但未收敛、Tc 位于边界或范围外、分类非单调、求解次数耗尽、提交响应丢失、未知作业和损坏状态。保留原始输出，不通过自动改参数修饰失败。

## 功能需求

### FR-001：公开命令与阶段边界

沿用统一入口并提供 superconductivity 边界：

| 命令 | 行为 |
| --- | --- |
| `epwflow check -c C` | 只读检查超导配置、输入来源和资源约束 |
| `epwflow prepare -c C` | 固定配置、温度计划及搜索规则，不启动求解 |
| `epwflow submit -c C --until superconductivity` | 自动安排必要前置、所选模式求解与受限搜索 |
| `epwflow run -c C --until superconductivity` | 在已登记资源内顺序运行，不申请额外资源 |
| `epwflow resume -w W -s 或 -r --until superconductivity` | 使用固定快照和既有计数恢复；执行方式互斥 |
| `epwflow superconductivity check -w W [--json]` | 只读检查温度产物、收敛与搜索记录，不追加温度 |
| `epwflow status -w W [--refresh] [--json]` | 沿用 F1 的状态语义；刷新不提交任务 |

本项边界完成不等于 F5 图表、安装和全部真实对照完成。完整 submit 在所有阶段接入后才贯通全部链路，不能把缺失阶段静默省略。

### FR-002：固定求解配置

在同一 TOML 契约中定义 `superconductivity` 及其 `iso`、`aniso`、`tc` 配置，包含：

- 显式 `mode = iso|aniso|both`、给定 μ*、虚频轴频率截断 `frequency_cutoff_ev`。
- 非线性迭代上限、目标版本的相对收敛阈值、混合参数和混合历史长度。
- 两个正的、不同的初始能隙幅度 `initial_gaps_mev`，以及适用时固定的初值频率形状。
- 明确的 `gap_temperatures_k`，用于所需能隙曲线；不依据经验 Tc 公式静默决定全部采样。
- 每种模式的 Tc 搜索下限、上限、目标区间宽度、求解次数上限及分类阈值。
- 对应 F3 谱展宽/数据身份；both 不允许混用未经声明的不同物理输入。

每个求解温度必须处于声明范围内。首个目标版本按 0.01 K 的整数刻度管理实际温度：不接受不可表示温度或低于该分辨率的精度要求，不静默舍入用户输入。输出适配器还须检查目标版本可可靠表达的温度范围。

频率截断、μ*、网格、展宽、Wannier 数据、混合参数及初值规则在搜索开始前固定；温度改变可按固定截断派生新的 Matsubara 点数，不能把这种必要变化误认成自动物理参数扫描。

禁止自动改变材料参数、放宽收敛阈值或延长迭代上限。要求实频轴等首版未支持输出时明确报错。

### FR-003：一次尝试只处理一个模式和一个温度

每次外部求解绑定一个模式、一个实际温度、一个任务类型（线性判据、非线性能隙或复核）及初值身份，具有独立工作目录和尝试号。底层 nstemp/temps 必须与该绑定一致。

独立目录避免底层舍入文件名覆盖结果；不得仅从文件名猜测实际温度。联合核对固定输入、实际温度日志、频率网格及文件身份，无法确定时拒绝结果。

生产搜索首版不跨温度直接复用能隙重启文件。失败续算可重新从固定非零初值执行；温度无关的有效 F3 数据继续复用。以后如需跨温度热启动，须单独验证其兼容性和零解风险，不能偷偷改变本版规则。

### FR-004：逐温度数值成功

非线性结果必须同时满足：外部程序正常结束；目标温度对应的求解明确收敛；最终有限残差满足输入阈值；全部必需数组、频率、索引和单位可校验。

解析必须区分“Convergence was reached”和“Convergence was not reached”，并按当前尝试、模式和温度关联；不得用全文模糊匹配或最后一行代替检查。

迭代上限、非有限残差、缺频率或模式数据、日志/产物冲突均判为无效。没有输出的残差不能编造：线性 LAPACK 路径使用其明确的求解器成功/错误和完整本征值输出证据，标明其未提供非线性残差。

程序成功、求解收敛与温度分类分别记录。底层认为收敛也不能跳过完整能隙分布和初值复核；未收敛结果不得用于 Tc 区间更新。

### FR-005：能隙与重整化函数的含义

保留全部已计算 Matsubara 频率上的 Δ 和 Z，统一能量为 meV、温度为 K，Z 无量纲。记录最低正频率及其索引，不能固定假定原始文件任意第一行就是所需频率。

iso 输出逐频率 Δ、Z 及最低正频率能隙。aniso 输出对应能带、k 点、能量、权重及逐频率 Δ、Z，并给出最低正频率上的带分辨统计、带符号均值、绝对值均值、均方根、最小/最大绝对值。

权重沿用 F3 的物理定义并记录归一化；不能把所有点等权平均冒充费米面平均。保留原始符号和索引，不按能隙大小重新排序后冒充能带映射。

图表交付须使用“最低正 Matsubara 频率能隙”等准确名称。未求解温度或无有效能隙时使用缺失值和状态，不能填零补出曲线。

### FR-006：各向同性 Tc 判据

使用目标 EPW 已有的各向同性线性化求解，首版采用经运行验证的 LAPACK 路径，读取最大本征值 ρ(T)。该量与 EPC 耦合常数 λ 分开命名。

对有效结果，ρ>1+ερ 记为线性判据的超导侧，ρ<1−ερ 记为正常侧，落在中间带内则暂不分类。ερ 必须大于输出舍入噪声；不能把打印为 1 的数当作精确根。

线性判据不生成非线性能隙曲线。对配置中的能隙温度，以及最终区间超导侧端点，单独运行非线性求解并复核。若正常侧温度没有非线性有效解，记录其线性状态与“能隙未获得”，不填伪造零值。

线性分类和同温度有效非线性结果矛盾时，停止该模式的最终成功判定，报告需要检查的证据。不得以经验 Tc 代替线性或非线性结果。

### FR-007：各向异性分类与双初值复核

使用目标版本的非线性虚频轴求解，不构造未经验证的各向异性线性接口。

每个参与分类的温度，必须从两份预先固定、不同的正非零幅度独立启动并得到有效收敛结果。两次均计入求解次数与预算。

定义 D∞ 为所有有效能带、动量及已计算 Matsubara 频率上的最大 |Δ|，D₀∞ 为最低正频率上的最大 |Δ|：

- 两次有效结果均满足 D∞≤δN，且分布一致，才可记为阈值意义下的正常侧。
- 两次均满足 D₀∞≥δS，且分布一致，才可记为超导侧。
- δN<δS；中间区、初值结果不一致、缺状态或任何一次未收敛，均不能分类为正常侧。

分布比较须匹配全部状态；只允许处理整个解的统一符号选择，不能逐点改符号消除差异。不能用带符号平均能隙消失证明所有能隙消失。

iso 的必需非线性能隙同样进行双初值复核。首版不自动尝试第三、第四组初值；无法判定就保留原因与数据，避免无限复核。

目标版本的相对残差在能隙趋零时可能难以满足。本项必须通过真实正常侧与临界附近验收；如果程序无法给出所需可靠证据，则明确报告该搜索未完成，不把未收敛小数值改称正常态，也不静默修改科学求解器。

### FR-008：有界温度搜索

每种模式维护独立搜索状态。先计算上下端点；存在已验证且来源一致的温度记录时可复用。只有低温为超导侧、高温为正常侧时建立有效区间。

正常细化取区间内的中点，转换为可表示的温度刻度，禁止重复相同点。有效分类才可替换对应端点。若有效求解落入分类不确定带，可依固定顺序尝试当前区间的四分之一和四分之三位置，仍受次数与预算限制；不能用不确定点直接缩区间。没有可用新点或仍无法推进时停止并报告判据受限。

求解失败或未收敛时停止受影响模式的自动搜索，保留有效区间；显式 resume 可在原规则和剩余额度内重试。未知调度状态先核对，不能自动重试。

检查全部有效分类的温度顺序；出现低温正常而更高温超导等矛盾时停止自动推断。单转变假设是首版搜索适用条件，不能靠删除矛盾点维持单调。

仅有效区间宽度≤目标精度时标记 located，输出两端、区间中点及半宽，并附方法和阈值。中点是区间估计，不是额外求解出的精确临界温度。

两端同侧时报告 not_bracketed；任何 Tc 上下界推断须注明单转变假设，原始结论首先是“已采样温度处于哪一侧”。不扩大输入温度范围，不从经验公式外推。

### FR-009：次数、调度与资源预算

每个运行、每种模式有明确的 `max_solves`；一次外部求解尝试算一次，线性判据、非线性初值、复核和失败重试全部计入。单个温度可能消耗多次求解，不能把 max_solves 解释为温度数。

提交前同时预留次数和 F1 资源；未决提交保留预留。已实际启动的失败尝试仍计数，明确未被调度器接受的提交可按持久证据撤销预留；未知状态不能退款。续算不清零。

独立手动参考单独登记尝试与其上限，参考、全部模式和三种 PH 来源共同使用 Epic 的资源账本；不能换目录重置 8 节点小时额度。

仍遵守每作业最多 1 节点、64 MPI、2 小时，同时最多 2 个运行作业，以及累计 100 GiB。后继温度由已验证结果触发，更新状态和预算后受控提交；不占计算节点轮询等待。两个模式可以独立推进，但共用并发上限和预算。

资源内 run 使用已登记分配并受剩余时间限制；不足以安全开始下一尝试时保留状态退出，不自动申请新资源。不存在无界重试、后台服务或额外预算。

### FR-010：恢复、来源与结果身份

结果身份绑定模式、实际温度、任务类型、初值、μ*、截断、数值设置、F3 来源及程序身份。温度刻度和唯一尝试号共同定位目录，不使用浮点格式化文件名作为唯一身份。

有效完成项经复核后跳过；活动项不重提；确认失败项只有显式恢复且额度足够时才重试。预算、求解计数、有效区间及活动任务跨进程保留。

### FR-011：状态与输出交付

逐温度记录至少区分：未执行、活动、执行失败、数值未收敛、数据无效、分类不确定、有效超导侧、有效正常侧。数值收敛与温度分类字段分别保存。

每种搜索状态至少包括：pending、running、located、not_bracketed、classification_uncertain、inconsistent、solver_failed、attempt_limit、resource_limit、scheduler_unknown。保存停止理由、已知区间及端点证据，不用一个布尔值压缩所有结果。

结果目录至少提供：

- `superconductivity/iso/`、`superconductivity/aniso/` 下各尝试的 epw.in、epw.out 与原始产物。
- `superconductivity/temperatures.csv`：模式、实际温度、任务类型、能隙统计、收敛/分类及来源。
- `superconductivity/gaps/`：完整频率与各向异性状态映射数据。
- `superconductivity/tc.json`：格式版本、两模式方法、阈值、区间、估计、状态和停止原因。

### FR-012：预先固定的数值与判定标准

以下为本版提出的真实 MgB₂ 验收规则，确认后实施前固定；材料参数和温度范围在首批计算前固化，不根据结果临时调参。

| 项目 | 固定标准 |
| --- | --- |
| 非线性收敛 | 目标 EPW 明确收敛，有限的原生相对残差 < 10⁻⁸；迭代上限预设为 1000，不在失败后自动增加 |
| 双初值 | 幅度固定为 1 meV、10 meV；其频率形状、混合参数预先固定，独立启动 |
| 各向同性本征值分类余量 | ερ = 10⁻⁶，读取目标版本实际输出精度；无法可靠区分时保持不确定 |
| 各向异性正常侧阈值 | δN = 10⁻⁴ meV，作用于完整 D∞ |
| 各向异性超导侧阈值 | δS = 10⁻³ meV，作用于 D₀∞；两阈值之间不强行分类 |
| 双初值分布一致性 | 匹配并至多统一翻转整体符号后，各 Δ 元素差 ≤ 10⁻⁴ meV + 10⁻³ × 对应幅值较大者；Z 差 ≤ 10⁻⁵ + 10⁻³ × 对应绝对值较大者 |
| Tc 区间宽度 | ≤ 0.5 K；保留端点与方法，不把该宽度当作材料预测误差 |
| 自动与手动能隙 | 同温度、状态、频率与输入，逐元素差 ≤ 10⁻⁴ meV + 10⁻³ × 参考绝对值；Z 使用上面的绝对/相对标准 |
| 自动与手动线性本征值 | 同温度最大本征值绝对差 ≤ 10⁻⁶ |
| 自动与手动 Tc | 各自有效区间宽度均 ≤ 0.5 K，区间有交集且中点差 ≤ 0.5 K；所有共同验证温度的分类一致 |

验收每种模式预留最多 64 次生产求解尝试；这只是次数上限，不保证资源账本允许全部运行。独立参考另有明确登记的尝试上限，但不能增加 Epic 资源额度。至少检查 3 个预先指定的有效超导态能隙温度；若原定范围无法提供这些点，验收记录不足，不能事后冒充原计划已覆盖。

手动参考在最终区间之外、仍位于原输入范围内的邻近温度独立复核两侧判据；复核点不得只复制自动流程已有端点。若边界没有可用复核点，或无法得到可靠正常侧，真实验收保持未完成。

各向异性不得仅比较平均能隙，须覆盖全部必需状态及相关频率；存在整体符号自由度时记录统一处理方法，保留原始值。不能逐点改符号、重排状态或忽略不匹配数据。

这些标准验证实现与独立参考的一致性，不证明网格、展宽、频率截断或 μ* 的材料收敛，更不要求小网格 Tc 接近实验值。失败后不得放宽上述标准或改用经验公式代替。
