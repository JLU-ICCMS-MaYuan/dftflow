## 目标与用户价值

用户通过已安装的直接 epwflow 命令一次启动完整流程，得到可核查的 α²F、λ、能隙和 Tc 数据及图表，并能依照手册复现或续算。交付须有 MgB₂ 三种 PH 模式、两种超导求解的独立数值对照，以及实际安装入口证据，不能只凭模拟测试或生成图片宣布完整工作流完成。

## 本次范围

1. **完整结果归集**：消费 F2–F4 的校验结果与来源，输出机器可读表格和摘要，覆盖 α²F、λ、逐温度能隙、Tc 区间/估计、收敛状态及停止理由。明确单位、模式、网格、μ*、程序版本、输入指纹与数据来源；无结果不得填零冒充数值，部分成功与完整成功分开。
2. **Rust 绘图与独立重绘**：生成 α²F/耦合结果、各向同性能隙随温度变化、各向异性带/动量相关能隙分布及 Tc 区间所需的独立图和汇总图。保留可检查的数据表，注明能隙定义、单位和状态；不通过平滑、插值或隐藏失败点制造收敛与转变。支持从有效已有结果重绘，不重跑 QE/EPW，不修改原始计算数据；具体图种、格式和文件名在 Spec 中确定。
3. **直接 CLI 与手册**：列明检查环境、准备、资源内运行、一次提交、状态、续算、结果收集和重绘的真实命令；解释三种 PH 模式、两种超导模式、初始化输入输出、均匀电子态、数据复用及温度搜索。区分主节点提交入口与内部 Slurm 脚本，不只提供 prepare.sh 包装。默认 outdir 为 ./tmp，显式配置和跨工作目录行为与前序契约一致。
4. **算例组织**：在 examples/MgB2/sugon-amd 下准备独立 EPW 算例，与原声子目录隔离；nosplit/index/coords 及求解模式的结果可区分，保留历史计算。使用用户指定 QE 7.4.1 配套 EPW，实际运行版本经验证后记录；inspur、chem 仅提供待填写配置说明，不臆造机器参数或宣称实测。机器路径、运行日志和新增算例内容遵守已有忽略规则，不强制纳入 Git。
5. **独立真实对照**：在 sugon-amd 以相同结构、赝势、物理参数、程序版本和并行条件，对三种 PH 模式与两种求解的组合逐项核对 α²F、λ、能隙及 Tc。手动参考独立准备、运行和核查，不能把 epwflow 自己生成的期望结果当作唯一基准；参考输入和输出另存并记录哈希。只在来源相容且证据充分时复用已有参考，不为表面覆盖无意义地重复计算。
6. **可复查验收证据**：记录提交作业号、阶段执行次数、一次 SCF、输入与制品哈希、数值差异、图表检查和预算消耗。核验一次入口完成、失败阻断、重复提交与续算；危险或昂贵的失败注入优先用模拟验证，真实数值对照不能被模拟替代。各项明确通过、失败或未完成，不将声子谱验收替代 EPW 验收。
7. **固定路径安装与兼容**：将 epwflow 纳入平台构建、运行库打包、固定 current 安装和入口验证；Linux x86_64 与 macOS arm64 配置继续分离，不混用制品。覆盖前验证所有待交付入口，在无活动计算链时更新，核对安装后实际执行文件与受测制品一致；不默认创建历史版本或备份，不保证多个程序同时原子切换。安装失败须如实报告实际状态，旧有 CLI 和独立工具保持兼容；未实测平台明确标注。
8. **整体收尾**：全部必需输出、数值标准、入口及手册验证通过后，回写当前功能 Overview 和各 Feature 验收，再检查 Epic 覆盖。预算、队列或环境阻塞时保留现场和未完成项，不将部分交付标成 Epic 完成；线上 Issue 仍由用户管理，不自动推送。

## 验证与关闭标准

- 使用模拟 QE/EPW/Slurm 与实际 CLI 覆盖从入口到结果的依赖、一次 SCF、两模式求解、受限搜索、失败恢复和幂等；前序测试证据可按源码与契约版本复用，不只汇总通过数量。
- 表格与固定参考数值核对；单位和能隙定义一致；图像能实际打开，坐标轴、图例、各向异性信息及失败/未定位标识可读。重绘验证原始数据哈希不变且未调用外部求解器。
- 真实 MgB₂ 验收覆盖三种 PH 模式 × 两种超导模式；在详细 Spec 实施前固定各比较量、匹配规则、误差统计及容差，与 F2–F4 一致。对照不要求原始矩阵元字节相同，也不以实验 Tc 作为小网格工作流正确性的标准。
- 隔离安装测试覆盖新增入口、全部既有入口、重复覆盖、源文件缺失和启动失败保护；目标登录及计算节点检查实际制品和运行环境，验证无 EPWpy 运行依赖。实际机器路径及哈希仅存本地忽略目录。
- 真实计算、独立参考、安装所需计算节点验证和失败重试共同计入 Epic 上限：每作业最多 1 节点、64 MPI、2 小时，同时最多 2 个，累计 8 节点小时、运行数据 100 GiB；前序已消耗预算不重置。额度不足不自动扩大或删数据腾挪，真实验收保持未完成。
- 直接命令快速入门、输出说明、预算/失败/续算说明及当前功能文档完整；所有必要标准满足才完成 F5 与 Epic。文档确认不等于实现或验收完成。
