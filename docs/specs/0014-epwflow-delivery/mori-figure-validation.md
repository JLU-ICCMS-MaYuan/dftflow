# Mori 风格虚轴能隙分布

本记录落实已有 F5 原生 aniso 分布图，不新增 Feature，不改变 μ* 或科学门。材料为用户指定的 `Wed.9.Mori.pdf` 第 25 页图 8：展示随温度变化的最低正 Matsubara 能隙分布。讲义示例 μ*=0.05 与引用文献 μ*=0.16 应区分，不能把文献曲线或 Tc 作为本次计算输出。

## 已实现的数据与图形约定

- 从原生结果包 `gap_states.csv` 读取最低正 Matsubara 的逐态 Δ、真实 k／带索引和物理费米面权重；完整频率数组继续归 F4 所有。
- 只绘制通过双初值分类的温度，排除失败、不确定与未分类温度。同一固定初值的数据仅取一次，不把两套相同物理态相加。
- 横轴为温度 K，纵轴为 |Δ_nk(iω₀)| meV；按 0.05 meV 固定宽度归箱，每温度的箱权重归一化为 1，以蓝色水平宽度表示。使用原权重，不平滑、不插值额外温度、不补造临界点。
- 图中显示实际 μ*、箱宽与权重说明。未取得可靠轨道归属时不把带编号命名为 σ／π；没有有效双初值时明确标缺数据。
- 沿用原生六类图的 PNG／SVG／PDF 交付、清单身份和空 PATH 独立重绘，不引入第二套科学计算程序。

## 验证与限制

数值回归使用明确标注的合成状态，验证非均匀费米面权重、整体符号翻转不变、双初值不重复计数、正常态零能隙箱、不确定／失败温度排除，以及重复物理态、非法权重和非有限值拒绝。已有两模式进程回归继续检查三格式、移动重绘与来源哈希，并核验新分布轴和说明。

2026-10-19 最终 `epwflow` 全回归为 **111 通过、0 失败、6 项真实测试显式忽略**。新分布两项数值契约通过；完整两模式进程样本在空 PATH 下生成三格式，并实际查看 PNG、SVG 与 PDF 的栅格化结果，轴、蓝色分布及说明一致。样本和完整日志只存 `docs/local/0015-native-closeout/`，其数值与 μ* 明确属于测试样本，不能当作 MgB₂ 结果。调度启动等待、超时、未知身份与终态拒绝也通过回归。
