## 背景、目标与取舍

交付用户能直接运行的 epwflow：一次入口自动完成所需科学阶段、收集和绘图，得到有单位、来源和状态的数据，并能独立重绘与续算。

最终交付必须同时核对数值、图表、命令和安装制品。图像生成成功不能代替科学验收；某一组合通过也不能代替三种 PH × 两种求解的六个组合。

采用固定 current 覆盖安装，默认不保留历史二进制或入口备份；与早期规划冲突的版本目录/回滚要求以 0011 较新决定为准。构建和验证的临时候选制品不作为长期历史版本管理。

本次是小网格流程验收，不开展材料收敛或实验拟合。不承诺缺少环境的平台已实测；真实计算、参考和计算节点安装验证仍共用原授权预算。

## 用户场景与验收

### US1：一次入口得到完整结果（P1）

**价值**：用户无需手工补交收集或绘图任务。

**独立验收**：真实 CLI 驱动模拟 QE/EPW/Slurm，检查从提交到图表和完成状态的完整依赖。

1. 假如所有科学阶段有效且资源允许，那么一次 submit 自动完成收集和绘图。
2. 假如科学阶段失败，那么受影响下游不计算，结果不标为完整成功。
3. 假如科学计算成功但绘图失败，那么保留科学结果并报告交付未完成，恢复时不重算有效科学阶段。

### US2：看懂数据和图表（P1）

**价值**：用户能区分两种求解、能隙定义、Tc 区间及失败点。

**独立验收**：对固定数据检查 CSV/JSON 数值和实际图像，包括多能隙、未定位 Tc 与部分成功。

1. 假如能隙来自最低正 Matsubara 频率，那么图例明确写出该定义。
2. 假如某温度失败，那么不在该温度补零，也不连线跨越该失败点制造完整曲线。
3. 假如各向异性存在多带分布，那么保留带与动量信息，不只绘制一个平均值。

### US3：只重新收集或绘图（P1）

**价值**：改图或导出表格不消耗新的科学计算资源。

**独立验收**：外部程序替身证明 QE/EPW/sbatch 调用为零，原始文件哈希不变。

1. 假如结果包有效，那么能独立重绘。
2. 假如结果包缺列、单位不明或被篡改，那么拒绝绘图并指出问题。
3. 假如输出位置已有不属于本工具的文件，那么拒绝覆盖冲突项。

### US4：安装到固定入口（P1）

**价值**：用户继续使用固定 PATH，不必每次修改命令路径。

**独立验收**：隔离安装和重复更新核验全部新旧入口、来源身份及失败保护。

1. 假如待交付程序或入口验证失败，那么覆盖前拒绝安装。
2. 假如相关计算链仍活动或状态无法确认，那么保留候选制品，暂不覆盖运行程序。
3. 假如更新成功，那么默认命令指向固定 current，内容对应已测试制品，不自动积累历史版本。

### US5：核查真实验收是否完成（P1）

**价值**：用户可逐项看到六个组合的证据与限制。

**独立验收**：对照覆盖表能定位独立参考、原始输出、差异统计、作业与预算。

1. 假如全部必需组合和标准通过，那么允许完成 F5 与 Epic 收尾。
2. 假如预算不足、队列未结束或数值超差，那么对应项保持未完成或失败，不以模拟通过补齐。

### 边界与异常

覆盖空结果、部分成功、全部温度失败、Tc 未定位、单位或模式混淆、源文件篡改、图形字体缺失、输出中断、重复收集、跨目录重绘、平台不匹配、源制品缺失、安装中途失败、活动作业及无法查询状态。只更新本工具拥有的派生产物，不删除历史计算或擅自扩大预算。

## 功能需求

### FR-001：完整入口与独立结果命令

最终 `epwflow submit -c C` 默认贯通所需科学阶段、结果收集和绘图；`run` 在已登记资源内执行同一链路。`--until qe-data|interpolation|superconductivity` 保持前序已确认的显式停止边界。

新增结果命令：

| 命令 | 行为 |
| --- | --- |
| `epwflow collect -w W [--output R]` | 从已绑定运行读取和校验结果，生成结果包；缺省 R 为 W/results |
| `epwflow plot --results R [--output D] [--formats png,svg,pdf]` | 从结果包独立绘图；缺省 D 为 R/figures，缺省三种格式全部生成 |
| `epwflow results check --results R [--json]` | 只读检查结果包结构、数据身份及图表清单，不计算、不绘图 |
| `epwflow --version` | 输出可追溯构建身份；不启动外部科学程序 |

保留 F1 的 check/prepare/probe/status/resume/budget 与 F2/F3 的数据检查、导入命令。所有入口提供 help，公开子命令分别验证帮助和错误语义。

collect、plot 和 results check 不启动 QE、EPW 或 sbatch。处理已声明的部分有效结果时，可成功完成导出操作，但必须同时明确 workflow_complete=false；没有有效科学量时只生成状态说明，不生成伪造曲线。篡改或结构损坏返回非零，不默默忽略。

### FR-002：完整结果包

结果包带格式版本、运行身份与来源清单，至少包含：

- `summary.json`：物理参数、模式、程序身份、阶段/整体状态、未完成原因、资源摘要及来源。
- `a2f.csv`：能量 meV、展宽身份、α²F 和累计积分 λ。
- `coupling.csv`：对应展宽的 λ_integral、λ_sum、Fermi 窗口、低频规则和检查状态。
- `gap_summary.csv`：模式、温度 K、明确的虚频轴定义、能隙统计 meV、收敛与分类。
- `gap_states.csv`：各向异性最低正 Matsubara 频率的能带、k 点/坐标、权重、能量、Δ 和 Z。
- `tc.csv`：模式、方法、状态、区间上下端点、中点/半宽、判据与停止理由。
- `report.md`：可读说明、表格和图像链接，明确小网格验收边界。
- `manifest.json`：上述文件身份、字段/单位、必需图种、产物状态和上游清单身份。

完整逐频率能隙仍保留在 F4 原始交付中；结果包保存其来源和身份，不为默认绘图重复复制全部大数组。结果包自身包含所有必需绘图数据，可复制到其他位置后重绘；移动后若原始来源不可访问，明确标为未重新核验来源，不能编造已验证结论。

数字保存足够往返精度，不能为了展示舍入而改变机器可读数据。缺失数值采用 CSV 空值、JSON null 并附状态；科学零值与缺失值分开。JSON 不写非法 NaN/Infinity。

### FR-003：图种、格式与物理含义

首版用 Rust 绘图，默认生成 PNG、SVG、PDF。每张图标注单位、模式、展宽或温度及相关状态，并保留对应数据表。

必需图种：

1. `a2f_coupling`：α²F 与累计 λ 分面显示，能量轴为 meV；两者纵轴含义分别标明。
2. `gap_temperature`：iso 最低正 Matsubara 频率能隙随温度变化；aniso 展示带分辨统计及范围，明确绝对值/带符号统计定义。
3. `gap_aniso_distribution`：按温度和能带展示带权重的能隙分布，附采用的频率定义，不用平滑隐藏多能隙结构。
4. `gap_aniso_k`：按能带展示各实际 k 点的能隙，点序号关联表中的晶体坐标；不是能带路径的点列不得画成高对称路径。
5. `tc_interval`：分别展示两种模式已确认区间；未定位时显示状态及已知证据，不画虚构中心值。
6. `summary`：组合谱函数、耦合、能隙和 Tc 面板，保留单位与图例；数据缺失的面板显示状态文字。

aniso 图仅在选择该模式且存在有效数据时产生；iso-only 不造空 aniso 科学图。所选模式未完成时，汇总图明确标注“部分结果”。每个有效温度的各向异性分布可分别输出，以结果清单索引，不能只挑最好看的温度。

不默认平滑、拟合或外推能隙/Tc，不把数值曲线重采样作为验收数据。连线只辅助连接有效相邻采样；已知失败/缺失点处断开。Tc 图不把算法区间宽度标成材料物理误差。

### FR-004：可重复收集与独立重绘

collect 重新核对上游身份和数值状态；plot 读取结果包的表格与清单，不读取已变化的原始配置来重解释结果。

相同来源重复 collect 的规范化科学表格应一致；可变的生成时间与工具版本记录不得混入数值比较。plot 前后结果数据和原始科学输出哈希不变。

输出采用可验证的完成清单；中断留下的临时图或半写文件不能标记交付完成。只允许覆盖清单中属于本工具的派生文件，遇到未知文件冲突拒绝，不递归删除整个用户目录。源目录和输出目录冲突须提前拒绝。

字体或图形资源缺失时给出明确错误，不自动下载或输出文字缺失的“成功”图。无有效数据时仍允许导出可读的失败状态，但不能生成虚假的成功验收标记。

### FR-005：一次入口、结果状态与恢复

完整链路的结果阶段只消费已经验证的科学数据。科学阶段失败后不自动继续受影响求解；用户可执行 collect/plot 查看有效部分。

科学结果已完成而收集或绘图失败时，resume 重做必要交付步骤，不重跑有效 SCF、PH、Wannier、矩阵元或温度求解。重复入口不重复提交有效科学任务。

区分命令操作成功、当前运行完成和 Epic 验收完成。单次用户配置的运行完成，不能自动宣称三种 PH × 两种求解全体验收完成。

终端保持简洁：状态、目录或作业号；具体原因与可执行下一步写在错误和报告中。JSON 继续使用 F1 的显式状态语义。

### FR-006：直接手册与算例组织

`epwflow/README.md` 和 `docs/overview/epwflow/` 为实际 CLI 提供功能、参数、直接命令、输入输出及限制；根 README 链接新家族与构建安装说明。Overview 只写已实现且有证据的行为。

手册完整展示 check → prepare → submit → status → resume → collect/plot，以及资源内 run 和显式 probe；说明哪些命令提交作业，哪些只是本地数据处理。

说明三种 PH 模式、一次 SCF 与必要 NSCF、only_init 的 ph_init.in/ph_init.out/dyn0、实际 outdir、Wannier 能窗、虚频轴能隙、两种 Tc 判据、求解次数和预算共享。不给只包在 prepare.sh 里的操作说明。

本地 MgB₂ 算例放在 `examples/MgB2/sugon-amd/epw/`，按 nosplit/index/coords 分配置和运行目录；每种可选择 both，在同一 PH/插值来源上运行两种求解，结果按 iso/aniso 区分。保留原声子运行目录。

sugon-amd 使用用户指定 QE 7.4.1 配套 EPW、amd7513、单节点最多 64 MPI，按阶段缩小资源。实际程序路径与环境放本地忽略配置；inspur、chem 只提供待填写说明，不声称已实测。

新增 examples 继续遵守忽略规则，不强制加入 Git。可复现的通用输入格式、字段说明及命令写入跟踪文档，真实机器路径、日志与数据留本地。

### FR-007：六组合真实验收

覆盖表按如下六个单元分别记录：nosplit×iso、nosplit×aniso、index×iso、index×aniso、coords×iso、coords×aniso。

允许每种 PH 模式只运行一次 QE/插值，再分别运行两种求解；不为了六个单元重复 SCF。三种 PH 来源必须各自经过有效接口消费，不能全部替换为同一个来源后冒充三模式覆盖。

独立手动参考自行准备、运行和核查底层 QE/EPW 输入，保留原始输入、输出与哈希，不以 epwflow 生成的期望结果作为唯一基准。相同参数与版本的独立参考可在证据充分时供多个组合比较，不要求无意义地重复同一参考。

每个单元核对适用的电子/PH 数据、插值质量、α²F、λ、能隙与 Tc。both 的模式选择还要有统一入口和整体状态验证；不能因两个单独命令成功就跳过 both 调度检查。

真实运行核对 SCF 次数、阶段次数、已提交作业、程序版本与并行条件；复用场景记录跳过的依据。失败注入与昂贵异常优先用模拟，真实数值对照不可被模拟替代。

### FR-008：数值标准继承与证据判定

本项完整承接 F2 FR-011、F3 FR-009、F4 FR-012，包括单位、匹配规则、覆盖要求、双初值、收敛、低频处理及临界附近独立复核，不另设较宽标准。

主要数值约束包括：

- F2：SCF 总能差 ≤ 10⁻⁷ Ry/计算晶胞；电子能量/Fermi 能差 ≤ 10⁻⁵ eV；动力学矩阵最大元素差 ≤ 10⁻⁷ Ry/Bohr²；声子频率差 ≤ 0.1 cm⁻¹；坐标与权重按已确认标准检查。
- F3：插值质量的电子最大/RMS 误差为 0.05/0.02 eV，声子为 50/2 cm⁻¹（2026-10-19 用户最新变更），并满足固定覆盖和虚频规则；自动/手动 α²F 归一化 L1 差 ≤ 10⁻³、归一化峰值点差 ≤ 10⁻²；对应 λ 差 ≤ 10⁻⁶ + 10⁻³×参考绝对值。
- F4：能隙逐元素差 ≤ 10⁻⁴ meV + 10⁻³×参考绝对值；Z、本征值、双初值和分类沿用其规则；Tc 两侧有效区间宽度均 ≤ 0.5 K、区间有交集且中点差 ≤ 0.5 K。

### FR-014：QE／EPW 四类叠图与总览

增加以下四张独立对比图及 comparison_overview 2×2 总览，作为 epwflow 的必需图表，与 FR-003 的 α²F、能隙和 Tc 图并存。默认输出 PNG、SVG、PDF，并保存对应成对数据表。

| 图种 | 内容与来源 |
| --- | --- |
| electronic_bands_comparison | 同一路径的 QE 直接电子能带与 EPW／Wannier 插值能带，共同有效能窗和同一 Fermi 能零点 |
| electronic_dos_comparison | 总电子 DOS、元素分辨 PDOS 和轨道分辨 PDOS 分面叠图；MgB₂ 分别展示 Mg、B，轨道按实际可靠投影列出 |
| phonon_dispersion_comparison | QE q2r/matdyn 曲线与 EPW 插值色散，另以标记显示独立 ph.x 直接验证点 |
| phonon_dos_comparison | 总声子 DOS 与元素分辨声子 DOS 分面叠图；保留原子到元素的振动权重定义 |

统一先绘制 QE 实线，再绘制 EPW 虚线，保证虚线在上层；同一元素固定色系，方法以线型和颜色深浅区分，图例同时说明方法和投影类别。总览采用与独立图相同的数据与样式；DOS 总量和元素面板都必须可读，轨道细节在独立图完整展开。能带和声子路径共享两侧坐标与高对称点，不连续段断开，不平滑、平移或删点制造重合。

声子实线标为“QE q2r/matdyn”，验证点标为“QE ph.x”，不能笼统标成整条路径的直接 PH 结果。电子横轴采用实际路径距离、纵轴为 E−EF（eV）；DOS 电子能量轴同样为 E−EF（eV），总量／投影密度为 states/(eV·cell)。声子色散频率统一为 cm⁻¹，声子 DOS 使用相同频率单位，密度为 states/((cm⁻¹)·cell)；转换原 meV 输出时同时转换 DOS 数值以保持积分。

缺少可靠投影或参考时，仅绘制已有有效面板并明确标记部分结果，缺项不画伪曲线，不能通过本项完整验收。电子 PDOS 不完备程度、声子归一化以及比较数据要求由 [0012 FR-014/015](../0012-epwflow-interpolation/spec.md) 唯一规定。
