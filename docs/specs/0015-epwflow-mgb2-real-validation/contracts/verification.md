# 验证契约

生产接口、科学数据格式、默认 ./tmp 及各阶段成功语义沿用 [0008 基础契约](../../0008-epwflow-foundation/contracts/interface.md) 和 [0010](../../0010-epwflow-qe-data/spec.md)、[0012](../../0012-epwflow-interpolation/spec.md)、[0013](../../0013-epwflow-superconductivity-tc/spec.md)、[0014](../../0014-epwflow-delivery/spec.md)。本项不另设较松容差。

| 测试层 | 必需输入与检查 | 结果含义 |
| --- | --- | --- |
| 现有回归 | Cargo 测试、固定源码 | 仅已覆盖代码行为 |
| 实际 CLI | 独立进程、配置、退出和日志；外部执行计数 | 是否真实接通公开路径 |
| 实际格式 | QE XML/dyn/phsave/EPW 原生数据，完整维度和来源 | 数据能否复用与解析 |
| 最小真实续算 | 单套兼容 PH/SCF、完整 NSCF、目标 EPW | 实际链路运行成功 |
| 三模式数值对照 | 相同参数、独立参考、逐点频率/谱/λ | 小网格实现一致性 |
| 原生超导与全链路 | 原 Spec 的 iso/aniso 输出、收敛与温度证据 | 原需求是否完成，未实现不得替代 |

失败应有非零退出或显式不完整状态，不能生成有效数据清单。提交成功与数值完成分别记录。原始来源哈希必须在试算前后比较；只允许已明确的派生目录写入。独立参考不通过生产实现填充期望值。

## 2026-10-19：FR-011／SC-005 叠图验证契约

| 检查层 | 必需证据 | 拒绝／未完成条件 |
| --- | --- | --- |
| 来源与配对 | 三种实际 PH 来源，各自 EPW 数据；同参数 QE 参考、共同能窗／路径／DOS 网格与哈希 | PBE/LDA 混用、自由对齐、删点／缺态、未消费某来源 |
| 电子投影 | 两侧同原子／轨道定义、复投影和 Wannier 规范／变换，spilling 与覆盖报告 | 仅有总量／Wannier 中心权重、缺复投影或规范不明 |
| 声子投影 | 同质量／原子顺序／ASR 本征矢、元素权重和、3N 积分及尾部／虚频说明 | 模式列冒充元素、错误质量／归一化、隐藏虚频 |
| 图表 | 四张独立图和 2×2 总览，PNG／SVG／PDF；QE 实线先绘、EPW 虚线后绘，直接 ph.x 点独立图例 | 只交误差图／总览，图例／轴／线型错误，缺项冒充完整 |
| 数值 | 继承原能量／频率门；DOS 同轴差、积分、范围、投影未完备报告 | 看图代替阈值、重新缩放隐藏差异、质量失败放行 F4 |
| 自动交付／重绘 | 公开 CLI、仅 F3 诊断、跨目录包、原始／表格哈希和外部调用计数 | 强制依赖不存在的 F4，重绘调用 QE／EPW／sbatch 或改原数据 |

每来源分别标记通过、失败、未完成；缺数据可显示部分图，但完整叠图不得通过。科学质量失败时诊断操作可成功，workflow_complete 必须为 false。DOS 本次报告差异和约定的归一化／积分检查，不另设比原 Spec 更宽的科学门。

新增参考、复制和图像存储与失败重试共同计入原 8 节点小时／100 GiB 等限额。未完成项不靠扩大预算、重置账本或删除旧数据解决。

## FR-012/013、SC-006/007：外窗与目录验收契约

| 边界 | 接受条件 | 拒绝或保留限制 |
| --- | --- | --- |
| 实际 Outer | 带哈希 wout 唯一边界，有限递增，支持实际 Fortran 指数；同一 Wannier 基底 | 缺记录、重复、逆序、非有限或指纹错误拒绝；不猜测 dis_win |
| 能量零点 | 绝对窗减共同 E_F 等于相对 window_ev，双边界差小于 1e−8 eV | 不自由对齐、不修改原质量窗；偏移不一致拒绝 |
| DOS 与显示 | 两侧共同核／展宽／物理权重，所有电子 DOS 覆盖完整显示窗；能带纵轴和 DOS 横轴一致 | 禁止沿用窄窗数据只换标题；保留 QE 未匹配态，不重新缩放隐藏差异 |
| 旧包 | 没有可选外窗字段时按已有 window_ev 读取／绘制 | 不声称旧包使用了已经核验的实际 dis_win |
| 三格式与重绘 | 四张独立图和总览共 15 文件，QE 实线先画、EPW 虚线后画；跨目录仅消费包内数据 | 表格／原始数据哈希不变，QE／EPW／sbatch 调用为零 |
| 目录整理 | 顶层运行实体编号加用途，脚本区只含测试脚本和说明；全部旧实体文件大小／哈希一致、链接有效 | 原科学文件和历史清单不改写；旧数据链接退役，现行来源改用新路径清单 |
| 质量语义 | 结果检查的操作成功、图像完整性和科学质量分别记录 | 五点 RMS 仍失败；quality_failed／workflow_complete=false 保留，不放行下游 |

当前脚本 `replot_window.sh` 首次缺比较 manifest 时执行 export-comparison；已有比较表时只收集和重绘。改变来源或窗口时应在独立新运行目录重新导出，不能把修改 sources 文件当作已有比较表已更新的证据。实际验收和覆盖映射见 [验收](../window-directory-validation.md)、[分析](../window-directory-analysis.md)。
