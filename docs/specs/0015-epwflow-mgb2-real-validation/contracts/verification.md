# 验证契约

生产接口、科学数据格式、默认 ./tmp 及各阶段成功语义沿用 [0008 基础契约](../../0008-epwflow-foundation/contracts/interface.md) 和 [0010](../../0010-epwflow-qe-data/spec.md)、[0012](../../0012-epwflow-interpolation/spec.md)、[0013](../../0013-epwflow-superconductivity-tc/spec.md)、[0014](../../0014-epwflow-delivery/spec.md)。本项不另设较松容差。

| 测试层 | 必需输入与检查 | 结果含义 |
| --- | --- | --- |
| 现有回归 | Cargo 测试、固定源码 | 仅已覆盖代码行为 |
| 实际 CLI | 独立进程、配置、退出和日志；外部执行计数 | 是否真实接通公开路径 |
| 实际格式 | QE XML/dyn/phsave/EPW 原生数据，完整维度和来源 | 数据能否复用与解析 |
| 最小真实续算 | 单套兼容 PH/SCF、完整 NSCF、目标 EPW | 实际链路运行成功 |
| 三模式数值对照 | 相同参数、独立参考、逐点频率/谱/λ | 小网格实现一致性 |
| 原生超导与全链路 | 原 Spec 的 iso/aniso 输出、收敛与温度证据 | 原需求是否完成，未实现不得替代 |

失败应有非零退出或显式不完整状态，不能生成有效数据清单。提交成功与数值完成分别记录。原始来源哈希必须在试算前后比较；只允许已明确的派生目录写入。独立参考不通过生产实现填充期望值。
