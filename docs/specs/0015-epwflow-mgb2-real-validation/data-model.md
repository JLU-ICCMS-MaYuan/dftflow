# 测试数据与所有权

- **SourceInventory**：mode、来源根、原始配置/结构/赝势/版本、每项相对路径/字节/SHA256、全局 q 与局部编号/扰动元数据。来源只读；缺证据记录缺失，不能补造。
- **StageEvidence**：源码/制品身份、模式/阶段、输入哈希、实际程序/作业、退出和收敛、原生产物及验证。模拟与真实分别标识。
- **ReferenceComparison**：独立参考身份、参数一致性、单位/匹配、差异、固定阈值、通过/失败/未运行。缺参考不等于零差。
- **CampaignBudget**：沿用 Epic 同一活动账本，补核历史实际 allocation，步骤不重复计费，未知任务不释放资源；不能以本项目录新建另一份额度。
- **DefectRecord**：编号、严重性、源码证据、最小复现、受影响 FR、修复提交和回归证据。没有实际验证不能由“文件已写”关闭。

原始输出保留，隔离副本用于续算；通用测试夹具允许入库，机器路径/真实波函数/日志/作业证据放忽略目录。
