## 首次真实启动暴露的谱路径缺陷

作业 1291302 验证了重启开关确实跳过 PWSCF 初始化，但 iso 在正式求解前退出 255。目标 EPW 5.9 的 `fila2f` 是 80 字符字段，长绝对路径被截断；其 `read_a2f` 使用 `STATUS='unknown'`，因而创建空文件后报读取结束。该空文件移入失败现场保存，不改历史科学文件。aniso 已读完原生矩阵，但因尝试目录缺少已有谱，触发不必要的谱重算。发现后取消该分配，未把任何估计或未完成结果计为 Tc。

修复为两模式均复制已验证的 α²F 到独立尝试目录，核对来源哈希，输入只引用 `source.a2f`。谱副本作为正式尝试产物记录，避免截断与重算。回归使用超过 80 字符的来源路径，并检查两模式的本地谱和引用。

本次取消分配实际消费 121 节点秒，共享累计 2773，预留归零。显式恢复保持原科学根目录、配置、来源与尝试计数；已有 iso 失败和 aniso 中断现场保留，新尝试使用新编号，旧分配终态必须通过 sacct 核实。
