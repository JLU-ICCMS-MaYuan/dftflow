# 原生 MgB₂ 两模式 Tc 验收

本记录细化 [0013 T039～T045](../0013-epwflow-superconductivity-tc/tasks.md) 与本项真实验证任务，沿用已有本地 Issue，不新增线上操作。

## 本次固定范围

复用[已验证的 40³/20³ 原生细网格](native-fine-validation.md)，不执行新的 SCF、NSCF、PH、Wannier 或细网格 EPC。5 WF、原冻结上界 8.8 eV、粗 k/q=6³、电子展宽 0.1 eV、声子展宽 0.5 meV、μ*=0.05 和虚轴截断 0.5 eV 保持固定。五点、45 模质量全部保留，声子最大／RMS 门为 50／20 cm⁻¹。

预先固定本次 Tc 搜索区间为 10～55 K，宽度目标 0.5 K，两模式各最多 64 次实际求解；必需能隙温度仍为 10、15、20 K。每个非线性温度独立使用 1／10 meV 初值、最多 500 次迭代、相对残差小于 10⁻⁸，混合参数不变。先探测上端点；未收敛的小能隙不能归为正常态。不得用日志中的经验 Tc 替代原生结果。

单个 Slurm 分配上限为 1 节点、24 MPI、2 小时，预留和实际消费均计入原 8 节点小时账本；容量仍为 100 GiB。来源、配置、程序、报告及各矩阵文件均以哈希绑定，已有目录不能隐式重试。

## 执行代码

- `attempt.rs` 显式设置 EPW 重启开关，跳过 PWSCF 保存树初始化；只读现有谱和原生矩阵，逐温度运行。
- `source.rs` 的共用角色绑定同时服务完整 F3 清单与明确的阶段验收报告，不伪造 F2／F3 自动链身份。
- `engine.rs` 先验证搜索上端点，再按原整数温度搜索；探测、双初值和失败均在同一持久尝试记录内计数。
- `real_tc.rs` 显式忽略的本机测试验证冻结物理来源、五点质量、原预算和真实分配，调用上述生产引擎及交付函数。阶段验收继续标记 `automatic_workflow_validated=false`。

原生 Δ／Z、两模式 Tc、独立临界参考、Mori 图与三来源六组合均须由实际输出分别验收，不能由格式回归或作业提交成功推定。

## 首次真实启动暴露的谱路径缺陷

作业 1291302 验证了重启开关确实跳过 PWSCF 初始化，但 iso 在正式求解前退出 255。目标 EPW 5.9 的 `fila2f` 是 80 字符字段，长绝对路径被截断；其 `read_a2f` 使用 `STATUS='unknown'`，因而创建空文件后报读取结束。该空文件移入失败现场保存，不改历史科学文件。aniso 已读完原生矩阵，但因尝试目录缺少已有谱，触发不必要的谱重算。发现后取消该分配，未把任何估计或未完成结果计为 Tc。

修复为两模式均复制已验证的 α²F 到独立尝试目录，核对来源哈希，输入只引用 `source.a2f`。谱副本作为正式尝试产物记录，避免截断与重算。回归使用超过 80 字符的来源路径，并检查两模式的本地谱和引用。

本次取消分配实际消费 121 节点秒，共享累计 2773，预留归零。显式恢复保持原科学根目录、配置、来源与尝试计数；已有 iso 失败和 aniso 中断现场保留，新尝试使用新编号，旧分配终态必须通过 sacct 核实。

## 已确认的单次数值诊断

用户答复“允许这一次固定诊断（推荐）”。仅此一次调整数值设置，旧运行保持冻结：物理输入、原矩阵、μ*=0.05、0.5 eV 截断、1／10 meV 双初值与相对残差 10⁻⁸ 保持；固定 Broyden 因子 0.7、历史长度 8、最多 2000 次，检查 iso 10 K 和 aniso 80 K 共最多四次求解。独立新目录记录旧尝试来源，计入原共享预算和剩余次数，最多一个 1 节点／24 MPI／2 小时分配，失败不追加扫描。

此方案只是数值收敛假设，不承诺能解决趋零解的相对残差问题，更不把提高上限本身当作科学改进。目标 EPW 原生 Broyden 历史长度最大为 8；配置与单次请求应在启动前拒绝超出后端范围的值。

诊断复用生产 `Engine::attempt` 与双初值分类器，不运行 Tc 搜索。每模式新配置硬限两次调用，历史交付以哈希绑定，启动前核对既有 iso 11／aniso 2 次与新增两次合计仍不超原 64 次。首初值失败可以执行本次事先授权的另一初值，不重提失败初值，不追加温度。完整 Tc 与 Mori 图仍不因此自动完成。
