## 2026-10-16 复用实现方案

1. epwflow 严格配置经适配器转换为共享输入模型；直接使用 qf-crystal 的结构解析、qf-input 的 PW/PH 渲染与原子质量。显式赝势绑定由共享渲染接口接收，不退回目录自动猜选。
2. 先提取无文件副作用的 PH 渲染接口，qeflow 原写文件接口和 epwflow 同时调用。完整均匀 NSCF 网格使用共享网格生成器；EPW 5.9 的 SYSTEM.nosym/noinv 设置为 false，保留晶体对称性并检查实际完整点集（本轮真实调试修正）。旧 build_nscf_pw_params 不直接作为 EPW 适配器。
3. qeflow/src/phonon_init.rs 与 phonon_chain.rs 内的日志/保存检查、完整快照、only_init、dyn0 计数与坐标转换、分 q 物化逐步提取到共享库。优先使用 0006 当前链路；qf-phonon 的旧 generate_split_inputs 仍逐 q SCF，不作为 EPW 主路径。
4. 科学阶段与调度分离：共享函数产生输入、数据和校验结果；epwflow foundation 负责预算、作业记录和执行，不直接调用不受其账本约束的旧提交入口。
5. EPW 独有的响应势/phsave 配对、原生 EPW 保存格式、Wannier 与插值质量、超导求解继续由 epwflow 负责。普通 qeflow 声子合并成功不自动成为 EPW 交付成功。

验证先覆盖两入口共用输入、统一 prefix、真实质量、完整均匀网格和三模式 PH 语法；再覆盖快照隔离、旧结果导入和真实原生 EPW 消费。仍未接通的阶段不得记为通过。

## 2026-10-18 讲义输入与原生质量阻断

1. 参数出处为用户指定讲义的第 16～19 页，先固定结构、NC LDA 赝势、显式原子质量、8³ SCF、6³ NSCF、3³ PH、5 个 Wannier 函数及质量点。SCF 正文另写 12³，采用展示输入 8³并记录矛盾；不复用旧 PBE 电荷。
2. `EpwConfig` 区分粗网格质量计算与细网格矩阵元生成，按原生参数名和单位渲染。支持只给冻结窗上界；Fermi 相对能窗须有绑定值。EPW 自带 Wannier90 为原生参考主路径，旧独立程序编排仍须改造，不能称为自动链已完成。
3. 质量计算显式写 `selecq.fmt` 选择全部固定 q 点，保留 0.4 eV Fermi 窗口，防止筛选后的未计算点被当作零频。长 `dvscf_dir` 在运行前拒绝，不接受 Fortran 静默截断。
4. 参考电子态由独立 QE 计算取得，使用共同能量零点和有序单射匹配。参考声子按目标 EPW 的 Γ 点 onsite 简单 ASR 修正所有 q，再交由 QE dynmat 对角化；不修改原始 PH 矩阵。参考和派生产物均登记指纹。
5. Rust 只读检查实际原生谱、结束计时及质量产物；质量超差保留数值报告并返回非零，细网格前必须阻断。生产 F3 还缺完整原生矩阵元适配，F4 在原生求解未接通时明确报错，不再发布经验公式结果。
6. 新输入按讲义真实执行后声子质量失败。此处保持既定阈值并暂停依赖该质量门的计算，不追加盲目参数尝试；参数依据、版本适配、预算和失败证据分别写入 Research 与 Acceptance。
