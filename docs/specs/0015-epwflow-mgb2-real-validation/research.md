# 研究与取舍

## 已核查事实

- 真实 CLI submit/run 直接拒绝，--until 缺失；已保存实际退出码，不仅搜索字符串。
- 41 项测试通过，但 F3 fixture 自己写 epw.out、fine_frequencies.dat 等简化数据，并用没有电子态和 q 点的 F2 清单触发成功；不能证明目标 EPW 格式适配。
- F3 频率公式造谱及 F4 经验公式可从生产 scheduler 调用链直接定位，不是仅存在于测试中的辅助函数。
- 目标安装的 EPW/src/readin.f90 没有 energy_reference/seedname 输入名，却有 nkf1/nqf1。生产输入生成器写了前两项并将细网格写成 nk1/nq1；必须按完整目标 namelist 逐项适配，不只修改一个拼写。
- 现有三模式日志、dyn0、响应势和保存数据已盘点；旧计算没有新 manifest，不能直接声称导入可用。

## 决策

1. 先复用三模式已有数据，避免重跑兼容 SCF/PH。备选从头重做全部会增加成本且绕开用户要求的复用验证，拒绝作为默认路径。
2. 冒烟与科学一致性分开：启动成功可以形成第一份证据，但不能关闭 0015 或上游 Epic。
3. 只修复原契约；若需大范围补齐缺失能力，先明确职责并交接。不能把重写科学求解器当 debug，也不能把经验模型输出冒充 EPW。
4. 旧 41 项测试保留作回归，增加实际格式和 CLI 失败场景。测试必须拒绝空清单、合成谱、缺收敛及未知预算状态。
5. 已授权预算不因 0015 新编号而清零；与本活动无关的 SiP2 作业不凭名字含 EPW 混入统计。尚不能证明的历史消耗保持未知。

## 证据边界

当前没有本次新增真实作业。文件存在、源码版本、模拟退出零分别不足以证明可执行版本、数值收敛和物理正确。真实目标路径与原始查询仅存 docs/local/0015-epwflow-smoke/。

### 本轮故障定位

旧 index 的 Γ 动力学矩阵与 nosplit 相差约 0.357 cm⁻¹，NSCF 能量最大差约 7.56×10⁻⁵ eV，误差已存在于 EPW 之前。复制完全相同的 SCF 快照重新计算 index PH 后，原生谱按行比较的归一化 L1 降至约 7.46×10⁻⁶，但能量轴仍差约 1.2×10⁻⁶ meV；尚不能把按行结果标成同轴严格验收通过。旧参数的独立电子参考还显示验收能窗存在 Wannier 缺态和超差，保留失败证据，不据此盲目增加轨道。声子质量对照必须先统一 ASR，不能把不同 ASR 的差异当正式误差。

## 2026-10-18 原生运行与独立质量结论

### 旧 index 差异定位

原三套 PH 使用的 SCF 数据内容并不完全一致。保持旧来源只读，在新目录将 index 的两个 PH 点绑定到与对照相同的 SCF 快照，复用相同 NSCF，再运行原生 EPW。同序号谱形 L1 诊断从约 9.71×10⁻³ 降至 7.46×10⁻⁶，峰值诊断约 8.88×10⁻⁶；轴仍差约 1.2×10⁻⁶ meV。该实验支持 SCF 来源不一致是主要差异来源，但不等于同轴谱验收通过，也没有把不同模式映射问题全部关闭。

### 讲义输入的实际运行

新 LDA 计算完成一次 SCF、六个不可约 q 点的 nosplit PH、216 点/16 带 NSCF、原生 Wannier 化和粗网格 EPC。SCF 与 NSCF Fermi 能不同，质量对照绑定均匀 NSCF 的 7.497269413025949 eV，不另拟合能量平移。B 的显式质量 10.811 同时写入 QE 和 EPW，不能由公共默认 10.81 静默替换。

已由实际失败核对的适配问题：

- 此目标 EPW 的启动要求 MPI 总数等于 pools×images；24 MPI 的原生 EPW 使用 24 pools，而 PW/PH 可使用 6 pools。三程序不能共用未经验证的同一并行开关。
- `dvscf_dir` 是定长 100 字节字符变量。过长的绝对路径曾被截断并导致找不到 patterns；改为相对实际工作目录的短路径后读取成功，生产渲染器提前拒绝长度达到 100 字节的输入。
- `band_plot` 仍可能按 Fermi 窗口过滤 q，两个独立 q 的未计算结果出现全零。质量参考改为明确的全 q `selecq.fmt`，没有增大 `fsthick=0.4` 来掩盖缺点。
- 同一 ASR 必须精确定义。目标 `EPW/src/io/io.f90` 的 `dynmat_asr` 先从 Γ 矩阵求 onsite 行和修正，再对所有 q 施加同一修正；不能对每个非 Γ 矩阵分别强加零行和。本轮在派生副本实施该变换，由实际 QE dynmat 对角化，原始 PH 矩阵保持不变。
- 原生谱分两类：普通谱多列 α²F，超导数据准备谱还带累计 λ 列。二者能量轴都来自谱表，不能拿细网格声子频率当谱采样轴；积分复核使用目标 EPW 的离散求和规则，分别保存 λ_integral、λ_sum。

### 固定点上的结果

参考为预先固定的六个 k 点（四个在粗 k 网格外）和四个 q 点（两个在粗 q 网格外），共同能窗为 NSCF EF±0.5 eV，全部九个声子模。

| 数值指标 | 实测最大 / RMS | 原定最大 / RMS | 结论 |
| --- | --- | --- | --- |
| 电子能量 | 0.013027809 / 0.008787088 eV | 0.05 / 0.02 eV | 当前采样能窗内数值指标通过 |
| 声子频率 | 48.530593309 / 10.610753468 cm⁻¹ | 5 / 2 cm⁻¹ | 失败 |

电子参考能窗共有四个态，其中只有一个网格外 k 点在该能窗有参考态；不能据此宣称完整费米面或其他能窗均已验证。声子粗网格点误差小于 0.001 cm⁻¹；最大差出现在晶体坐标 (1/6,0,1/6) 的排序后第八模：参考 569.397344，插值 617.927937 cm⁻¹。网格内外差异及小的声学负值均保留，不取绝对值或删模。

讲义明确是教学输入，不承诺严格独立质量阈值。当前证据不足以把误差归结为需要增加 Wannier 轨道，不能沿用此前猜测；进一步物理参数变更必须有依据，保留本轮失败输入和阈值。40³/20³ 仅完成配置适配，未越过失败质量门实际生成矩阵元，更未得到原生能隙/Tc。

## 2026-10-19：经授权的单次 6³ 粗 q 对照

只将 PH 和 EPW 对应粗 q 网格从 3³ 改成 6³。结构、LDA 赝势、原子质量、8³ SCF、216 点/16 带 NSCF、5 个 Wannier 函数、能窗、Fermi 来源、全 q 诊断选择和独立参考不变。两份保存树使用独立复制，新增 SCF/NSCF 执行次数均为零。

原生 PH 得到 28 个不可约点；dyn0、XML 动力学矩阵坐标、patterns 全局编号与非空响应势逐项一致。新旧 Γ 原始矩阵最大元素差约 2.19×10⁻¹⁵ Ry/Bohr²，原独立 Γ onsite ASR 参考可继续用于该受控对照。EPW 实际读取完整 216 点粗 q 网格，解纠缠与局域化分别收敛。

| 对照 | 声子最大 / RMS（cm⁻¹） | 原标准 5 / 2 的结论 |
| --- | --- | --- |
| 原 3³ | 48.530593309 / 10.610753468 | 两项均失败 |
| 单次 6³ | 9.042613107 / 1.840341913 | 最大误差失败，RMS 通过；整体仍失败 |

原最大误差点 (1/6,0,1/6) 现在落在粗网格上，该点全部模式最大误差约 0.002836 cm⁻¹。剩余最大误差出现在网格外 (1/12,0,0) 的排序第八模：独立 QE 为 533.851426、EPW 为 524.808813 cm⁻¹；同点第一模误差约 5.868814 cm⁻¹，也超过最大误差门。电子最大/RMS 仍为 0.013027809/0.008787088 eV，未改变电子能窗或匹配规则。

以上只证明该单项加密显著降低原固定点误差，不能证明完整质量通过，也不能据此推断必须增加 Wannier 轨道。四个固定 q 点在 6³ 网格下仅剩一个网格外点，完整 F3 覆盖不足另行保留；没有删点、平滑或重设阈值。实验失败后停止追加网格和依赖的细网格/超导计算。

## 2026-10-19：叠图的证据边界

用户确认了共同有效能窗、QE 连续声子曲线加直接验证点，并要求把叠图纳入 epwflow。电子窗必须至少包含 E_F±0.5 eV 和全部 Fermi 窗口；这不授权自动扩大 Wannier 基底。直接 ph.x 点验证物理插值质量，q2r/matdyn 提供明确标注的连续 QE 参考，两者不能互相替代。

已有六 k／四 q 质量比较和 6³ 误差图不包含完整电子／声子路径与两侧可靠元素／轨道 DOS，不能作为本次四图交付证据。旧数据各自的参数来源保持隔离；需要重新核对是否有同波函数规范的原子投影、解纠缠变换和质量加权声子本征矢。

采用 0012 的原子投影算符与声子元素权重契约，拒绝以键中心 Wannier 权重／模式编号代表 Mg/B 元素。采用 0014 的自包含比较包与 Rust 绘图，不以手工绘图脚本替代公开入口验收。图层、单位、尾部、投影缺项和质量失败均须可见；失败数据可以诊断，不能发布 F4 就绪。
