## 先固定目标，再选择四界

目标验证窗继续至少覆盖共同 E_F±0.5 eV，并检查与实际 EPC 电子取态范围的包含关系。当前 `fsthick=0.4 eV`；它是电子费米窗口参数，不能用它替代外窗，也不能与 Matsubara 截断 `wscut` 混用。目标程序对取态的具体比较式须由执行适配层核对。

先处理真实排除带和自旋通道，再统计实际传给 Wannier 的全部均匀 k 网格本征值。当前 MgB₂ 没有排除带，是非磁性单通道；不能直接把教程的半芯态排除带号套进来。

对金属使用经来源绑定的 E_F，不凭稀疏 k 网格中 HOMO 与 LUMO 的间距将它改判为绝缘体、把冻结上界移到 LUMO＋2。绝缘体分支将来应根据可信电子类型与带边来源单独定义。

### 推荐的兼容起点

以下是提议的四边界生成规则，不是上游四边界自动算法的逐字移植。`δ=0.02 eV` 是本次提出的端点余量，需在实施设计中固定；不改变电子误差门。

```text
Emin、Emax：处理排除带后的全部输入本征值极值
dis_win_min  = Emin - δ
dis_win_max  = Emax + δ
dis_froz_min = dis_win_min
dis_froz_max = E_F + 2 eV
```

全候选外窗作为起点保留构造平滑子空间的余地；这不意味着 N 个 Wannier 函数能复现外窗内所有 Bloch 带。其宽度后续由有界比较优化，而不把“刚好够 N 态”的外窗直接当作默认最优解。

四界必须满足包含关系，并在每个实际 k 点满足：

```text
N_outer(k) >= N
N_frozen(k) <= N
target_window ⊆ frozen_window ⊆ outer_window
```

检查任一失败时，报告请求窗口、容量限制和最差 k 点，停止生成可执行推荐。对于这里从谱底起算的冻结窗，可以提供 `min_k E_(N+1,k)` 以下的可行上界作为诊断，但不能静默把请求上界压低后仍称满足原目标。一般的独立冻结下界必须重新按区间计数。

端点附近有简并簇时须整体处理并报告敏感性；不得利用输出舍入拆开简并态。缺少足够空带、初始投影秩不足或目标窗本身包含超过 N 个必须保留态时，说明当前基底／数据不满足目标，不能自动增轨道或缩小验收窗。

### 第二阶段：少量数据驱动的外窗候选

固定冻结窗后，保留全候选外窗作为对照，再提出两个外窗上界候选：

```text
U0 = max_k E_(N+1,k) + δ
U1 = U0 + 2 eV
```

候选必须与冻结上界相容并处于输入空带覆盖内，重复或超出全候选外窗者去重。采用第 N+1 带，是为每点至少保留一个额外候选态；它仍然只是静态候选生成依据，不能保证子空间平滑、投影有秩或误差通过。

如需比较冻结下界，可另加费米附近的双侧冻结窗。它会放开深价态的精确保持，可能改变局域化结果，因此本建议不把它静默替换为默认，也不启动四维扫描。

## 如何选出真正可用的一组

先固定候选列表、选择参考集和未参与调参的最终复核集，再运行有界原生对照。已有反复查看的点可以作为回归／选择集，不能改名为未使用的最终独立验证集。

依次检查原生收敛、目标态完整覆盖、目标窗内电子最大误差≤0.05 eV 且 RMS≤0.02 eV。通过后比较候选误差与窗口小扰动的稳定性，spread 及实空间衰减作为辅助依据。不得只取 spread 最小者，也不得删掉失败参考点。

同一 Bloch 基底下，能否复用原始 `.mmn`／初始投影要由数据适配确认；新窗口须重新解纠缠、局域化并生成匹配的新 Wannier 规范数据。旧旋转矩阵和旧 EPC 矩阵不能直接作为新窗口结果。

这次没有授权新增科学试算，不提交作业。后续实验仍沿用既有累计预算；当前声子 RMS 8.075133 cm⁻¹ 超过 2 cm⁻¹ 的阻断不因电子选窗而解除。
