## 查证结论

### 1. 外窗和冻结窗承担不同职责

SMV 从每个 k 点外窗内的态构造固定维数的平滑子空间；内窗中的态必须包含于该子空间。因此，给定 `N=num_wann`，能量窗口必须满足：

```text
对每个实际 Wannier 输入 k 点：
N_outer(k) >= N
0 <= N_frozen(k) <= N
outer_min <= frozen_min < frozen_max <= outer_max
```

态数应在排除带、自旋通道与单位转换处理后计算。它们是必要条件，不是足够条件；初始投影秩、子空间平滑性、收敛和网格外误差仍可能失败。冻结态被保留不意味着所有网格外插值严格等于 DFT。

外窗不能只围住 E_F 附近的少量态：即使某个 k 点附近没有费米面，仍须构造 N 维子空间。也不能要求五个 Wannier 函数复现同一点十六条 QE 能带；宽窗图上的缺态不自动说明费米面模型错误。

### 2. AiiDA 提供可借鉴的流程，而不是通用四个数

源码有两种不同机制。`auto_energy_windows` 用投影质量估计 `dis_froz_max`；其工具函数取达到阈值的态中的最高能量，随后主流程限制上界，避免冻结超过 `num_wann`。这是启发式，不能把孤立高投影态对应的最高能量直接当作最优冻结边界；其上界保护也不能替代任意非平凡下界时的完整逐点计数。

`optimize.py` 调的是投影阈值，不是四个能量边界。阅读版本使用有限候选；有 DFT 参考时根据能带距离选择，没有参考时可使用 spread 分布指标。其默认候选约为 `dis_proj_min=0.01～0.02`、`dis_proj_max=0.99～0.85`，参考能带距离的选择能区涉及 E_F＋2 eV。这些数是该项目协议，不构成本项目需求或验收标准。对 MgB₂ 超导，应保留本项目的固定目标能区、最大误差和 RMS 双门。

### 3. 投影解纠缠比单一能量截断更能识别态的性质，但当前不能直接启用

Qiao 等按投影质量把态分为排除、混合和保留，并建议结合费米能附近的能量冻结约束。原因是高能区可能同时混有有用轨道态与自由电子态，单一水平能量线无法区分所有情况。

前提是投影基底合适并正确规范化，使 `p_nk=Σ_m |A_nmk|²` 有明确含义，通常处于 [0,1]。若投影基底不正交，应先处理重叠度量；不能直接把任意 `.amn` 数值平方和当作可比的投影质量。当前五个函数包含 B:pz 与键中心 s，并不等同于论文的完整原子轨道集合；本轮未取得相应规范化投影数据。

最新 Wannier90 文档还包含 `dis_proj_auto`，采用多级 Otsu 划分投影质量分布；这是投影阈值自动化，不是四个能量窗口自动优化。当前日志为 3.1.0，对应发布源码没有这些新关键字。不能直接把最新文档中的参数写入当前 EPW 输入，也不应为本轮调研升级程序。

暂缓元素／轨道 PDOS 展示，不代表可以删除 Wannier 初始投影；内部投影质量诊断与对外原子 PDOS 是不同数据产品。前者可作为未来选窗依据，但也需要真实数据，不能由当前总 DOS 推导。

### 4. SCDM 是备选子空间构造路线，不能作为当前窗口优化的无成本替代

Vitale 等以投影质量拟合能量权重，自动确定 SCDM 的 μ、σ，并以 DFT 插值误差评估。它改变初始子空间构造方式，仍依赖 Wannier 维数、能量权重及底层波函数接口；并不天然保证目标态全部保留。直接更换当前 Mori 投影，会改变实验基线，应另行评估。

## 推荐方案：先形成可信候选，再用固定目标验证

以下为基于文献和代码的项目建议，尚不是用户已确认的生产实现设计。

### 第一步：固定准确描述的目标能区

以共同 F2 E_F 为基准，至少覆盖现有质量窗 E_F±0.5 eV，并取与实际 EPC／超导电子费米窗口的并集。当前 `fsthick=0.4 eV`；实现时按目标 EPW 版本的实际取态语义核对，不能将 Matsubara 截断 `wscut` 误当作 Bloch 电子窗口。

将目标能区、候选比较用参考点、最终独立复核点、匹配规则和误差门在候选运行前固定。若以后扩大目标能区，重新评估子空间容量；不通过缩小验收窗掩盖失败。

### 第二步：四个边界分别确定依据

| 边界 | 候选生成依据 | 必须拒绝的情况 |
| --- | --- | --- |
| `dis_froz_min` | 至少低于目标能区下缘；比较保留深价态的基线与适度收窄候选，有投影时再检查是否误纳无关态 | 目标低能态落到冻结窗外，或靠裁掉失败态通过验收 |
| `dis_froz_max` | 至少高于目标上缘；受逐 k 点冻结态数限制；投影质量可辅助识别何处不宜继续冻结 | 冻结态数超过 N、目标上缘无法覆盖或投影依据缺失却声称已验证 |
| `dis_win_min` | 不高于冻结下界，保留构造平滑子空间所需的低能候选；根据谱结构提出有限候选 | 任一点外窗态数不足 N，或裁掉目标态／必要混合态 |
| `dis_win_max` | 不低于冻结上界，容纳足够候选及有用反键／高能混合态；既检查态数，也检查输入空带覆盖 | 仅用“第五带刚够”宣布最优，或在缺少输入空带的范围声称完整 |

当冻结窗从所有输入态的底部起算时，可用 `min_k ε_(N+1,k)` 作上界预筛；一般情况下须对实际区间计数。外窗同样必须按两端点共同计数。端点避开简并簇并保留与输出精度相称的余量，不能利用数值舍入人为拆开本应一同处理的态。

### 第三步：先使用现有数据做静态筛选

复用现有 NSCF、输入与实际日志，枚举谱间隙或预定义边界附近的小集合，而不是连续四维大扫描；输出每个候选的四界、来源、逐点计数范围、最差 k 点与淘汰原因。有可信投影时追加投影质量／秩诊断；没有则标记为能量依据候选，不伪造轨道判定。

若目标窗内本身就有超过 N 个必须保留的态，或者能量约束无可行解，应报告“当前子空间／方法不满足目标”，交由用户决定是否扩基底或更换方法，不能自动增轨道、缩窗或删验证点。

### 第四步：有界原生对照并复核稳定性

后续经设计确认进入实验时，冻结基线输入、程序身份、候选集合、最大尝试数和资源上限；资源继续记入同一累计账本，另立需求编号不重置预算。仅在适配确认可复用时重用原始 Bloch 基底的 `.mmn`／投影等数据；改变窗口后须重新解纠缠／局域化，不能复用旧旋转矩阵或旧 Wannier 规范的 EPC 矩阵假装新结果。

候选选择集可用于比较误差；最终独立复核集不能在选窗时反复查看调参。不够的独立参考另行固定并计入预算。先按目标窗内态的完整覆盖、原生收敛及电子最大≤0.05 eV、RMS≤0.02 eV 过滤，再结合最大／RMS 误差、窗口小扰动稳定性与 spread／实空间局域性给出排序；不能只按 spread 最小选胜者。

同时报告费米能附近穿越及可获得的速度／DOS 诊断；缺独立速度或足够密网格时不声称费米面拓扑已验收。稍微移动边界的结果明显改变时，应报告敏感而非稳健。具体候选数、扰动步长和稳定性量化门在正式 Plan 前确定，当前不擅自给出新的硬门。

## 对当前 MgB₂ 的具体建议

保留当前四边界作为原始对照，尤其保留 `dis_froz_max=8.8 eV` 的出处。先把三个隐式边界连同实际默认语义显式记录，再完成静态可行性筛选；是否写成新的原生输入，应核对日志端点舍入与实际全精度本征值，不能简单照抄五位小数认定完全等价。

现有态数统计证明有收窄外窗或改变冻结窗的可行空间，但没有证明哪组候选最好。目前不能负责任地给出新的“最优四个数”。推荐交付是带理由、约束及失败说明的候选报告，经过原生对照和独立复核后才发布推荐值。

电子选窗可能改善电子子空间，不保证修复当前声子 RMS 8.075133 cm⁻¹ 的问题。声子仍按最大50／RMS2 cm⁻¹ 阻断下游；不能以窗口优化研究替代声子根因分析。
