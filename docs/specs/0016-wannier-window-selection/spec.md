## 背景与目标

当前 MgB₂ 仅显式给出冻结上界，其余采用默认值；已有工具提供带号／态数启发式，但没有与 epwflow 的目标能区、独立误差及版本能力形成完整选窗流程。本需求先建立可信现状与外部证据，再定义可验证的改进能力。

### 需求结论与变更取舍

首次按要求先说明当前选择并完成一手调查。后续用户明确指定子仓库和默认组合模式，并两次要求完成接入、弃用旧方式，因此本次按该范围实施，不重复请求模式或实施许可。旧分阶段优化建议不再作为主方案。

## 用户场景与验收

### US1：了解当前选择及其依据（P1）

用户能看到配置值、默认值、实际使用值和能量参考。**优先级理由**：没有可信现状就无法比较改进。**独立验收**：由实际输入与日志复核四界。

1. 假如输入仅给冻结上界，当检查现有计算时，应同时展示另外三个实际边界、默认来源和共同 E_F。
2. 假如缺少实际日志，应报告未知实际窗口，不能用绘图范围补造。

### US2：根据开源与论文判断改进方向（P1）

用户能比较能量启发式、投影辅助、投影解纠缠和 SCDM。**优先级理由**：避免凭经验猜参。**独立验收**：每项关键结论可追溯到读过的一手材料，并说明当前版本是否适用。

1. 假如方法需要规范化投影或较新版本，应明确缺口及替代方案，不静默写入不支持的参数。

### US3：两套 flow 使用指定上游默认组合方案（P1）

用户在 epwflow 与 wannierflow 中得到相同选窗行为。**独立验收**：真实本征值驱动平移与限制，默认投影阈值进入最终原生输入；旧带号启发式不可执行。

1. 若不显式覆盖，生成上游默认冻结上界与投影阈值，其余边界保留原生默认。
2. 若逐点态数或输入数据不合法，拒绝生成可执行选择；缺少本征值时不得沿用旧固定窗。
3. 若实际程序无法核验投影解纠缠支持，执行前明确阻断，不切回旧算法。
4. 旧 `--auto` 返回明确弃用提示；`-n`／`-e` 保留只读分析用途。

## 边界与异常场景

- 排除带、能量参考、原生版本、单位或来源不一致，必须先拒绝依赖其结果的推荐。
- Rust 根据本征值确定能量约束；实际投影冻结由原生程序使用真实投影矩阵计算。不能用 DOS 或 Wannier 中心生成伪投影，也不能退化成纯能量算法后声称组合模式成功。
- 窗口端点简并、空数据、非有限数、目标覆盖不足、全部候选失败或预算不足，须输出可解释结果。
- 训练网格上的冻结态保持不能代替网格外质量；窗口缩窄不能改变已固定的验收样本。
- 本首轮真实目标为现有非磁性 MgB₂；不同自旋／自旋轨道情形须明确支持范围，不混合通道计数。

## 需求

### 功能需求

- **FR-001**：必须解释四边界的配置、默认、实际值及绝对／相对能量；未知值不得猜测。
- **FR-002**：必须先完成当前方案说明，再基于已阅读的一手开源实现及文献给出改进结论，记录版本和适用限制。
- **FR-003**：必须分别定义外窗、冻结窗、目标验证窗与显示窗，统一共同 E_F，保留来源身份。
- **FR-004**：两套 flow 必须共用指定提交的默认组合规则，包括能量平移、冻结上界限制与默认投影阈值；未设置边界不能补造成新的自动四窗算法。
- **FR-005**：必须基于实际本征值处理排除带并检查逐点外窗态数≥N、能量冻结态数≤N、区间包含与数据完整性；能量态数检查不冒充投影冻结结果。
- **FR-006**：默认约 2 eV 上界与显式覆盖都必须受上游上限限制，记录请求值、平移、上限、实际参数和本征值指纹；显式能量参考只转换一次。
- **FR-007**：必须让投影阈值及实际启用投影解纠缠所需的接口开关进入独立 W90／EPW 内嵌输入；对实际程序设置执行前必要能力门，关键字存在不冒充完整原生验收。
- **FR-008**：必须弃用旧带号自动选窗实现，不提供静默兼容回退；保留只读能量分析及已有结果读取，不改写历史科学输入。
- **FR-009**：数值规则须与固定上游函数差分核对；两套 flow 的输入生成、缺数据拒绝和旧 CLI 弃用均需行为验证。真实拟合质量仍采用既定电子双误差门，不能只评价 spread。
- **FR-010**：区分源码／输入接入、原生程序能力和新窗口科学质量；不自动改变基底、升级本机程序、扫描候选、扩大预算、恢复暂缓 PDOS 或绕过声子质量门。

### 关键实体

选择记录保存上游提交、模式、本征值指纹、共同 E_F、HOMO／LUMO、平移、请求上界、上限、最终参数、排除带与逐点能量态数；原生实际 Outer／Inner 仍由运行日志证明。审计记录保留其他可借鉴项及未完成边界。

## 成功标准

- **SC-001**：当前四边界100%具有可复核来源，含未显式给出的边界；无日志时100%明确未知。
- **SC-002**：调研覆盖至少两个开源项目与三篇相关原始论文，关键结论均附一手链接及适用限制。
- **SC-003**：epwflow 的两种原生输入与 wannierflow 的检查／初始化都消费共享选择，默认投影阈值为 0.01／0.95；缺失边界不被补造。
- **SC-004**：固定上游实际运行时函数与本实现的窗口数值在相同输入下误差≤1e-10 eV；真实 MgB₂ XML 只读核查保留来源。
- **SC-005**：旧带号算法代码已删除，旧参数明确报弃用；缺本征值、输入不合法或无法核验程序必要能力时不回退旧方式。
- **SC-006**：当前实际程序能力、未进行新原生计算及科学质量未验收如实记录；相关测试通过不被写成整个 EPW／超导链通过。
