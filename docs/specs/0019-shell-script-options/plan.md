# 实施计划

## 技术背景与设计

Rust 工作区由 qf-runner、qf-phonon、qeflow、wannier90flow、df-substitution 和 epwflow 输出 Bash 脚本；scripts/ 维护构建、安装和自测，test_auto/ 有跟踪的手动入口。删除注入，不建立新的选项开关或配置层。

先审计跟踪文件和生成器，移除严格选项，再对依赖自动退出的关键命令补充 `|| exit $?`；函数内部需要向调用方传播错误时使用 `|| return $?`。EPW 环境加载使用同一显式失败约定。保留已有 if/exit 检查、Rust 退出码和 Slurm 身份核验。

按 [快速验证](quickstart.md) 执行；覆盖实际脚本初始化和安装失败边界。无需提交真实计算或执行完整 Docker 构建；后者用语法和失败路径检查验证修改，不宣称新平台构建成功。范围简单，采用直接删除与显式判断，符合 KISS／YAGNI；复用现有错误处理，避免新脚本框架。
