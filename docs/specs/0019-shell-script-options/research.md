# 设计依据

## 移除注入，不更换拼写

生产脚本中不仅有组合严格选项，还有 QE／substitution 的单独 `set -e` 和 EPW 环境加载后的 `set -u`。统一移除这些自动开启项，不改成拆分命令、shell 启动参数或全局 ERR trap。用户 Slurm header 不过滤，冻结历史文件不迁移。

## 显式处理关键失败

删除隐式自动退出会影响环境加载、文件复制、程序校验和测试断言。保留已有判断，对必要命令补充局部退出码传播。未采用“直接删除后忽略失败”方案，因其会使安装校验和自测产生假成功；也不引入通用执行框架。

## 本地追踪约定

当前 0018 等 Issue 草稿明确由用户维护线上 Gitee。本次按同一方式新增本地 0019，并明确它不是已创建的线上编号；不执行线上关闭或擅自推送。
