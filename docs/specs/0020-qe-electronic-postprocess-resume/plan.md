# 实施设计

## 原生任务记录与数据流

电子适配器分别管理 PW 能带、bands 与 DOS。每份记录包含版本、任务键、原生输入身份、日志／退出码及产物身份；PW 记录完整 portable save 文件集合，拒绝新增、缺失或被改写的文件。任务键绑定局部科学请求、上游实际输出和程序，排除 MPI 启动数量；DOS 的展宽变化只更新 DOS。

输入生成先验证并保护已经完成的 PW 输入；同请求失败恢复不归档整个电子阶段。科学请求或上游身份不相容时按现有阶段历史机制更新，不复用旧结果。失败后重试先归档对应日志，完成记录原子写入。

## 一次性旧现场衔接

从已有终态尝试查找匹配的冻结配置，逐一核验结构、赝势、KPATH 和 PW 程序身份，重建原生输入并逐字比较实际输入。再核验零退出码、完成日志、结构、k 点、带数、与 SCF 快照一致的电荷密度及全部 portable 波函数。先提供只读检查，再在正常生成／运行入口写入新的任务记录，不更改旧尝试。

## 接口与错误

bands.x 在既有 MPI 启动器后使用自身 `-pd .true.` 参数，不继承 PW／EPW pool。保持脚本哈希验证，附加“重新执行公开命令生成新尝试”的提示。冻结尝试同时保存实际 bands／DOS 程序身份。
