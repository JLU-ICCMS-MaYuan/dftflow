## 首次真实提交发现的后处理适配缺陷

公开 -s 真实作业 1311765 退出 1，12 节点秒。EPW 已正常结束，解纠缠和局域化收敛，`.ukk/.chk/.wout` 通过校验并发布 Wannier 科学收据。后处理失败：独立 W90/postw90 报缺少 mp_grid。EPW 内嵌库通过参数直接提供晶格、原子、网格、k 点与带数，输出的 win 不包含独立程序启动必需的全部信息。独立程序为串行 3.1.0，io_error 使用不带状态的 Fortran STOP，可报错却退出 0，原实现仅检查退出码导致延迟到缺文件才报错。

补充设计：从已经校验的同一 NSCF XML 按原顺序提取晶格、原子、k 点、网格和排除后的带数，补全后处理 win，不从手写参数或另一个 POSCAR 猜测。复用 Geometry／nscf 校验，保持既有窗和投影。独立程序每次检查本次原生日志和 werr，零退出也必须无错误；历史 werr 先归档。W90 绘图无论成功失败都恢复拟合 wout，防止失败破坏已发布收据；下一次只重试后处理，不重新拟合。后处理缓存版本独立更新，不让 QE 或 Wannier 科学键失效。

进一步核对 W90 parameters.F90:1620–1665：独立程序还需要 `.eig`，原 EPW 库现场未生成。补齐同一 NSCF 的绝对 eV 本征值，严格保持实际 k 点次序，排除带后按 1-based 紧凑编号输出；不重新计算电子态。协议同时核对完整网格、结构、保留带数和 eig 的 k／带序。

每次后处理先归档旧错误、wpout、运行日志及原生能带／DOS 产物，再校验本次产物，避免旧成功文件掩盖本次缺失；原始拟合 wout/chk/ukk 不纳入归档。

新增协议校验还拦下实现期的 mp_grid 编码错误：共享 win 更新器仅为 dos_kmesh 特判数组，mp_grid 数组会写成 JSON；本模块显式提供原生空格分隔值，避免向 W90 传入方括号。该失败留在 numbered-regression.log，修正后的结果另记，未带错误构建重提真实作业。

## 并发命令锁提示与第四次调度失败

用户执行 -s 与本轮提交准备可能重叠；control.lock 属于登录节点命令（job_id=None），而 control() 先按旧 active 的 Slurm 作业尝试恢复，产生“锁不属于原分配”的不透明提示。现场复核时登录进程已结束、control/execution 锁均已正常释放，不是永久限制用户运行。保留恢复限制，错误增加锁路径、host、pid、Slurm 归属及等待另一条命令结束的说明；不以进程不存在或等待超时作为删锁授权。连续进程测试持有真实控制锁，验证第二条公开命令拒绝、保留锁和冻结配置且不重复 sbatch，释放后继续既有活动作业检查。
