# 实施依据与取舍

- 当前 `stages::reusable` 对清单所有输出直接 verify，NotFound 被提升为 input_conflict；修复在阶段复用层区分缺失，不放宽 Identity 的严格验证语义。
- 原完成回执位于独立隐藏树；改为阶段本地文件，删除目录自然删除完成身份。原生电子收据和后处理收据也归所属阶段。
- `.epwflow` 除状态还保存交付清单和冻结快照；不能只改 steps，也不能让旧 frozen script 在新路径继续运行。
- 迁移不对全体 JSON 做文本替换或重新捕获哈希：这会替改变过的科学证据背书。采用有界迁移，复用独立于旧隐藏路径的上游，保留旧后续交付为历史并要求重建。
- 原 0018 的内部状态路径条款由本项替代；科学数据所有权与 DAG 不变。旧来源读取只出现在迁移/导入边界，不扩散到正常查询。
- KISS/DRY：使用现有阶段、身份、复制与锁工具；不增加运行服务或第二套工作流。不改变真实计算参数和测试替身数值。
