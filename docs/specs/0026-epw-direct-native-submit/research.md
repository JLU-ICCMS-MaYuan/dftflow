# 0026 设计依据

现有 `workspace::script()` 将公开程序与 `--workspace-attempt` 写入实际 Slurm 脚本，是用户所见问题的直接原因；`native_script()` 也生成 `--workspace-task` 包装。仅打印原生命令不能解决问题。

采用作业外控制器与持久任务记录，复用已有输入生成器、原生日志校验器和插值／Tc 检查点。执行边界交回控制器时保留进行中状态，不作为计算失败。拒绝后台守护、节点内嵌套提交及多科学调用脚本，因为用户已选择手动推进和只保留原生命令。

Slurm 的终态与退出码来自调度记录；科学成功仍由已有收集器验证。COMPLETED 本身不替代输出完整性与来源验证。日志使用文件名并设置工作目录，避免跨目录手工提交改变落盘位置。
