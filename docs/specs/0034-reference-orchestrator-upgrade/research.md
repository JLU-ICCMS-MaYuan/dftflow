# 调查证据

当前质量参考请求的 sources[5] 指向可覆盖安装的 epw_wannier。references::resume_request 的编号分支虽比较前五科学来源，却随后遍历六项 Identity::verify；ensure_sources 又同时发布旧、新编排器来源，导致相同路径不同哈希。quality_binding::Frozen 也把所有 provenance 都当成活动数据。

程序升级不等同于 PW／PH／dynmat 或物理输入改变；后者仍要求完整身份相同。保留原始请求与参考文件、把精确绑定的编排器身份留作追溯，可保持原摘要及已完成子任务，不依赖原二进制永久在线。
