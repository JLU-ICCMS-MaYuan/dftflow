# 需求规格

原文见 [Issue](issue-draft.md)。

- FR-001：仅准确匹配 slurm-数字.out/err 的文件属于运行日志，不冻结为原生计算输入；恢复旧清单时忽略其日志项，但所有其余已绑定输入和输出继续严格核验。
- FR-002：工作区与原生粗网格重试归档共用当前日志同 inode 入口维护，历史保留，脚本哈希保护和科学门不变。
- FR-003：不修改旧请求或收据，不删除当前／旧日志，不引入严格 shell 选项。

SC-001：日志追加与旧记录恢复成功，科学输入修改仍拒绝；原生重试期间打开的日志保持同 inode／完整内容。

SC-002：规范构建安装后公开粗网格续算，不再因正常日志追加失败，当前日志仍可直接查看；上游及参考哈希、真实结果、预算和文档记录完整。
