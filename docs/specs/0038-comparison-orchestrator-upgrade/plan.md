# 实施计划

编号工作区显式续算核对原始请求摘要、相同科学配置及除第七项原编排器外的全部来源。原 CLI 仅历史追溯，当前版本由冻结提交记录追溯；复用原摘要驱动子任务恢复，不改旧 request 和成功子记录。旧非编号工作区仍严格核对全部来源，不忽略科学程序、矩阵或物理数据。

T001 对应 FR-001，核实实际原生日志与文件；T002 对应 FR-001/003、SC-001，增加复现和最小修复；T003 对应 FR-002/003、SC-002，构建安装后从公开入口续算，逐项哈希核对；T004 更新文档影响并按明确范围自动提交。保持 KISS／DRY，复用现有阶段、尝试与原生格式组件，不增加公共程序或物理配置。

FR-004 由 T002／SC-001 的真实 ELF 升级回归覆盖，每次公开提交自然产生新的 KPATH 快照位置；不把路径文字不同当成物理参数改变。
