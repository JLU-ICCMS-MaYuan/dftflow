# 实施计划

## 组件与数据职责

保留 native_quality 的原始达标布尔与配对来源契约，增加统一告警输出；quality_binding 继续严格重验当前数据，通过执行入口返回已校验的数值报告并按需告警。调度器的质量摘要记录 valid／warning，结构 validation 只证明来源和数据可用，不把数值超差混入硬失败。独立检查 CLI 超差返回 operation_status=ok、quality_warning，原 passed=false 保留。通用质量函数同样返回 warning 报告，缺失／非有限仍 Err。

所有粗／细／F4／工作流执行门替换数值 ensure，保留完整性和来源检查。复用合法 warning 清单仍重验原始来源；历史 valid 清单保持可读。图表和比较包继续显示实际 failed 质量，不改历史科学表或 passed 字段。最终交付的 workflow_complete 只反映原生数据与图表是否完整，质量超差单列 quality_warning=true，不能再因数值超差触发 finalize 的 partial 错误。F4 原生收敛、搜索次数与状态判定不改。
