# 调研与决策

实际提交等待与共享盘小文件延迟来自 fine-submit-0040.strace；串行循环位于 stages::Completion::{available,verify}。优化采用 std::thread::scope，每批最多 8 线程，原 64 KiB 逐块读在实际提交中产生了 7.5 万余次 read、读取 4.3 GB 且 CPU 仅数秒。将 hash_file 改为 1 MiB 堆缓冲以减少往返，8 路缓冲最多 8 MiB，避免线程栈压力。保留所有身份校验，避免使用 mtime／文件大小代替内容哈希。未采用跨调用缓存，防止后续篡改被漏检；未重构科学阶段依赖，以控制修复范围。共享盘延迟与其他串行开销可能仍存在，验收不承诺某个固定秒数。
