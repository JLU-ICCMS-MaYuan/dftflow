# 实施计划

## 已确认设计

抽样参考链完全删除；常规图表及最大差值负责事实展示，用户负责科学判断。公共程序维持 epw_phonon、epw_wannier、epw_superconductivity。

## 数据与职责

1. 配置／调度：删除 Quality 配置、快照与专用来源依赖、质量状态及阈值。粗网格原生输入关闭抽样 band_plot；常规比较重读保留，并使用明确的比较用途名称。共享来源指纹类型迁入比较组件，不能保留整个抽样模块以借用类型。
2. 比较：常规 QE bands、QE mesh、q2r/matdyn 和 EPW 重读构成唯一对比来源；实际 Outer 窗为显示和电子配对范围。移除直接抽样点表和图中抽样专用标记。数据契约采用新版本，不在新包写旧质量字段。
3. 最大值：在比较组件直接处理路径切片和已有 DOS 网格切片；电子抽取无阈值的有序最小平方匹配，保留原带索引；声子统一单位后排序逐模比较。空结果为 null；存配对数量、未匹配数、坐标和原值，绘图只消费该结果。
4. 结果：比较包和总结果分别核验文件、来源和执行完成，不再读取质量评级；最大值不改变流程。版本化读取历史自包含图包以维持重绘，历史记录不改写。旧活跃运行不自动升级；已有上游只经现有导入复用，旧配置兼容仅限定在历史导入边界。

## 差值数据契约

`metrics.json` 与比较清单使用版本 2。`differences` 的四个键为 `electronic_path`、`electronic_mesh`、`phonon_path`、`phonon_mesh`，每项保存：

| 字段 | 含义 |
| --- | --- |
| unit | 电子为 eV，声子为 cm-1 |
| points | 参与统计的常规点数 |
| paired_states | 所有点的配对总数 |
| unmatched_qe_states、unmatched_epw_states | 显示窗内两侧未配对态总数 |
| maximum | 最大值记录；无配对为 null |

`maximum` 包括零起始的原始 `point_index`、晶体坐标 `crystal`、路径距离 `path_distance`（网格为 null）、一起始的 `qe_index`／`epw_index`、共同零点及单位下的两侧原值和 `absolute_difference`。电子保留原始带编号，声子为排序模式编号；不以数值配对推断本征态身份。最大值并列时保留原点顺序中首次遇到的配对，不添加容差阈值。

常规 bands 路径输入由共享 QE 适配器生成；完整均匀 NSCF 仍只供 EPW 主科学数据与 DOS 网格。历史导入只移除已经废弃的质量小节及 dynmat 程序核验要求，原始绑定文件不改写，主科学来源仍逐文件严格核验。
