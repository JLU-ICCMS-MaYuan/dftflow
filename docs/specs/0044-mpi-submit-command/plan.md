## 技术上下文与结构

Rust 2021／Bash，复用 qf-runner、shell-words、现有 Cargo 集成测试与安装工具；目标为 Linux／Slurm。qf-runner 提供参数数组和科学命令前缀转换；QE resolver、VASP 和 Wannier 在拼接重定向前调用；EPW 在写新原生脚本时转换，保留历史任务键与记录。组合流程复用下层生成器，无第二套解析器。

字符串只扫描第一个 shell 词（以及普通 exec 后的程序），只改对应字节范围，保留其余文本。完整 argv 路径不经 shell 求值。mpirun 的配置不依赖登录 PATH，其余启动器保留既有定位校验。仅新生成命令不固定 MPI 文件身份。
