# 0044 设计依据

## exec 与退出码

Bash help exec 明确其替换 shell 进程。单调用作业不依赖这种替换，普通末尾调用保留退出码；多调用脚本继承既有显式失败判断。只改科学执行前缀，不触碰构建包装、测试替身或用户 header。

## 配置与启动器身份

epwflow 的 Config::resolve 原来调用 paths::command 把裸 mpirun 解析为登录 PATH 文件；native_jobs::prepare 又固化命令及绝对可执行文件身份。改为 mpirun 不预定位，新脚本写命令前规范化，记录来源时跳过此启动器，继续记录科学程序和环境。历史 task key 及已持久化 argv 不回写；新 Task.command 保存实际规范化的命令，任务查找仍用原配置请求键，已有记录校验规则不削弱。

## 跨模块复用

qf-runner 是 QE／VASP／Wannier 共享层，EPW 增加直接依赖复用转换。转换限于科学调用串的起点；已有复合脚本在嵌入命令前接入，避免修改 echo、注释、数据或控制流。不另写任意 Bash 解析器。

## 部署与迁移

当前 PATH 中 QE／VASP／Wannier 等指向固定 current，EPW 仓库 bin 已有独立制品，两者都更新。源码导出自提交，复用私有运行库打包，记录提交及源／打包／安装哈希。现用配置和未绑定脚本可更新；冻结 unique script、快照及科学文件保护，必要时仅另建调试副本。无真实 sbatch。

KISS／DRY：一份共享前缀转换，所有模块在拼接复合命令前调用，不建立任意脚本解析框架。VASP 多步优化与 LOBSTER 后续回显原来依赖 exec 提前结束，改普通调用后必须显式保存非零退出，避免复制或完成提示掩盖科学失败。
