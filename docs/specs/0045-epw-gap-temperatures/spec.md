## 背景与目标

用户在 TOML 列出温度，通过 README 的公开命令完成这些温度下的超导能隙计算。温度列表属于通用产品配置，MgB₂ 本例选择 20、30、40 K。

## 用户场景与验收

### US1（P1）：按温度列表计算能隙

用户选择 iso、aniso 或 both，列出温度后运行第 8 步。独立验收：三个温度、both 恰好产生六个首次原生非线性求解；无额外温度、Tc 线性分类或第二初值。

### US2（P1）：逐点查看结果并续算

用户查看每点是否正常结束、是否收敛和能隙文件。独立验收：中途失败后显式恢复只补未完成点，成功记录不被覆盖；未收敛但正常结束的原生任务如实报告，不以原生退出 0 声称能隙有效。

### US3（P1）：保持旧流程并完成实际使用

旧 TOML 仍执行 Tc 工作流；新配置由实际安装的三个公开程序识别。独立验收：旧 Tc 回归及新配置安装回归通过，MgB₂ 六点由公开命令真实完成，README 可复制。

## 功能需求

- **FR-001**：新增明确的计算任务选择；缺省保留 Tc 搜索，指定温度任务不要求 Tc 区间、精度及双初值设置。
- **FR-002**：所选 iso／aniso 模式与温度列表作笛卡尔组合，每个组合只按单个配置初值执行非线性能隙求解；不隐式扩展温度或搜索 Tc。
- **FR-003**：温度必须有限、为正、可表示为 0.01 K 刻度、互不重复，并符合当前原生格式和截断要求；非法输入在提交前拒绝。
- **FR-004**：复用原生 EPW 求解与现有公共 CLI、提交及预算能力；不增加独立脚本工作流或第四个公开程序。
- **FR-005**：逐点保存输入、实际温度／模式／初值／数值设置、程序与上游身份、日志、退出码、正常结束和收敛状态；可用且有效的能隙保存完整 Δ／Z 与真实逐态身份，缺失或无效数据明确标记。
- **FR-006**：各点原生正常结束即可满足本次运行验收；数值收敛和数据有效性另列。非零退出、缺完整结束、预算不足或来源损坏阻止阶段完成；不以 NaN、缺文件、未收敛数据发布有效能隙，不强制得到非零能隙或合理 Tc。
- **FR-007**：支持成功点重验复用和失败点显式恢复；活动或未知作业不重提，配置／来源冲突拒绝，不清零历史预算或覆盖旧尝试。
- **FR-008**：保留旧 Tc 模式、旧清单读取及既有收敛验证语义；指定温度模式不生成虚假的 Tc 区间或数值。
- **FR-009**：用户可显式选择目标 EPW 支持的线性混合或 Broyden 参数，透传并记录；不为收敛暗中切换混合、初值、温度或标准。
- **FR-010**：更新实际仓库 EPW 安装、配置示例、结果归集／绘图和操作说明；完成公开 CLI 的真实六点验收后才可称已接入。

## 关键实体

运行计划由任务、所选模式、温度列表及单初值构成；每个点关联原生尝试及执行证据；能隙数据和 Tc 搜索结果是不同类型的交付，不能相互冒充。状态与字段设计见 [数据模型](data-model.md)。

## 成功标准

- **SC-001（FR-001～004）**：隔离公开进程验证 iso／aniso 各三点、both 六点；执行温度集合与配置完全相同，无 Tc 搜索或双初值调用。
- **SC-002（FR-003/005/006/009）**：非法温度／设置、错模式／温度、非零退出、缺结束、未收敛、NaN 和缺 Δ／Z 的测试均按契约区分执行与数据状态；收敛数据的单位与完整性检查通过。
- **SC-003（FR-007/008）**：恢复不重算成功点，未知作业拒绝重提，篡改拒绝；旧配置、旧 Tc 搜索及交付回归通过。
- **SC-004（FR-004/005/006/010）**：当前目录 PBE 的公开命令实际完成 20／30／40 K 两模式六点，保留 EPW 正常结束及 Slurm 终态，逐点报告能隙与收敛；不能用历史手动六点替代。
- **SC-005（FR-008/010）**：实际安装来源与已验证提交对应，安装程序读取新配置；结果包、重绘和 README 均表达指定温度任务，Tc 未请求时不填 Tc。
