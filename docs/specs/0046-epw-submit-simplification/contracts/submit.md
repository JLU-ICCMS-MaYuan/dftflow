# 0046 提交行为契约

三个公开命令和参数不变。正常顺序重复调用仍依据已记录作业号判断活动／完成／失败／未知；不再以工作区 control.lock 或 execution.lock 判断是否可以操作。

新原生脚本为 `<功能>.sh`，两路 Slurm 日志为 `slurm-<功能>.log`，设置 truncate；只在正文 cd，不传 --chdir。QE/EPW 将原 -inp/-in 参数转为 `< 输入 > 输出 2> 错误`，其余参数和 MPI 资源保持原样。Wannier 种子接口保持原样。source 环境后直接执行科学命令；source 失败没有额外自动退出包装，科学命令失败仍返回非零。

旧残留目标锁忽略并保留；预算与其他用途的锁维持原行为。固定脚本与 Slurm 日志可覆盖，科学文件仍不可悄悄修改。多命令同时修改同一工作区不提供互斥保证。
