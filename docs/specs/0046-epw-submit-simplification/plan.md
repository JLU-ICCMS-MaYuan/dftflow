# 0046 实施计划

基线为 [Spec](spec.md) 最新收窄范围及用户“开始落实”指令。只改 Rust/Bash 生产路径与必要测试，不安装、不真实提交、不更改预算、科学配置及其他锁。

## 设计与职责

1. 工作区入口只检查目录就绪、已有作业与回执，不再获取或恢复控制／执行锁；旧锁既不读取也不自动删除。阶段求解同步去掉 execution 锁。迁移专用锁与其他锁保留。
2. `native_jobs` 负责固定功能脚本、Slurm 日志与科学输入输出重定向；提交 cwd 使用现有 `current_dir`，正文保留 cd。安全字符直接呈现，特殊参数按 Bash 双引号转义。环境脚本直接 source，科学命令为最后命令以传播退出状态。
3. 新任务采用版本 2：科学 stdout/stderr 直接来自 `<stem>.out/.err`；版本 1 历史任务继续按原日志回收规则读取。提交前和活动任务仍校验脚本；版本 2 终态不依赖可覆盖脚本及 Slurm 日志，科学输入、来源及输出校验不变。
4. 固定脚本与 Slurm 日志不作为阶段科学产物或后续尝试输入。保留现有三份任务记录与全部预算接口。
