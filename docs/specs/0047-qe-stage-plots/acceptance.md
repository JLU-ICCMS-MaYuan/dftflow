## 实现

- 电子叶任务核验／复用时立即绘图，数据来自 PW 原生 XML／dos.x TDOS，使用已核验 NSCF 的 Fermi 零点。复用现有电子渲染函数，不依赖声子或 Wannier 能窗。
- 声子后处理接入 qf-phonon 的表格、元素聚合及绘图，要求完整的原子投影列与递增有限频率轴，不用部分投影代替元素结果。
- 图像放在阶段 `plots/`，独立登记完成清单；科学证据排除派生图，数值后处理另存检查点。删除图或修复绘图失败后可补图，成功科学调用保持不变。
- 电子叠图保留；声子 DOS 独立图及总览只画两侧 TDOS。新导出不再将插值元素声子投影列为缺项；旧包仅含该缺项时不显示 PARTIAL，其他缺项照常处理。粗阶段后处理版本更新触发旧样式重绘。

复用既有表格／绘图库体现 DRY；单独模块只管理派生图，保持组件职责；不增加配置、公共 CLI、依赖或调度框架，保持 KISS／YAGNI。
