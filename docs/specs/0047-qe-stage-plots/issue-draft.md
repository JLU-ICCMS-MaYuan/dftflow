## 问题与目标

目前第 3 步只执行电子能带和总 DOS 数据任务，电子图在第 5 步 Wannier 后处理中生成；第 4 步 q2r／matdyn 结束后也没有接入即时绘图。用户需要先检查各步已算出的 QE 结果，再看后续插值与 QE 的叠图。

## 范围与预期结果

- 第 3 步：`qe_eband` 成功后立即生成仅 QE 的电子能带图；`qe_eledos` 成功后立即生成仅 QE 的电子总 DOS 图。两者不等待 PH、Wannier 或 EPC。
- 第 4 步：QE 声子后处理成功后，生成仅 QE 的声子谱、总 DOS 和元素投影声子 DOS，保存在对应 `qe-phonon` 阶段。
- 第 5 步：保留 QE 与 Wannier 插值电子能带、电子总 DOS 的叠图，不覆盖第 3 步 QE 单独图。
- 后续声子插值数据就绪时：保留 QE／EPW 声子谱叠图，声子 DOS 对比只画两侧 TDOS；元素投影只在 QE 声子阶段展示，不生成元素投影对比面板，也不因缺少插值侧元素投影把 TDOS 对比标为缺项。

## 可验收结果

1. 无第 4／5／6 步产物时，第 3 步仍可完成并自动生成两张 QE 电子图；一个电子子任务完成即可看到它自己的图。
2. 无 Wannier／EPW 插值结果时，第 4 步后处理完成即可查看 QE 声子谱、TDOS 和真实元素投影，MgB₂ 可辨认 Mg／B 贡献。
3. 第 5 步生成的两张电子叠图均含 QE 与 Wannier 曲线，先前 QE 单独图仍可读取。
4. 声子叠图按现有可用插值阶段产出；DOS 面板仅含 QE／EPW TDOS，不画元素投影及其缺失占位。
5. 缺失投影数据不得用总 DOS、模式编号或零曲线冒充；仅补图不重复已成功的科学计算。详细场景见 Spec 的 US1～US3、SC-001～SC-006。
