# 研究与决策：QE 分阶段即时出图

## 现状分类

这是编号工作区主路径缺少即时绘图；不是 QE 未生成数据，也不是必须等待 Wannier 的科学依赖。当前 -s 作业内只跑原生科学程序，任务结束后再次调用公开命令完成核验和推进；本功能在该核验调用中立即出图，不向原生作业插入 DFTFlow 包装命令。

## D1：电子结果独立绘图

决策：沿用现有 Plotters 电子绘图层，增加单侧入口；能带使用已校验 PW 原生 XML 的本征值、k 点和真实路径分段，DOS 读取原生 TDOS。两者用 NSCF XML 的 Fermi，不读取 Wannier 窗口。

理由：电子数据已经完备；单侧图无需等待声子或拟合。路径根据实际点数和原生倒格矢计算，跳段不连线。

备选：提前调用现有两侧对比函数不可行，因为它要求 Wannier 文件；另建 Python 绘图违反生产语言边界；不采用。

证据：workspace_electronic.rs 的三种原生任务回执、workspace_plot.rs 的现有绘图，以及 stages.rs 的 Electronic 依赖。

## D2：共享声子绘图与严格元素数据

决策：将原生频率、路径标签、逐原子 DOS 复制到本阶段 plots 的绘图输入子目录，调用 qf-phonon 表格、谱图、DOS 与联合图。绘制元素图前严格核验每行包含频率、TDOS 和全部原子的贡献。

理由：共享组件已按结构顺序聚合元素，不再维护第二套科学投影。现有共享表格会截取可用原子列，因此本入口额外验证完整列数，避免把部分投影当成完整元素贡献。

备选：根据模式编号、Wannier 中心或零值补足投影不可靠；不采用。

## D3：插值声子比较只展示 TDOS

决策：声子 DOS 独立比较图使用单个 total 面板，总览继续使用 total；新导出不再把未要求的 EPW 元素投影列为 missing。历史数据文件保持原样，重绘时也不生成元素投影面板。

理由：用户明确只在 QE 单侧看元素贡献。电子投影的既有暂缓范围不因本次变更而扩展。

## D4：派生图像与科学复用分离

决策：图像与派生表位于 plots/，使用已有 Identity 与原子写入保存轻量完成清单；科学完成证据排除该目录。原生电子回执先落盘再绘图；声子 q2r/matdyn 数值产物使用阶段内检查点，绘图失败后可重验并直接补图。复用阶段也检查派生图是否缺失。

理由：缺图不等于科学任务失败；同时不能绕过来源损坏检查。原生 -s 已有逐任务成功记录，补图不应产生新提交。

备选：把图像加入科学 completion 会导致删图触发重算；无条件每次重绘会在逐原生任务推进中反复产生大量图像 I/O；均不采用。

## 兼容与任务边界

已有合法科学回执缺 plots 时直接补图；不改旧科学回执的数据身份。不修改历史原始产物和独立运行目录。与 0046 并发修改重叠时保存任务前基线并只提交本次增量，不包含其锁或脚本调整。
