# 数据与状态

点清单版本 4 保留 plan／attempts／execution_complete／data_complete，增加批次与日志关联；版本 3 按历史规则读取。点身份仍为方法＋0.01 K 整数温度。

方法批次包含固定请求列表、目录、原生任务键、批次序号及已收集标记。Task 增加可选方法分组，iso／aniso 各一个活动指针；历史未分组记录维持 native-active.json。来源与程序身份沿用原字段。

批次点记录版本 2 绑定完整温度序列及不可变输入／日志快照，逐点记录完成、收敛和能隙状态。已完成前缀可在后续点异常时保留；尚未开始或异常中断点不算完成。原生成文件按温度后缀保留，不迁入温度子目录。

恢复读取已确认调度终态，收集旧批次后只选择未完成点。旧失败记录不被改成成功。旧单点版本 1 与点清单版本 3 的路径和哈希维持校验，不搬迁历史结果。
