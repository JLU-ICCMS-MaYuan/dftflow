## 目标与范围

`task="gap"` 的一次公开命令提交全部选定方法，每种方法一个独立 Slurm 作业、一次 EPW 多温度执行。两方法互不依赖，由调度器决定启动时间。目录为 `iso-mu<实际值>-<起始温度>-<终止温度>` 和 `aniso-mu<实际值>-<起始温度>-<终止温度>`，同方法温度共目录。默认 mu_star=0.13，显式值优先。温度边界按配置列表首尾显示，保留配置顺序与全部点。

## 验收与关闭条件

1. both、20／30／40 K 一次命令提交两个作业，各包含三个温度；单方法只提交一个，无逐点重启要求。
2. 每点执行、收敛及完整 Δ／Z 证据可区分，错误／缺点不能冒充完整。
3. 失败与未知回执不丢失另一方法；恢复只补未完成点，成功／活动／未知任务不重提。
4. 目录反映实际 mu 与首尾温度；省略 mu 使用 0.13，显式其他值保留；旧清单可读，旧 Tc 行为回归。
5. 通过公开进程、实际脚本与受控原生 IO 回归；文档同步后报告源码、安装与真实科学运行边界。线上关闭还需平台链接与 Documentation Impact 核验。
