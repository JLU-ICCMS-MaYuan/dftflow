# 实施计划

## 摘要与技术上下文

Rust／Bash，复用 native_jobs 的脚本生成、提交、账本与 sacct 核验。指定温度阶段新增方法批次执行器，不增加依赖、公共程序、后台控制或工作区锁。脚本直接执行 mpirun EPW，普通输入输出仍在方法目录。

## 实现

配置添加 mu_star 默认 0.13 与原生 50 点上限。新批次执行器负责方法分组、首尾目录名、完整 temps 输入、独立原生任务和逐温度结果。native_jobs 增加有界的 iso／aniso 活动记录与可复用提交／终态核验函数，旧单任务路径维持。

同方法恢复前保存本批输入日志快照；新批次只包含未执行完成点，全部原生温度文件仍共目录。点清单使用版本 4，读取版本 3；批次点记录用版本 2，旧版本 1 仍校验单点日志。结果归集继续消费逐点接口，不复制第二套结果包机制。

## 验证与交付

公开 CLI 实际执行受控 Slurm 与原生 IO 脚本，覆盖双作业、早停、恢复、未知回执、来源损坏、单方法及旧 Tc。构建采用 scripts/build-native.sh；保存初始脏文件，按明确路径及共享文件补丁隔离提交。不部署或提交真实科学任务。
