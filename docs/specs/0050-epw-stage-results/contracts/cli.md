# 执行、发布与兼容契约

本契约为待审阅设计，不宣称以下能力已经在当前安装或源码中落地。

## 公开接口边界

保留 `epw_phonon`、`epw_wannier`、`epw_superconductivity` 三个公开程序及已有配置、阶段和恢复选项。用户现有 `epwinput.toml` 无须因目录变化改名。不新建专用于比较或发布的公开可执行程序。

现有提交命令在作业提交后仍可立即返回；“作业内自动完成”指该作业执行到成功收尾后，无需用户再次运行公开命令来触发后处理、出图或发布。只读状态查询继续只读，不承担补图或登记。自动收尾不意味着自动提交下一物理阶段。

旧 collect／plot／results check 等内部或已有交付入口，应统一识别新阶段包和已知旧包；实施前核对其现有参数，不凭本文增加新 CLI 参数。独立重绘只读数据／图参，不调用科学程序。

## 原生调用约束

| 阶段／任务 | 允许路线 | 禁止的重复或隐式路线 |
|---|---|---|
| 第 5 步拟合及能带 | `epw.x` 输入 wdata 传递路径与绘图参数，读取内嵌 Wannier90 输出 | 外部 `wannier90.x` restart=plot；以粗网格为电子出图依赖 |
| 第 5 步电子 DOS | `postw90` 读取已有模型及已有 NSCF 派生输入，仅做 DOS | 重新拟合；为 DOS 执行 Eliashberg／第 6 步 |
| 电子 QE 参考 | 读第 2／3 步，必要时从已有能量重累计表格 | 比较过程中另做同一 PW／NSCF |
| 第 6 步 QE 声子 | 读所选第 4 步相容力常数／频率；确缺采样才最少后处理 | 相容数据已存在仍 q2r／matdyn；切换另一声子模式凑来源 |
| 第 6 步插值声子 | 读已有插值样本，缺少时用现有粗网格结果最少求值 | 为重画重复粗网格；重算电子对比 |
| 独立重绘 | 只读结果包表格和图参 | QE／EPW／Wannier／postw90／sbatch 调用 |

输入生成前须检查 wdata 实际容量、路径表达与窗口设置；输出后必须验证真实采样坐标。必要程序执行前保存 [必要计算说明](../data-model.md)，程序失败按现有退出语义传播，不伪报成功。

## 数据读取与比较前置条件

先核验结构、模型、来源清单、配置身份及文件内容；再核验两侧真实坐标、路径分段、网格／权重／偏移、单位、共同费米能、展宽、自旋和 ASR。点数一样或标签相同不构成相容证据。

- 可逆单位／坐标表示转换：记录变换及来源后允许读取。
- 缺必需派生样本：在说明具体缺项后允许最少求值。
- 身份冲突、文件损坏、未知计数／规则或不能精确对应的路径：拒绝对应比较交付，保留已有科学结果；不能静默降级成成功。
- 第 6 步总览只读取第 5 步已核验电子包，不能用另一拟合或旧窗口的表顶替。

## 发布后置条件

阶段成功交付必须同时满足：

1. 对应数据／来源及比较口径核验完成。
2. 应有图片和对应数据、图参、窗口／差值说明完整。
3. 阶段包发布校验完成，根导航可定位相应完整单元。
4. 最后记录该单元／阶段最终交付成功；科学证据仍以原工作流机制为权威。

第 3 步每个电子子任务独立触发上述流程。第 4 步元素投影完整性继续遵守 0047；第 5 步两张电子图先发布；第 6 步两张声子图及四面板总览使用第 5 步电子表；第 7／8 步仅接入已有图表。

## 失败与恢复

| 故障 | 用户能看到的事实 | 恢复行为 |
|---|---|---|
| 原生任务失败 | 具体任务、原因及现有科学检查点 | 沿用已有显式恢复规则，不越过失败 |
| 比较口径不相容 | 差异字段、来源及未交付图 | 先解决输入或派生方案，不改写原科学文件 |
| 仅图片失败 | 科学结果有效、该图未交付 | 只补图及发布 |
| 发布／索引更新中断 | 完整单元可核验，未完整单元不能标成功 | 重验 journal 和清单后补余项，不重新计算 |
| 重复公开请求 | 已交付来源仍需核验 | 不新增成功科学调用，活动／未知作业不重复提交 |
| 旧布局缺少新位置 | 显示已知旧来源及校验结果 | 只导出派生结果，不因目录变化重算 |

作业内部必须处理本阶段所有应有收尾，不能把“等待用户再运行一次 -s”作为成功正常路径。父尝试失败与科学证据复用区分，恢复不能把成功的原生程序再次执行。脚本保持可读的原生命令，失败传播应显式处理，不引入 `set -euo pipefail`。

## 可移动结果与有界兼容

结果包清单只用包内相对路径引用重绘数据，来源绝对路径可保留为审计说明。完整 results 移动后，校验和重绘应在不访问原工作区、不调用科学程序的环境通过。

已知旧版本读取集中在布局／交付边界：旧科学产物、冻结脚本、回执和历史报告不改；新请求一律写新契约。识别不了的版本、来源或模式应明确报错，不递归扫描所有阶段“碰到什么就用什么”。
