# 未来实施后的快速验证

本文是验收操作设计，**本轮没有执行其中命令**；当前源码／安装不保证已具备目标行为。完整条件见 [Spec](spec.md)，记录位置见 [acceptance.md](acceptance.md)。

## 准备

选用隔离测试工作区；固定当前配置、结构、模型身份和所选声子模式，记录科学文件集合及哈希。已有结果先核验，不复制未知或冲突来源。先核对当前执行程序与版本，区分源码、编译产物、安装和真实作业证据。

普通回归计划使用仓库构建脚本，避免直接 Cargo 环境差异：

```bash
CARGO_PROFILE_TEST_DEBUG=0 bash "scripts/build-native.sh" test -p epwflow --no-fail-fast
```

实际原生计算与 Slurm 提交只有在已有独立授权及预算覆盖时执行，不能因为这是 quickstart 就自动启动。

## 第 5 步独立电子交付

在仅有有效第 1～3 步电子数据、没有第 4／6 步产物的隔离工作区，按现有入口提交第 5 步，例如：

```bash
epw_wannier -c "epwinput.toml" --stage wannier -s
```

这是将来的验收调用示意；不在真实用户工作区直接试跑。只执行一次，等待生成的作业脚本自行结束，之后直接读取 `results/5.epw-wannier/` 与 `results/index.json`，不再次调用公开命令触发绘图或登记。

核对电子两图、QE 与插值曲线、实际四窗口、最大差和未配对态说明，以及配套表、图参和来源。检查 `5.epw-wannier/comparison-native/electron/`；记录无 PH／粗网格依赖。调用账目证明能带由 epw.x 内嵌 W90 输出、没有外部 wannier90.x 绘图，postw90 只做 DOS。

另外使用非等长段、断段和共享端点路径核对实际 `.kpt` 坐标。点数／坐标不相容的输入必须明确拒绝完整对比，不能仅缩放横轴通过。

## 逐阶段即时发布

分别验证第 3 步能带先完成和 DOS 先完成：另一子任务阻断或失败时，成功子任务的单侧图和数据仍立即可见。第 4 步在所选模式下交付单侧声子谱、TDOS 和真实元素 DOS，不等待插值。

第 6 步使用已有电子包及粗网格结果，检查声子两张叠图和四面板总览。元素投影只在第 4 步单侧图内；第 6 步不新增电子参考、拟合或电子比较采样。第 7／8 步只核对已有最终图及数据按阶段发布，不要求新增图型。

## 防重、必要计算与拒绝

1. 记录已有相容 PW／PH、q2r／matdyn 和插值输出，重复成功请求，核对这些调用计数均无增加。
2. 仅缺一份目标插值采样时，核对执行前已保存具体缺项及最少求值说明；仅执行必要程序。
3. 改坏来源身份、坐标、网格权重、自旋、展宽或 ASR，检查具体错误与未交付项，不应静默采用默认值或重做上游。
4. 在三种声子目录均存在时选定一种，检查没有跨目录读取补齐。

## 恢复、兼容与移动重绘

在图像生成或清单／索引发布处注入中断。恢复后检查原科学调用无增加，成功单元保留；最终发布前不能标记该阶段全部交付成功。索引可由完整阶段包恢复；不同阶段、模型或模式的包不能混入。

对已知旧布局做只读接入，核对旧科学文件、冻结脚本、回执和历史报告哈希及文件集合不变，不因新目录缺失重算。

复制完整 `results` 到新位置，在不能访问原工作区、PATH 中没有科学程序的环境，用既有重绘接口重绘。核对图片内容、表格哈希、窗口／标签及相对路径引用；不能调用 QE／EPW／Wannier／postw90 或 sbatch。

## 证据归档

按 SC-001～008 保存命令／脚本、版本、调用账目、源与输出哈希、故障注入点、恢复记录和实际图片检查结论。替身回归、真实程序验证、安装部署和科学收敛分别报告。本功能不评判粗网格是否收敛，不以图像相似宣称精度合格。
