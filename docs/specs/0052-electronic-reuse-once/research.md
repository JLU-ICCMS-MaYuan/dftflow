# 设计依据

重复源头是 reusable 的预检／递归、files 的重复产物哈希，以及 refresh_post 对前置电子阶段的反复刷新。只删除 println 不能满足需求。

采用限定在持锁 advance 内的临时确认，保留原核验实现作为未确认路径；完整配置不相同则绕过。只共享 Electronic 相关结果，避免扩大到所有科学阶段。已有 PDOS 确认并入首次主核验，缺失仍由现有电子后处理补齐。

不采用磁盘缓存和关闭核验开关，避免跨命令忽略用户或原生程序更改。错误与未完成结果不记成功；SCF／NSCF／电子写入或归档前清除确认。后续阶段的独立科学检查保持。

主电子科学结果仍只由 PW／bands／DOS 判定可复用。PDOS 缺失表示投影尚未确认，不将已经成功的主电子计算判为需要重跑；在本阶段后处理中补齐后再汇总输出。
