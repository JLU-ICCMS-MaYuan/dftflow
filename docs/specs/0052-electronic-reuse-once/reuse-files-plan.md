## 与旧设计冲突

旧 0052 依赖操作内缓存减少电子检查，本修订先缩小访问范围，不能仅增加缓存。0064 的就近原生结果检查保留，但递归批次追查让位于当前输入需求。0067 的电荷密度／波函数免核验保留。0065 的 Slurm header、launcher 不变。0026 的当前阶段自动后处理保留；不得扩展为刷新历史阶段。

## 验收方法

1. 使用公开 CLI 与受控科学程序，在真正的文件交接边界记录访问和复制；无关阶段设置为不可用，验证不访问、不补算、不补图（SC-001）。
2. 捕获 stdout 对照实际接续路径，检查 7 空格、分组、去重；分别覆盖已有目标完成与实际取用上游数据（SC-002）。
3. 移走隔离夹具中的旧清单，注入过期清单；验证运行不依赖也不重建。直接输入缺失、格式错误和原生 I/O 失败分别拒绝；不预检原始密度／波函数（SC-003/005）。
4. 已有模型但无窗口日志、无无关上游电子态的夹具中验证插值准备；核对默认及显式费米能原生输入，不修改 fsthick（SC-004）。
5. 回归调度活动／未知回执、失败／未收敛，确保不会因移除来源登记而假报成功（SC-005）。
6. 代码完成后运行相应 Rust／公开进程回归，再 release 构建覆盖固定命令。不得以替身验证宣称真实科学验收，不自动提交科学作业。文档回写后仅提交本次文件，不推送。
