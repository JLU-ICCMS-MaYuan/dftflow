## 背景与需求结论

用户明确要求把主电子参考与三次 projwfc 提示对应的核验合并到第一次，减少实际重复 I/O 和重复提示。首次核验覆盖第 3 步主参考及已有 PDOS，后续第 4、5 步和收尾共用本次确认结果。整个目标已完成的快捷返回仍保留既有总体完成提示。

## 附件与推断

无附件，images: []。确认结果限定于本次持锁命令，是保留新命令检查与来源变更检查的实现边界，不新增持久复用状态。

## 用户故事与验收

- US1（P1）：已有第 3～5 步结果时，推进流程仅集中输出一次第 3 步复用，PDOS 核验和电子派生交付不被后续阶段重复调用。
- US2（P1）：SCF／NSCF／电子来源重算、配置变化或新命令后重新检查；缺失 PDOS 可补算，失败后可恢复，损坏文件拒绝。

## 功能需求

- FR-001：首次电子主阶段复用核验包含已有 projwfc／PDOS 核验，成功后汇总为一次 reuse: 3.qe-electronic。
- FR-002：本次命令内共享有效的电子核验、PDOS 产物确认和电子派生刷新结果，减少实际重复操作。
- FR-003：作用域结束、配置不匹配、SCF／NSCF／电子来源重算时不使用旧确认；错误和未完成结果不能记作成功。
- FR-004：保留 PDOS 缺失补齐、原生检查点恢复、坏产物拒绝和图像修复，不增加配置开关，不改变电荷密度／波函数免核验边界。

## 成功标准

- SC-001：公开命令进入 Wannier 的复用输出，第 3 步主提示一次、projwfc 复用子提示零次，科学调用数不增加。
- SC-002：实际核验闭包与刷新闭包调用次数测试证明重复操作减少；配置、生命周期、来源失效和错误重试有回归。
- SC-003：相关真实进程替身回归通过；release 编译并覆盖固定命令。

## 依赖、边界和非目标

依赖现有工作区目录锁、电子阶段完成记录和 PDOS 检查点；无需新数据格式。第 4、5 步仍按自身规则核验科学结果，只共享第 3 步确认。无新科学计算、持久缓存、资源设置、推送或分支切换。无待确认的范围决策；远程 Spec 未发布，Issue 不关闭。
