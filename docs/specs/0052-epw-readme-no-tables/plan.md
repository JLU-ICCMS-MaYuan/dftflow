# 实施计划：README 使用独立命令行并取消表格

依据 [Spec](spec.md) 及其中完整保留的追加实施授权，本项只调整指定 README 的表达。

## 修改方式与理由

以实施前 Git 版本为内容基线，将八阶段表格改为八个独立小节，每节依次说明作用、命令与产物位置。完整命令使用 `bash` 代码块，一条命令一行，无提示符，便于直接复制。原有检查、状态与重绘代码块保留。

不改动表格之外已有的操作说明，仅将并行参数处的行内命令片段拆为程序名和参数说明，避免误认为待执行的完整命令。不引入校验框架或持久测试脚本；此次是可逆文档调整，静态比对与 shell 语法检查足以验证。

## 需求与验证对应

- FR-001／005、SC-001：核对全文源码及 Markdown 标题、段落与代码块结构，无表格与失效表述；无需额外安装渲染工具。
- FR-002／007、SC-002／005：核对八小节及命令顺序，将旧版行内阶段命令与新版代码块命令逐条比较，检查全部代码块语法与提示符。
- FR-003／004／005、SC-003：逐项核对原有说明与八阶段产物，比较全部原有链接及其目标。
- FR-006、SC-004：检查 Git 变更范围，只提交目标 README 与 0052 文档，不执行 README 中的科学命令。

## 不适用产物

无新增数据模型、接口、依赖或架构决策，无需单独数据契约或研究文档。README 本身即操作指南，不复制另一份快速入门。
