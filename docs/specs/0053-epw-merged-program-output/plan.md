## 技术上下文与质量门

Rust 2021／Bash，现有 Cargo 工作区、serde 原生任务 JSON 和 SHA256 身份。Linux 原生构建使用 `scripts/build-native.sh`；公开 CLI／实际 shell 的隔离回归复用 `three_stage_execution`。

范围与七项验收已由用户确认，实施授权明确。单项维护使用同一基线的编号规格，不增加 Feature、平台操作或外部依赖。保持 Slurm 日志、退出码、预算和原生输入不变；不创建分支或推送，不触碰无关 `AGENTS.md` 修改。

## 设计与职责

- `native_jobs` 生成任务版本 3，唯一科学命令结尾为 `> stem.out 2>&1`。集中按版本选择并捕获日志，供调度器归集、分配内执行和方法收尾共用。
- 版本 1 保留 `native-ID-JOB.out/err`，版本 2 保留 `stem.out/err`。版本 3 的 stdout／stderr 身份指向同一 `.out`，保持已有报告字段类型；不迁移旧记录或依据 `.err` 是否存在猜版本。
- `ExecutionReport` 按实际不同日志路径归集；路径相同时只复制 `.out`。单温度尝试按同一日志集合登记产物，防止强制捕获不存在的 `.err`。原有非 Slurm 本地执行器保留分离日志。
- 电子后处理回执按当前原生任务的版本剔除对应 `.err`，不以文件存在与否决定模式；旧回执核验及归档旧日志的集合保持原样。
- 现用脚本先清点并核对记录绑定；冻结／历史脚本保存原字节，没有可迁移目标时明确记录。文档更新与代码验证分开，不把源码完成写为默认安装已更新。
