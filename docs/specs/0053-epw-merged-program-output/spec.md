## 附件与推断来源

## 背景与目标

用户查看一个科学程序的 `.out` 即可同时看到正常输出和错误。采用已确认的科学程序合并范围；Slurm 自身日志沿用原设置。覆盖全部 EPW 原生阶段及其后处理，并保护已有科学证据。

## 用户场景与验收

### US1：在同一个输出文件查看科学程序日志（P1）

程序写 stdout 和 stderr 时，两者实时进入同一 `.out`；带空格或 Shell 特殊字符的程序路径正确引用。退出非零仍失败，种子参数型程序保留接口。独立验收使用公开 CLI 生成脚本，再用受控科学程序实际执行。

### US2：正常归集、续算和保留旧证据（P1）

新任务无需 `.err` 即可完成、归档及复用；历史分离日志仍按原记录核验。缺失或篡改必要日志应拒绝，已有活动脚本不得改写。独立验收覆盖分配内子任务、iso／aniso 收尾及旧任务恢复。

## 功能需求

- **FR-001**：全部 EPW 原生科学脚本使用 `> xxx.out 2>&1`，涵盖 QE、Wannier、EPC、超导及后处理。
- **FR-002**：保留输入／种子参数、引用、MPI 设置和 Slurm 日志设置；标准错误合并必须实时生效。
- **FR-003**：新任务日志记录、复制、科学尝试产物和恢复不要求独立 `.err`；必要 `.out` 的身份仍严格校验。
- **FR-004**：旧任务按其原日志契约读取、验证和归集，不改写历史输出、冻结脚本或绑定记录。
- **FR-005**：迁移现用且可修改的脚本；提交或身份绑定脚本及历史脚本只核验，不迁移。
- **FR-006**：非零退出、缺失日志、输入／输出篡改继续阻断，不通过创建空 `.err` 伪装成功。

## 成功标准

- **SC-001**：实际生成的各阶段科学命令统一重定向，全部所测脚本通过 `bash -n`（FR-001／002）。
- **SC-002**：运行中的两路输出在同一 `.out` 可见，无新增科学 `.err`；退出 17 保持失败（FR-002／006）。
- **SC-003**：新任务完成、复用、归档、方法收尾及失败恢复通过针对性回归，损坏证据仍拒绝（FR-003／006）。
- **SC-004**：旧版两种日志契约均可续算，缺失旧 `.err` 仍拒绝；冻结现场文件哈希不变（FR-004／005）。

## 关键实体、依赖与边界

原生任务拥有脚本和日志身份，科学尝试只绑定实际产生的日志。关联 0022、0026、0035、0046。无新 CLI、配置或科学参数；不提交真实科学作业、不修改共享 qeflow 日志规则，不自动安装或推送。
