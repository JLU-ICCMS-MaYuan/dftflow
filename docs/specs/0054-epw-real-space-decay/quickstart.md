# 实空间衰减图使用说明

适用于 0051 新版源码生成的编号阶段脚本；默认安装和已冻结脚本不会自动升级。

## 自动交付

在配置所属目录按现有方式提交粗网格目标：

```bash
epw_wannier -c "epwinput.toml" --stage coarse -s
```

原生粗网格核验成功后，同一阶段分配先生成衰减图，再继续其他后处理。衰减出图本身不启动科学程序或新作业，不等待声子比较成功，也不要求第 7 步。此命令仍按既有阶段流程执行必要科学计算；已有完整检查点时复用。

阶段内保存于 `6.epw-coarse/decay/`，发布到 `results/6.epw-coarse/decay/`：

| 文件名主体 | 内容 |
| --- | --- |
| `decay-H` | Hamiltonian，电子实空间距离 |
| `decay-dynmat` | 动力学矩阵，声子实空间距离 |
| `decay-epmate` | 电声矩阵元，电子实空间距离 |
| `decay-epmatp` | 电声矩阵元，声子实空间距离 |
| `decay-overview` | 按上述顺序排列的 2×2 总览 |

每个主体有 `.png`、`.svg`、`.pdf`，共 15 图。包内还含四份原始文件副本、`decay-data.json` 和 `decay-manifest.json`；阶段发布单元另有来源清单。紫色点逐行绘制，同距不合并；零值保留在数据并注明未参与对数绘制。图供人工判断，不增加自动质量门。

## 恢复和移动重绘

阶段绘图或发布失败，修复具体问题后沿用原目标加 `--resume -s`。已有科学检查点保留，缺图仅补派生结果。缺原生文件时列出全部缺项，不自动重跑 EPW；应先核对本次来源和原始备份，不从其他运行借数据。原生数据、来源或包内数据被修改时明确拒绝。

移动完整 `results/` 后可使用同版程序核验和重绘：

```bash
epw_wannier --results-check --results "results" --json
epw_wannier --plot --results "results"
```

重绘只读包内数值，不要求原科学工作区、QE／EPW 或 Slurm 可用。它仍需要现有绘图运行环境和字体。仅移动单个 PNG 不构成可重绘结果包。来源绝对路径仅用于审计，包内通过不代表已重新访问原来源。

真实 MgB₂ 只读图表的位置和验证边界见 [验收记录](acceptance.md)。
