# 技术评估与决策

日期：2026-10-22。需求基线见 [Spec](spec.md)。

## 生成时机

EPW `epw.f90` 的 `IF (elph)` 包含 `build_wannier`；`wannier.f90` 调用 `bloch2wannier.f90` 的 Hamiltonian、动力学矩阵及电声顶角实空间变换。第 5 步 `elph=false` 不执行这一路径，第 6 步才有四类输出。即使声子比较失败，只要原生粗网格已核验，衰减图仍有独立价值。

## 来源和科学检查点

当前编号 Completion 从阶段文件捕获身份，已有回执可直接绑定原生 decay 文件。后处理只能消费这些身份，不能看到同名文件就补认来源。当前 Completion 将缺少任意文件当作科学不可复用，会让缺少诊断数据触发粗网格重算。因此对 Coarse 的四种已绑定 decay 文件明确区分：缺失保持科学复用资格但派生交付报错；存在时仍核对哈希、长度和真实目标。其他科学文件不作例外。回执及科学 output_key 不重写，细网格来源身份保持稳定。

若历史回执没有绑定完整四份文件，报告未绑定／缺失列表，不自动重跑或追认。独立图包移动后只核对副本与清单；原始绝对路径只用于审计。

## 数据与图表

沿用原生前两列与 Å／Ry 标签；对另一方向取最大值已由 EPW 完成，绘图不再平均或拟合。同距散点保持逐行顺序。Fortran E／D 数值接受；负值、非有限数、空数据拒绝。精确零值不补 epsilon，全零面板明确说明无正值。

复用 Plotters 和 svg2pdf，五张图采用同一份数据与参数。单点及常数范围只扩大显示范围，不改变样本。使用自包含 JSON 和原始副本核对样本，避免重绘时单位、数据或统计被改动。绘图不调用科学程序或调度器。

## 发布与恢复

复用已有 publication journal 和 stage_results 单元；衰减单元单独发布，早于电子／声子比较收尾。原始副本、数据、15 图均绑定哈希，未知文件冲突不覆盖。缺图允许补绘；数据损坏拒绝。所有新派生目录排除在科学 evidence 之外，防止后续补图改动科学身份。

拒绝新增公开程序、重新计算矩阵元、把衰减尾部转为阈值或把“图像完整”当作“科学精度通过”；这些都不是本需求。

## 进程中止与锁恢复

发布 journal 恢复之外，强制中止可能留下 `decay-publication.lock`、衰减单元 `stage-publication.lock` 或 `results/index.lock`。沿用 store 已有作业 owner 和 Slurm 终态核验，通过 workspace 的旧尝试检查接入，不自动移除未知所有者锁。公开进程测试覆盖不匹配所有者拒绝和匹配旧终态作业恢复。独立离线重绘遇到未知遗留锁仍须先核对所有者，不能强行覆盖。
