# 组合图数据与交付契约

## 目录与文件

- 第 3、5 步的 plot/ 各生成 electronic.png 和 electronic-from-lowest-to-highest.png，各自对应自包含 .plot.json。
- 第 4、6 步的 plot/ 各生成 phonon.png 和 phonon.plot.json。
- results 对应阶段的 plot/ 发布相同图片与图参。数值 CSV、指标、归一化和科学来源继续独立保留。
- 新生成端不输出分离能带／DOS 图片、-valence 图片或比较总览；逐带范围和衰减诊断保留。

## 能量与频率

电子图纵轴为 E−E_F（eV）。近费米范围读取 [plot] 的 electronic_energy_min_ev／electronic_energy_max_ev，独立默认 −3／＋3。全范围严格由 QE 路径全部本征值的最小和最大值确定。

声子图纵轴为频率（cm⁻¹），显示 0 至路径最高频率；比较图取 QE／EPW 最大值。负频原始数据与虚频判断不变。

## 数值与渲染

DOS 原始图参保存 (能量或频率, 密度)，渲染时转置；未覆盖区间留空。两个面板上下留白一致，绘图区纵轴逐像素对齐。

组合图参包含曲线、边界、标签、窗口、来源说明和渲染版本。PNG 为 3600×2400，至少 300 DPI。QE 实线先绘，EPW 蓝色虚线后绘；不恢复紫色误差标记。数据和科学比较窗不因显示范围变化而改变。

## 恢复与历史包

绘图范围不进入科学身份，配置改变和缺图只触发派生恢复。新结果包通过 Combined 图参独立重绘，不需要原工作区或外部程序。历史分离图参保留有界读取能力；不向历史包伪造新数据。

旧图清理仅针对既有生成器明确拥有的文件名或事务发布清单登记产物。未知文件和科学数据不得删除。
