## 问题与目标

实施前电子图为 1000×700 PNG，没有 DPI 元数据；QE 单侧 DOS 使用完整输入范围，相对费米能约 −109.17～90.83 eV，尖峰与密集网格挤在小图中。可见脱离主体的短线状黑点，连续折线代码没有主动添加散点，根因不能直接归结为低 DPI。原 EPW 编号电子流程只消费 TDOS，虽生成 `elepdos.in`，没有实际调度并消费 projwfc 元素投影；不是只缺几条颜色曲线。

本需求让电子图默认提供两种有物理意义的显示范围，能带和 DOS 同窗，并补齐 QE 元素 PDOS 与真实 300 DPI 输出。PDOS 只在第 3 步 QE 侧绘制，第 5 步继续比较总 DOS。

| E3-02 | 第 3 步 QE 电子能带 | 最低 QE 价带～+5 eV |
| E3-03 | 第 3 步 QE TDOS＋各元素 PDOS，同图 | −5～+5 eV |

两种范围均以同一个 QE 费米能为零；最低价带使用共同 QE 参考中的最低已计算占据态，不用 Wannier 外窗下界代替。各元素曲线汇总画在对应 QE DOS 图中，不按元素再增加独立图；原声子、衰减图和既有总览不计入本次 8 张。完整定义见 [Spec](spec.md)。

## 验收条件

1. 第 3 步完成 4 张 QE 图，第 5 步完成 4 张对比图；能带和 DOS 对应范围严格一致。
2. PNG 原生以至少 300 DPI 渲染，默认 10×7 英寸、3000×2100 像素；保存可核验的密度信息，不能把 1000×700 插值放大冒充高清。
3. 无无数据依据的黑色散点、断线碎片、裁剪残影；保留真实窄峰，不以擅自加展宽／加密网格掩盖问题。
4. QE TDOS 与逐元素 PDOS 使用真实投影，同一费米能、展宽、网格和计数口径；报告投影残差，不强制归一到 TDOS。
5. 复用已有科学数据，只允许缺投影时做必要 projwfc 后处理；单纯换显示范围、DPI 或重绘不重跑 PW／PH／Wannier／EPW。失败保留科学检查点，不能把缺投影标为完整交付。
6. 逐阶段自动发布到根 `results/`；图片、对应数据、来源和参数可移动重绘；不得等待声子才交付电子图。
