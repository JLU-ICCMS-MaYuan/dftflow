## 设计

1. 建立共用电子配色与高清 PNG 输出：红色仅费米线、蓝色仅插值，窗口采用绿／褐／橙／紫，QE 深灰。按数值直接生成 3000×2100 图并写 PNG 密度。
2. 双显示预设使用共同 NSCF XML 的最低占据能量和费米能；显示裁剪与既有比较指标窗分离，完整 CSV 保留。
3. 曲线使用 SVG 描边并从数值矢量栅格化，避免位图后端对密集折线整条扩宽多边形产生填充碎片；裁剪保留交点，不连接路径断点。
4. 在电子 DOS 叶子复用已校验 NSCF 波函数的隔离副本执行最小 projwfc 后处理；原生收据独立于 PW／TDOS，同一高斯核和展宽，TDOS 使用同次 projwfc 的 DOS 列以保持原生同网格。保存必要计算原因，完整投影及来源受哈希绑定。
5. 原生投影按原子波函数的 LDOS 列汇总到元素，不重复加磁分量。核验每个原子、能轴和标量非磁格式；输出投影和与 TDOS 差异，不强制归一。
6. 第 3／5 步均发布近费米和完整价带图；参数及完整曲线封装到可移动的 plot.json。旧包重绘采用新颜色，旧包无 PDOS 明示缺项。
7. 既有比较入口和四面板总览电子面板统一近费米显示与配色，不改变科学指标或声子数据。

## 实施中的明确取舍

高清 PNG 使用 Plotters SVG 路径，再由已锁定的 resvg 直接栅格化；保留全部输入数值和真实窄峰，不将粗折线整体填充为位图多边形。PNG 密度向上量化为 11812 px/m（300.0248 DPI）。SVG 作为内存渲染中间产物，不依赖外部图片软件。

插值 DOS 原有能区不能覆盖深价带时，仅将已有 QE 本征值的 DOS 数值求和网格按同一步长向下扩展；插值曲线保持原范围。图中明确两侧支持范围，空缺不补零，不补算 EPW。不改变路径／均匀网格态配对的原科学指标窗。

投影的原生请求 key、已成功原生日志和派生收据分开保存。若原生日志及请求仍相容、仅派生收据丢失，恢复直接核验并登记投影，不重复 projwfc。

## 重合曲线样式

FR-016／SC-010 → qf-plot 共享两侧描边常量 → workspace_plot、comparison_plot、wannier90flow → T007。DOS 下层长虚线 18／6、线宽 4；电子能带下层为连续实线、宽 4；上层短虚线 6／6、线宽 3，单位为 SVG 逻辑像素。按整数后端取约 33% 加粗，避免额外 SVG 改写。所有参考图层先完成，再覆盖插值；图例使用同一常量。渲染器版本递增只失效派生缓存，不改变科学后处理请求。用完全重合的两类曲线检查实际像素；TDOS／元素图中，总量复用下层样式，元素短虚线长度从 6 起递增 2（按既有六色周期）；密集 DOS 的连续性在无投影的单曲线实线图上独立核验。
