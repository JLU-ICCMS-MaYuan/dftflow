# 组合图设计依据

- 电子全范围依据用户澄清，仅采用 QE 路径全部实际本征值；DOS 支持范围不能定义纵轴。
- 组合图在同一画布创建两张图表，显式统一上下留白与纵轴边界；DOS 在渲染时将 (能量,密度) 转为 (密度,能量)，不改数值文件。
- 绘图配置与科学阶段输入分离，纳入派生缓存检查和交付身份；无需修改任何 launcher、资源申请或科学输入。
- 复用现有声子元素聚合及展宽算法，不维护第二套平滑公式。
- 旧结果包使用原有分离图参重绘；当前新包使用 Combined 自包含图参。旧包兼容不改变新输出数量和命名。

## 2026-11-18：深能级 DOS 尖峰

当前真实全能窗 QE DOS 的中位数为 0；排除近零采样后中位数仍约 0.51。深能级最大峰约 32.6，而 E_F±3 eV 内最大值约 4.24。用户已选择按关注能窗的最大值定范围，拒绝继续用全能窗峰值撑宽横轴，也不采用分位数启发式。

参考能窗是显示参数，不进入科学身份。保存在自包含图参中，可使独立包重绘保留同一尺度；现场重绘则显式读取当前配置。范围无正数据时回退可见范围并注明，避免没有实际依据的极小轴；声子继续使用全显示范围最大值。裁剪采用线段与矩形边界交点，避免把高峰数值强行钳制后伪造平顶。
