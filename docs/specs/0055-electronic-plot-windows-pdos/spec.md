## 背景与目标

当前自动图过宽且分辨率不足，无法清楚检查费米能附近和全部价带到低能导带的结构；电子 DOS 缺少真实元素分解。目标是稳定交付两种能窗、同步能带／DOS、可核验的高清图与真实 QE 元素贡献。

### 需求结论与变更取舍

- 相对能量统一为 E−E_F，默认提供近费米能范围 [−5,+5] eV 和完整价带范围 [E_min,QE−E_F,+5] eV。
- 最低价带下界取共同 QE 均匀 NSCF 参考中最低已计算占据态，保存原始能量、来源和费米能；该有限采样下界不宣称为全倒空间精确极小值。赝势显式计算的深价带／半芯态保留，冻结芯态不凭空加入，不能用 dis_win_min 或 EPW 模型低能截断替代。
- 采用用户后续选择：QE 元素 PDOS 与 TDOS 同图，第 5 步仅做两侧 TDOS 对比。按两种范围共 8 张独立电子图；不另给每个元素拆图。
- 0047／0050 的逐阶段交付时机继续有效。仅本次 QE 元素电子 PDOS 新范围覆盖此前暂缓；声子元素投影及声子 TDOS 比较要求不变。
- 只改变显示预设和图像质量，不修改物理选窗、科学数据或旧比较指标定义。图中继续提供实际四个选窗值；超出显示范围的边界在图例或注释说明，不为显示边界扩大能量轴。

## 用户场景与验收

### US1：直接查看两种尺度的电子图（P1）

用户完成电子阶段即可分别查看近费米能和完整价带范围，而不用手动编辑图片。

**优先级理由**：解决用户最直接的可读性问题。

**独立验收**：无声子／coarse 结果时第 3 步交付 4 张 QE 图，第 5 步再交付 4 张对比图；按数值参数核对同一范围的能带和 DOS。

1. **假如**QE 电子叶子任务完成，**当**自动出图，**那么**生成对应两种范围，不等待另一叶子或声子计算。
2. **假如**Wannier 电子后处理完成，**当**发布，**那么**两种范围的能带和 TDOS 对比各一张，不重复 QE 计算。

### US2：在 QE DOS 中识别元素贡献（P1）

用户能看到 Mg、B 等各元素对 DOS 的真实贡献，并能核查投影来源。

**优先级理由**：总量曲线不能回答元素贡献。

**独立验收**：由原生原子／轨道投影按元素加和得到图中曲线；CSV 可回溯，缺投影时明确报缺，不能改用 Wannier 初始轨道伪造。

1. **假如**完整原生投影存在，**当**绘图，**那么**每个元素跨同类原子汇总且与 TDOS 一起显示。
2. **假如**投影缺失或损坏，**当**恢复，**那么**保留成功科学数据及已交付 TDOS，记录元素图未完成，只有必要后处理可补算。

### US3：清楚阅读和独立重绘（P1）

用户获得至少 300 DPI 的实际渲染结果，图片与数据移动后仍可重绘，不出现无数据依据的黑点碎片。

**优先级理由**：仅改 DPI 标签不能解决当前像素和曲线问题。

**独立验收**：检查像素／物理尺寸／密度元数据，实际查看两个能窗，核对密集尖峰连续性，空科学程序环境重绘不改变数值。

## 需求

### 功能需求

- **FR-001**：默认交付表中 8 张独立电子图，文件及清单可明确区分阶段、内容和近费米／完整价带两种预设。
- **FR-002**：近费米预设固定为 E_F±5 eV；完整价带预设使用同一 QE 参考下界到 E_F+5 eV。能带纵轴和 DOS 能量轴采用相同上下界，均相对同一 E_F。
- **FR-003**：下界及 E_F 来源在参数中可追溯；最低价带不由 DOS 计算输入的 Emin 或展宽尾部零值决定，不使用 Wannier 外窗替代。
- **FR-004**：数据不足以覆盖预设时明确记录覆盖区间和缺失部分，不把越界数据补零为“已计算”、不拉伸能轴、不用额外 PW／EPW 自动补齐。两个阶段相同预设边界不随模型带数缩窄。
- **FR-005**：每张必需 PNG 从数值数据重新渲染，至少 300 DPI；默认物理尺寸 10×7 英寸、像素至少 3000×2100，保存可核验密度信息，允许标准元数据单位换算的量化误差。不得上采样旧图充当高清渲染。
- **FR-006**：字体、线宽、图例及主刻度按目标物理尺寸设计，费米能零点可辨、网格简洁，高对称点符号保持轴外；实际四个 dis_win／dis_froz 值继续保留且不挤压主曲线。
- **FR-007**：定位并消除无数据依据的黑色散点、脱离线段、裁剪残影和错误跨段连线；不对普通 DOS 曲线默认添加采样标记。先核对数据和渲染，不把所有尖峰归因于 DPI，不以擅改展宽或网格作为修复。
- **FR-008**：第 3 步两张 DOS 图必须包含真实 TDOS 与所有元素的 PDOS 汇总，曲线颜色和图例区分；同元素原子贡献正确相加，不把原子序号、Wannier 函数或总 DOS 当元素贡献。
- **FR-009**：TDOS／PDOS 使用同一 QE 状态来源、能量零点、能量网格、展宽核、宽度、自旋及单位；优先复用合格投影文件。投影和与 TDOS 的差异应如实输出，不能强制归一以掩盖不完备投影基底，也不能重复加和 LDOS 与其磁量子数分量。
- **FR-010**：仅无可用投影时才执行必要投影后处理并事前说明技术原因；不得为改范围、DPI 或补图重新 SCF／NSCF／PH／Wannier／EPW。已校验上游保持只读身份，缺少必须波函数时具体报缺，不静默重算。
- **FR-011**：第 3 步各叶子完成即可发布，第 5 步电子图不等待 PH／coarse；第 5 步 DOS 仅比较 TDOS，电子能带保持 QE 实线先绘、EPW 短虚线后绘，DOS 使用既定长短虚线。
- **FR-012**：所有图片及对应数据、参数、投影汇总与来源按阶段自动发布至根 `results/`，成功标记晚于相应完整性核验；缺元素 PDOS 不得标记本功能完整完成。失败保留科学检查点，恢复只补未完成派生结果。
- **FR-013**：完整结果包移动后仅凭包内数据重绘，能窗和 DPI 可核验；旧完整数据可重整绘图，旧包无投影时明确缺项，不将其伪装为新完整包。
- **FR-014**：已有四面板总览的电子面板采用同一显示规则，默认近费米预设；不新增两张总览以扩大 8 张独立图范围，不改变声子面板物理数据。实际拟合窗和既有数值比较口径保持，只区分科学指标窗与显示窗。

- **FR-015**：所有电子能带与电子 DOS 显式绘制 E−E_F=0 的红色费米线；EPW／Wannier 插值曲线统一蓝色。其他曲线、窗口边界及普通标签不得占用红蓝，重绘旧包也遵循此规则。

- **FR-016**：两侧完全重合时仍能在绘图区分辨各自颜色；DOS 参考下层长虚线比插值上层短虚线约粗 30%；电子能带参考下层必须为连续实线。图例同步，科学曲线与费米能不变。

### 关键实体

- 显示预设：近费米／完整价带，下上界均有共同 QE 参考和单位。
- 原生投影：原子、元素、原子波函数及分量身份、能量轴、展宽、自旋和来源。
- 元素汇总：每个元素全部对应原子／原子波函数贡献与汇总规则、投影差异。
- 渲染请求：阶段、图种、预设、物理尺寸、像素、DPI、字体线宽及科学来源。
- 交付单元：图片、数值表、参数和来源；缺项／失败／完成相互区分，不替代科学回执。

### 边界与异常场景

能轴／单位错误、非有限数据、能量重复或乱序、缺原子投影、混用来源或计数不明确均应具体报错。显示裁剪须保留曲线穿越边界的真实交点；不连接断开的高对称路径段。PDOS 失败时已完成的能带与 TDOS 不撤销，但元素图保持缺失状态；不等待另一叶子或 PH。空覆盖、无正 DOS 或完全重合的四个窗口应有可读说明，不伪造曲线或擅自改变科学参数。

## 成功标准

- **SC-001**：默认清单中 E3-01～04、E5-01～04 均存在，阶段及预设不混淆；对应图能量边界数值完全一致，同一 E_F。
- **SC-002**：8 张 PNG 像素与密度信息满足 FR-005，实际从原数据渲染；100% 及适合阅读的缩放下图例、文字、线条清楚，不重叠遮挡关键曲线。
- **SC-003**：对当前 MgB₂ 尖峰数据和最小密集尖峰样例核对曲线／矢量或独立参考渲染；脱离数据的黑点和残影消失，CSV 原始科学数值、峰位及展宽未因美化被更改。
- **SC-004**：Mg／B 各自曲线逐点等于其原子／原子波函数投影汇总；TDOS 与 PDOS 来源及口径一致，投影差异被报告而非被强制抹平；负向数据／来源用例拒绝。
- **SC-005**：首次缺投影只增加必要后处理；更改显示范围、DPI、丢图恢复和完整重复执行均不增加成功 PW／PH／Wannier／EPW 调用，既有科学文件身份不变。
- **SC-006**：没有第 4／6 步产物时，第 3／5 步仍按时交付；叶子故障不阻断另一叶子成功发布，元素投影失败不会误报本功能完整成功。
- **SC-007**：完整包移动且原科学目录不可访问、PATH 不含科学程序时，8 图仍可重绘核验；缺投影的旧包清晰报缺，已有可复用科学数据不被改写。
- **SC-008**：受影响总览、模块手册、MgB₂ 使用和测试说明与实际行为一致；需求未实施前 Overview 不把本草案写成当前能力。

- **SC-009**：检查第 3／5 步、旧包重绘及总览电子面板：能带的水平零线、DOS 的垂直零线均为红色，插值为蓝色，其余线与标签避开红蓝。

- **SC-010**：用逐点完全相同的能带、两侧 DOS 和三条 TDOS／元素曲线核验绘图区同一行同时可见全部颜色；能带在重合处仍连续，QE 实线图例与曲线相符；真实 MgB₂ 包重绘后数值及来源不变，保持八张 300 DPI 图。
