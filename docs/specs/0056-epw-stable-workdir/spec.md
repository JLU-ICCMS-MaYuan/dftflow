## 需求

- **FR-001**：全部编号阶段的公共归档路径保留阶段目录的 inode。
- **FR-002**：归档旧计算输入、输出、完成记录和失效的配套状态，隔离新旧科学结果。
- **FR-003**：保留当前 Slurm 日志的原 inode 与阶段目录入口，归档前后持续可读。
- **FR-004**：归档成功后在原目录生成新输入和脚本；相容阶段继续复用。
- **FR-005**：归档失败停止执行，列出失败源路径与目标路径，不覆盖冲突文件、不启动新计算。
- **FR-006**：保留显式恢复、活动／未知作业防重和上游复用规则。

### 关键实体

阶段目录是稳定工作入口；历史是旧计算和旧记录；现用记录是当前完成回执、任务状态及结果包。逻辑字节不表示实际释放磁盘空间。

## 成功标准

- **SC-001**：持有旧工作目录的独立进程归档后无需重新 cd 即可看到新文件，目录 inode 不变。
- **SC-002**：归档文件字节不变，现用目录没有旧科学输出。
- **SC-003**：已经打开的 Slurm 日志句柄继续写入，阶段目录能读取新增内容。
- **SC-004**：SCF 重算、声子恢复和粗／细网格相关公开进程回归通过。
- **SC-005**：注入归档失败后不执行新科学程序。
