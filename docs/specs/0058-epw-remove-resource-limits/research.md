# 设计依据与取舍

## 限制来源

Resources 强制包含两字段并校验上限；budget.rs 在预留与登记检查时间、存储；native_jobs、workspace 和 workflow 分别生成 #SBATCH --time，workflow 另传 sbatch --time。storage.rs 只有限额辅助接口与对应测试，无生产调用，整体删除避免留下未使用限制实现。

## 决策

- 直接删除字段和 CLI 参数，不用大数、零或可选开关模拟取消限制，符合 KISS／YAGNI。
- 保留预算模块中的作业身份、并发登记、实际用量结算及原子写入；不把取消两种额度扩大为取消全部调度防护。
- 历史账本额度改为可选字段并保留原值，新账本不生成；状态只公布仍生效的并发限制，历史原文仍可核查。
- 原配置保持严格解析并带路径上下文；这是用户明确选择，不设置历史配置忽略分支。
- 原生脚本、阶段脚本及旧入口提交分别核验，避免只改常用入口留下旁路。

## 证据边界

本项验证调度与资源接口行为，不执行真实 QE／EPW，不认证科学数值，不自动安装。历史 Spec、科学日志及冻结快照保持原样。
