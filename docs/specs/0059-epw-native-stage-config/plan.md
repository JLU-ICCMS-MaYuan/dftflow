# 实施计划

## 实施基线

对照 [Spec](spec.md)、[设计依据](research.md) 和 [参数契约](contracts/config.md)，FR/SC → 任务 → 验证证据完整追踪。

## 配置与输入

新增严格版本 2 的阶段配置，科学设置按程序原生输入段保存。现有算法通过有界的内部类型视图取值，视图不能作为外部配置格式，也不能在阶段之间继承科学参数。统一输入生成与参数来源记录；保持共用 QE 格式库。

## 验证、清理与真实运行

先执行配置/输入/回执及公开进程回归，再构建固定程序。无活动或未知作业后，只清理当前算例内已授权的旧产物，不归档。以新配置从头执行八阶段，核对原生采用值、收敛和双方法全部温度结果。

## 交付

更新当前事实文档和验收，保留其他任务差异，按明确差异暂存并自动提交，不推送。
