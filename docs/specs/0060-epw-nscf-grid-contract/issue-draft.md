## 目标与范围

- NSCF 配置仅填写三个正整数，例如 `stages."2.qe-nscf".pw.K_POINTS = [2, 3, 6]`；坐标仅展开到实际科学输入。
- 执行前核对 SCF 与 NSCF 的三个网格维度一致；本次生成 Γ 中心零位移网格，SCF 位移非零时明确报错，不静默覆盖。
- Rust 生成器与仓库官方 `kmesh.pl` 保持相同公式、遍历顺序和数值打印精度：坐标八位小数，等权重按六位小数科学计数法打印。生产运行不依赖 Perl，验证直接调用官方脚本对照。
- NSCF 完成后对照本次实际输入文件和 QE 输出 XML：输入声明点数、输入坐标行数、输出声明点数与实际电子态记录数必须一致，并核验完整性、坐标对应和权重。
- 不一致即非零退出，不发布成功记录，不启动下游；列出输入与输出数量、文件和建议。提示准确写为“将本阶段 calculation='nscf' 改为 calculation='bands'，仍使用 pw.x 重新计算”，不自动改值或重试。
- 第 2 阶段同时支持 `nscf` 与 `bands`；阶段目录和完整网格含义不变，`bands.x` 不作为波函数生成器。
- 支持原生密度／平滑 FFT 参数；核对已完成 SCF、NSCF 和进入粗网格所需 PH 响应的实际 FFT 兼容性，不一致时停止并列出来源，不改写旧响应。

## 验收标准

- 简写网格能生成完整实际输入；非法整数、维度冲突、非零 SCF 位移及点数乘积溢出在计算前拒绝。
- Rust 与官方脚本至少对照 1×1×1、2×3×6、6×6×6、4×4×2 和含 7 分之一的网格，坐标、顺序、权重及打印精度一致。
- 真实执行路径的受控测试覆盖输入 36／输出 36 通过、输出 40 或 35 失败、相同点数但缺点或重复点失败；失败后不调用 Wannier／EPW。
- SCF 不可约点数 16、NSCF 完整点数 36 不作为数量冲突；比较的是 NSCF 输入与输出。
- `bands` 模式保留相同完整点表并执行同一验收；不会调用 `bands.x` 替代 `pw.x`。
- SCF 216×128×60、NSCF 216×125×60 的不匹配明确拒绝，信息列出两份 XML 和三个维度；匹配场景通过。
- 完成相关回归和文档同步后，才报告源码实现完成；真实计算与安装另记证据。
