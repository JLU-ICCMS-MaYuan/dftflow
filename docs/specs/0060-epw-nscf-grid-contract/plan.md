## 基线与范围

用户已明确“开始执行落地”。本次落实 0060 的 FR-001～011、SC-001～007；依赖工作树中的 0059 原生配置，保留并隔离其未提交改动。外部 SiP₂ PH 导入、实际计算和安装均不在本次范围。

## 职责与数据来源

- 原生配置解析 NSCF 的三个正整数，检查乘积可用 QE 整数表达；验证 SCF 维度相同、零位移，允许 nscf 或 bands。
- qf-input 现有均匀网格函数的带权重输出采用 kmesh.pl 的遍历和打印；生产不调用 Perl。Rust 科学计数法补足指数符号和两位指数。
- NSCF 校验器读取实际 nscf.in、SCF 不可变快照 XML 与 NSCF 输出 XML。输入声明数、行数、输出 nks、ks_energies 数量必须相等；输入逐点符合生成结果，输出保持顺序、均匀性、唯一性和归一化权重。
- 坐标在 crystal 中比较，周期等价差容差 1e-8（官方八位小数最大舍入误差 5e-9）；均匀网格距离容差为 1e-8 且小于网格间距四分之一，拒绝非有限及重复点。权重按总和归一化，容许 QE 总权重为 2；逐点相对容差 1e-6，拒绝不等权重。
- XML 单独读取实际 fft_grid(nr1/nr2/nr3)、fft_smooth(nr1/nr2/nr3)；注意 XML 属性与 SYSTEM 中 nr1s/nr2s/nr3s 名称不同。配置仅接受各自完整正整数三元组。未设置由 QE 决定，完成后仍核对 SCF 与 NSCF，不静默传递。
- 新计算完成、编号阶段复用和版本 2 QE 清单交付均进入相同校验；PH 响应仍由绑定 SCF 几何、来源身份与尺寸验证。失败不发布完成回执或启动下游。
