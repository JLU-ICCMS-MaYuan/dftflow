## 本轮实施补充

公共字段在已有调用映射展开后、原生输入段展开前回填；适用性复用现有参数白名单，阶段显式值优先。物种数组和四类网格只在此边界规范化；内部算法、生成器和科学参数仍使用原有字段。保留外部来源和数组表达的内存记录供错误定位与序列化，均不参与科学身份；修改阶段值后作为明确覆盖保留。

`scientific_key` 对参数对象递归排序再序列化，防止公共回填改变表内插入顺序而改变标识。当前编号工作区仍比较现行解析后的实际参数并核验原生文件，不修改已有记录。配置格式调整不调用数据复制、核验或计算入口。

验证覆盖公共字段分发／独立覆盖、原生卡片与数组往返、未知／非法／混写拒绝、全部阶段参数及科学键等价、实际 MgB₂ 改写前后比较和公开 CLI 隔离检查。已有运行现场不迁移；只更新当前输入，发布通过验证的固定模块命令。
