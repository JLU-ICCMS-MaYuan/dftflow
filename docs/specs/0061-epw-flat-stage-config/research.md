# 0061 研究与取舍

旧实现的实际调用边界已分离，问题在外部 TOML 暴露了内部调用、程序和输入段结构。采用边界适配，保持内部职责，避免逐个重写科学算法。

原生输入段的参数白名单作为归属事实来源，平层参数在程序对应的输入段中查找。若同次调用出现无法唯一识别的参数，明确拒绝，不能凭最后一次写入覆盖。不同程序同名参数通过用户已确认的独立配置段区分。

科学配置保持 `schema_version=2`，但按本轮需求只接受平层表达。内部阶段视图不是第二种可公开读取的配置格式；不提供旧多层输入的兼容入口或迁移工具。现有冻结计算现场保持原样，本轮不据此请求重算。

自动绑定规则必须有有限目标列表和代码来源，不能把任意缺失参数视为自动生成。需要动态生成的 Tc 初值和恢复温度子集仍由已核验请求提供。工作流可编辑设置移至顶层 workflow，内部登记表不进入用户 TOML。

并行 0060 的 NSCF 网格与实际输入证据改动留在工作树；本轮提交只包含自身增量，提交前审计缓存差异。
