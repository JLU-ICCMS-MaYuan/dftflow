- FR-004：用户可编辑的工作流设置独立于科学参数；自动选窗、来源、PH 模式、调度和搜索能力保留。
- FR-005：生成输入、配置快照、指纹、恢复和参数映射使用同一有效配置；用户诊断和来源记录指向实际平层配置位置。

### 追加功能需求

- **FR-011**：顶层 `[baseparams]` 支持 `ATOMIC_SPECIES`、`prefix`、`ecutwfc`、`ecutrho`、`Emin`、`Emax`、`DeltaE`；仅向消费对应字段的原生调用提供公共值，不成为任意参数的全局继承表。
- **FR-012**：`ATOMIC_SPECIES` 支持形如 `[["Mg", 24.305, "mg_pbe_v1.4.UPF"], ["B", 10.811, "b_pbe_v1.4.uspp.F.UPF"]]` 的二维数组。每行严格为元素字符串、有限正数质量、非空赝势文件字符串；保留物种顺序及显式质量，仍满足结构与赝势绑定的既有约束。
- **FR-013**：`ecutwfc/ecutrho` 保持 Ry，`Emin/Emax/DeltaE` 保持 QE DOS／PROJWFC 的 eV 语义；不改作绘图范围、Wannier 能窗或 postw90 参数别名。公共参数配置不改变原生数值校验和跨阶段一致性要求。
- **FR-014**：对应 PH／EPW 调用支持 `nq = [2, 2, 1]`；对应 matdyn DOS／EPW 调用支持 `nk = [8, 8, 4]`；EPW 细网格支持 `nkf = [4, 4, 2]`、`nqf = [2, 2, 1]`。示例值只说明格式，不要求所有阶段采用同一网格。

- **FR-016**：四类网格数组各恰有三个正整数，按原生方向顺序展开；错误长度、零、负数、非整数及数组与对应带方向编号字段混写必须报错并定位字段。NSCF `K_POINTS`、SCF 卡片和高对称路径保持既有契约，不将所有网格统称或改名为 `nk`。
- **FR-017**：公共参数与数组简写解析后沿用同一内部有效配置；相同有效科学设置的原生输入、阶段科学身份及复用判断一致，不因表达变化自动重算。不改写历史冻结配置或已有科学结果。
