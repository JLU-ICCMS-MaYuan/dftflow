# 端点路径与电子比较契约

- 用户输入：继续使用 `kpath` 指定的 `kx ky kz label` 端点对，兼容 VASPKIT 文件头。无中间插值点要求。
- 文件头：允许任意标题的完整四行结构“标题／正整数／Line-Mode／Reciprocal”，大小写不敏感的模式与坐标制关键字；忽略空白与 `#` 注释后识别结构。文件头以外每条记录均按端点严格校验，不静默跳过正文错误，错误位置保留原始物理行号。不改写来源文件。
- 实际 `wdata`：`begin/end kpoint_path` 之间每条真实边一行 `label x y z label x y z`；保留真实标签、分数坐标和断段。`bands_num_points` 继续使用用户原生设置，不静默改密度。取消旧的固定为 1 的配置约束；按真实倒格矢检查短段舍入为零个间隔的情况并提前拒绝。
- 新原生路径读取：使用 `*_band.kpt`、`*_band.dat`、`*_band.labelinfo.dat` 核验点数、端点、分段及每段均匀原生坐标。`band.eig` 仅保存实际路径能量；`sampling.json` 描述相同路径，`band-origin.json` 记录路径类型和原始文件身份。
- 旧人工路径读取：没有新的高对称端点路径登记时，按旧目标完整覆盖契约读取已有结果；来源与数据核查保留，不因缺少新输出重拟合。
- 比较：双方曲线使用各自原生样本和同一真实倒空间距离。仅相同坐标、路径位置和连续段的点参与差值；无同坐标不算。不显示共同点覆盖率，不补能量或缩放横轴。
- DOS：继续由同一已完成模型的 postw90 输出，与既有 QE 均匀网格 DOS 比较。没有逐点网格插值本征值时，不编造电子网格最大差值。
- 第 6 步：Sources 可选增加带哈希的第 5 步电子比较表、DOS 表、统计及 sampling 来源；有此来源时直接复用，电子不再绑定声子取点。旧 Sources 无新增项时仍执行原有严格全点检查。结果 metadata 显式登记独立电子采样，旧包保持原验证语义。
- 错误：原生输出截断、缺端点、路径外点、非有限数、哈希变化、非法标签和超出原生容量时停止。不同点数本身不是错误。
- 失败任务归档：将原活动记录字节不变地保存为同一历史目录的 `native-active-retired.json`，另写 `native-archive-binding.json` 记录旧目录到 `calculation/` 的映射及原记录哈希。原 `native-jobs` 历史不删除，不改变失败结论或科学回执。
- 遗留接续：仅对显式恢复的第 5 步已退出失败任务处理悬空输入；要求阶段已经进入另一代失败尝试，且唯一一份归档完整匹配原任务绑定的输入、脚本、版本对应的日志及外部来源。未知／活动任务、同代进度、证据缺失、损坏、符号链接或多重匹配拒绝；不通用跳过 `Identity` 校验。
- 准备与完成分开：恢复可以生成新输入、独立电子保存树及 `prepared` 原生任务；没有作业号和预留即未提交，未生成完成回执即未完成拟合。真实目录验证不得以修改回执哈希或伪造调度成功代替。
