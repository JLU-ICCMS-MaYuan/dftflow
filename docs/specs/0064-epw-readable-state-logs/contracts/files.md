# 0064 文件契约

- `epw-state/` 恰好八份阶段日志，目录例外仅 `imports/`。声子日志使用实际模式名。
- `.log` 为 UTF-8 中文纯文本：标题、分隔线、工作区、当前状态、任务与进度、问题、下一步；键值采用中文冒号，任务使用具名小节。值中的换行转为单行可读说明，不能破坏记录边界。
- 日志只记录当前子任务，不保留旧批次执行历史。字段缺失明确为未记录，未知提交不得被读成未提交；无法解析的完整记录报出具体日志和字段。
- `<阶段目录>/<阶段名>.jobs` 为带表头的纯文本，列为子任务和 Slurm 作业号；不填写虚构任务号，不累积旧批次作业。
- 阶段日志缺失而 `.jobs` 仍有任务号时，先查询实际调度状态；运行中或查询失败均保留任务号和现场，确认终态后撤下孤立记录，再按当前输入准备。不以日志消失推断任务已退出。
- `<配置同目录>/0000-config.toml` 起递增，至少四位；不覆盖已存在版本，原文保持。用户实际输入名不强制更换。
- 不新增 `continue.log`、JSON 工作流状态、历史归档或固定展开配置。科学程序的原生日志和结果包数据格式不受此契约改名。
- 正常重算清空本阶段可替换内容，保留阶段目录 inode 和当前打开的 Slurm 日志。退出旧布局只操作固定程序状态路径，绝不跟随链接删除外部资料。
