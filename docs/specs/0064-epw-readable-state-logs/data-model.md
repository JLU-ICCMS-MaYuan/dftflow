# 0064 当前状态数据模型

## 阶段

八个阶段分别对应唯一 `.log`。记录布局、声子模式、源配置／编号配置路径、当前批次、阶段状态、失败原因、下一步和命名子任务。批次用于区分本次重算与尚存的下游结果，不是请求指纹。

## 子任务

以可读任务名和实际计算目录区分。保存当前状态、配置版本、批次、脚本／科学日志路径、提交预算关联、退出码和科学检查结论。Slurm 作业号从所属阶段 `.jobs` 查询。输出存在与任务结束不能自行成为科学完成。

## 配置

编号 TOML 位于解析后的 `work_dir/epw-state/`，完整保留输入字节，与最大编号版本不同才新增；A/A/B/A 对应三份快照。阶段记录指向实际用于本次生成输入的版本；恢复使用该版本核对相关阶段参数，再读取现用科学结果。读取编号配置不生成展开后的配置副本。

第 1 步日志保存 `配置快照 · NNNN-config.toml` 小节，包含 `原始目录`（绝对路径）和 `原文 SHA-256`。这是原文字节快照的解析上下文，必须跨 SCF 重算保留；加载时先校验记录与原文，再按原始目录解析相对结构、赝势、程序、工作区及预算路径。它不是阶段科学完成凭据。不存在、损坏或来源冲突不得自行猜测目录。

第 1 步日志整体丢失时，只有唯一版本与显式原输入的字节一致，且其他阶段仍明确绑定该版本和同一原输入路径、所有现存任务已终态，才恢复该版来源记录；多版本历史或局部损坏仍拒绝猜测。`--work` 指向旧非编号现场时沿用其固定绑定，不读取未参与该查询的外部输入。

旧输入旁编号版本按工作区归属迁入，编号和字节不变。阶段及子任务的配置字段只更新位置，不改变批次、科学检查或参数。目标发布与引用转换完成后才移除旧文件；运行中或无法确认的旧任务阻断迁移，以免其脚本继续读取已经撤下的位置。

## 导入与交付

`imports/` 只保留外部来源、转换和必要映射。实际 PH／电子／EPC 数据从编号计算目录取得；清单类型允许在内存使用。`results/` 的自包含数据和图参属于交付格式，不能作为调度任务和续算状态的替代存储。
