## 技术上下文与边界

使用现有 Rust 2021、anyhow、serde、toml、libc 和 Rust／公开进程回归。生产数据和日志仍由原 QE／EPW 解析器核验；首轮受控回归不提交真实科学作业、不切换安装。2026-10-28 用户另行明确授权全仓库编译发布及指定 MgB₂ 工作区清除、真实重算，见 T015～T018。已有无关修改按任务开始快照隔离提交。

## 组件职责

1. `foundation/readable_state.rs`：唯一工作流状态存储。固定八个日志，中文分区和字段；子任务按名称独立更新。任务号另存各阶段 `.jobs`。文件写入使用同目录临时文件原子替换；合并更新锁定稳定的 `epw-state/` 目录 inode，持锁后重读，避免原子替换日志使锁失效，不建立永久锁文件或目录。
2. 配置版本：公开入口读取原文后，比较最新编号快照，相同不写，变化以排他创建生成下一编号；原文路径与编号版本写阶段日志，内部加载旧版不额外备份。
3. 阶段状态：使用配置版本、当前批次、子任务名及直接科学结果重建当前状态；请求指纹只允许在一次调用内比较，不持久保存。旧 `Completion` 等数据结构若仍被解析器需要，只在内存中从实际目录构造。
4. 原生任务：日志只保存执行所需的当前任务信息、退出／验证结论及路径，`.jobs` 是 Slurm 任务号来源。删除三份任务对象副本、失败归档和源文件 hash 的前置阻断。提交前先记录提交中，回执未知保持未知；终态以 Slurm 和科学输出分别判定。
5. 阶段分配：第 3／4 步脚本直接引用编号原文配置和阶段，不引用 attempts 快照。分配内继续调用同一科学执行组件；第 5～8 步仍提交原生程序。
6. 科学数据：PH／粗／细数据从其编号目录重新解析，生成内存对象供下游。比较声子的 Γ onsite／Hermitian q2r 与 matdyn 计算放在第 4 步 `comparison/`，与该阶段默认 simple ASR 数值分开；相关子任务归第 4 步日志，电子模型变化不重复声子后处理。导入来源和必要映射保留 imports；移除共享清单读写和 post 缓存。结果包清单保持自包含交付用途，不承担调度／续算状态。
7. 续算：PH、q2r、matdyn、电子各子任务、比较、展宽及方法／温度在所属日志独立表示；已通过科学检查的子项可复用。明确重算仅清空本阶段可替换内容并撤下受影响下游状态，保留阶段根目录。
8. 旧状态退出：先查询旧当前任务的调度状态，再提取可用的配置／阶段／导入信息；不要求已归档的输入在线。退出代码只处理固定程序状态路径，不能删除 imports 或现用科学数据；运行中／未知任务明确列出。
