## 目标与范围

删除 EPW `[resources]`，统一采用已有 `[slurm].header` 原生文件头字符串及 launcher 启动方式。范围包括配置、各新生成脚本、sbatch 调用、并行和恢复检查、作业登记、测试、活动示例及使用文档；现有 QE／VASP 等接口保持已有结构。具体验收为 Spec 的 SC-001～006。
