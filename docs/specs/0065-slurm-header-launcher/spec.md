## 需求结论

全仓库统一复用 `[slurm].header` 字符串。删除 EPW `[resources]` 外部配置和内部同名资源模型；MPI 调用仅使用配置的 launcher，Slurm 资源申请仅使用 header，不从 launcher 反推生成资源指令。Slurm 正确指令前缀为 `#SBATCH`。

## 用户场景与验收

- **US1**：用户直接提供完整 Slurm 文件头；提交脚本保留用户指令且不新增分区、节点、任务数覆盖。
- **US2**：用户仅在 launcher 指定启动参数；运行命令不被资源配置或恢复逻辑悄悄改写。
- **US3**：所有 flow 使用一致约定；Ubuntu 示例、公共模板和使用文档一致，历史计算现场保持不变。

## 功能需求

- **FR-001**：EPW 接入现有 `[slurm].header`；删除 `[resources]`，旧输入明确报错并说明迁移方式，不静默忽略。
- **FR-002**：全部新生成的 DFTFlow Slurm 脚本采用用户 header；不自动补写或覆盖 partition、nodes、ntasks 等资源申请，不通过 sbatch 参数再次覆盖。
- **FR-003**：MPI 启动 argv 以 launcher 为唯一来源；内部只在原生算法确实需要时读取可识别的进程数，不再与 resources 对照；不将 Slurm 分配任务数强制等同实际启动数。
- **FR-004**：保留作业身份、活动／未知作业防重复、真实调度状态和消费记录；节点消费使用实际 Slurm 证据，不虚构 resources 替代值。
- **FR-005**：审计 QE、VASP、Wannier、SC、替位及共享执行组件，沿用现有入口语法，不强制把其他模块的启动命令格式改为 EPW 格式。
- **FR-006**：迁移活动示例和测试夹具；更新根说明、受影响 Overview；历史验收、冻结输入和已生成脚本不批量改写。

- **FR-007**：每次成功构建直接覆盖固定命令，不创建编译版本记录、版本安装目录或入口备份。构建缓存不是另一套公开入口。

## 补充需求结论与验收

本次用户明确认可接口并授权实施；范围为 EPW 三阶段程序及清理入口使用的配置、执行组件和活动示例，不重写其他 flow 的配置格式。独立 Wannier 路径仅在实际调用时配置；EPW 内嵌 Wannier90 不新增外部程序依赖。

- **US4**：用户在一个 `[programs]` 内看见全部外部依赖及各自 argv，程序不再依赖可执行文件同目录布局。
- **US5**：用户可为每个程序独立设置参数；空列表不附加参数，其他程序的参数不继承。
- **FR-008**：公开配置采用 `pw_x`／`pw_args`、`ph_x`／`ph_args`、`epw_x`／`epw_args` 及 bands、dos、projwfc、q2r、matdyn、postw90、可选独立 wannier90／pw2wannier90 的同类字段。不接受旧 `[programs.xx]`，报错说明迁移方式。
- **FR-009**：所有实际调用程序均从自己的显式路径读取；不得通过 pw／ph 所在目录或 PATH 推导缺失路径。可选程序缺路径时，在消费边界返回具名配置错误；有非空 args 却无对应路径时拒绝。
- **FR-010**：各程序 argv 仅使用对应 `*_args`，空列表或未填 args 表示不附加额外参数；不自动注入 `-pd` 或继承其他程序的参数。launcher 和程序必需的输入／种子接口保留，空 args 不代表取消 MPI；原生程序的并行限制仍适用。
- **FR-011**：EPW 全部阶段禁用多 image；未填 image 或显式单 image 可用，多 image 的 `-ni`／`-nimage`／`-nimages` 别名在配置验证及执行预检拒绝。PH 的 image 参数不受 EPW 限制影响。
- **FR-012**：迁移活动示例与测试，覆盖独立目录、独立参数、空参数、公开脚本和共享 qeflow 声子链；历史科学文件、冻结输入及已生成脚本不批量修改。新配置需要用户显式迁移旧程序字段，不承诺旧工作区透明续算。
- **SC-007**：新配置可往返序列化且只含平铺程序字段；旧子表、未知字段、参数类型错误与无路径非空参数均明确拒绝。
- **SC-008**：实际生成和执行的脚本使用分别位于不同目录的后处理程序，准确传递各自 argv；空列表不出现自动 `-pd` 或空占位参数，修改 pw／ph 路径不影响后处理程序定位。
- **SC-009**：EPW 全阶段对多 image 拒绝、对单 image 允许；PH image 参数保留；合法 pool 别名、原有 launcher／Slurm header 契约不变。
- **SC-010**：合理回归、配置检查和重新编译通过；固定命令覆盖安装且不创建版本入口；提交仅包含本次任务修改，不包含已有目录整理和科学实现变更。
