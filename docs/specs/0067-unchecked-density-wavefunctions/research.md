# 调查与设计取舍

原先 save::files 同时承担哈希目录清单与复制文件列表，直接删除清单条目会漏复制。现分离 all_files（实际复制）和 files（只对受保护文件计算身份），避免给原始数据制造占位哈希或伪造核验值。只含原始数据的目录允许没有核验记录；所需 XML 的检查由对应科学边界承担。

旧快照、Identity、产物列表和清单在内存中排除两类条目，不改写历史文件，不按大小／mtime 增加替代核验。新清单不登记原始数据核验值。其余文件仍执行原检查，通用路径合法性独立保留。

VASP 的 CHGCAR 体积场后处理属于实际科学读取，并非本次要取消的重复核验；审计未发现同类重复哈希门，不修改其算法。qeflow 声子初始化原有原始数据非空／存在门已移除。目录迁移明确不在本次范围。
