## 用户场景与需求

- US1：复用 SCF／NSCF 时，无需为了电荷密度和波函数反复读大文件。
- US2：复制到下游时照常传递实际数据，但不做复制前后内容／尺寸／集合对照。
- US3：历史快照、收据或清单里有旧哈希，也不能继续触发被取消的核对。

- FR-001：集中识别 QE 电荷密度及原始波函数文件，含 dat／hdf5 和 prefix.wfcN 形式；不误跳过 XML、UPF、日志、PDOS 或 EPW 矩阵元。
- FR-002：这些文件不计算哈希，不比大小、非空、存在性和文件集合，不参与复用、完成或恢复的完整性判断。
- FR-003：分离复制遍历与核验清单，实际复制仍包含两类数据，不因不核验而漏复制。真实复制 I/O 或科学程序读取错误照常报告。
- FR-004：旧记录只在内存中忽略相关条目，不手改历史科学文件、清单或状态，不因旧哈希保留而回退到严格模式。
- FR-005：EPW 全部相关入口及共享 QE 前置检查遵循同一规则。其他模块无此核对的维持原实现，原生计算读取数据不算核验。
- FR-006：保留结构／赝势／程序／原生输入、XML、日志、收敛、声子响应和其他产物检查。
- FR-007：目录保持现状，运行数据不跟踪；更新现行文档、需求及验收，关联前序 0065／0066。
- FR-008：测试后重编译覆盖固定 CLI，不保留编译版本或旧命令备份，不新增真实科学计算。
