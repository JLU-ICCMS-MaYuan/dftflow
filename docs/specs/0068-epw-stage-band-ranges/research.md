# 技术调查与决策

1. 现有 qf-wannier::select_energy_only 在 k 点计数超限时提前报错，不能直接作为诊断数据源。提取边界推导为共用函数，严格调用方仍检查 frozen≤N≤outer。诊断调用方仅展示计数，不裁剪。
2. SCF 的带数／占据态不必包含未占据态，也不必达到 num_wann；不能要求完成一次严格 Wannier 选择才能画 SCF 图。
3. 现有前四步 -s 使用阶段分配，作业内 native_workspace::allocated 顺序推进。SCF／NSCF 当前被 refresh_stage 排除；纳入后即可在同一分配中即时画图，不增加作业。electronic 需在路径 PW 后插入，避免等待 DOS／PDOS。
4. 图片不进入科学完成身份；使用独立可校验图参、CSV 和阶段派生发布。窗口更改仅重绘，不触发 SCF／NSCF 重算。
5. 自动窗口由本阶段数据推导只用于预览。组合投影冻结不等于能量冻结数量，图注必须写明 energy-frozen。无法推导边界用 null 和原因，不替换为虚假有限数。
6. 当前 origin 是上游 wannier90；既有 0067 明确本地暂定编号／线上用户管理。因此准备本地 Issue 正文，远程发布不在本次写入范围。
7. 参考图保留宽布局与范围条，不机械复制红色窗口；沿用共享主题的红色费米线及其他颜色。
