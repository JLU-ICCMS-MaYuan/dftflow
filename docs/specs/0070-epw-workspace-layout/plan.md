# 实施计划

用户已确认当前汇总版并明确授权实施。只落地 FR-001～040，不新增科学任务、自动重试、导航或报告。

## 组件职责与顺序

1. `qe_data/save` 与 `layout` 统一正式 SCF 位置及最小基态输入准备；正式数据保持原生完整树，核验继续排除密度／波函数。
2. 统一相对软链接建立及验证，保持来源归属和目标不可变。DOS／PDOS 指向正式 NSCF，投影附加结果归集第 3 步。PH 归集完成才清理其明确工作 out；q2r 使用正式矩阵文件列表。
3. Wannier 同目录后处理；粗网格链接 Wannier 配套和 PH 路径；比较只保留最小数据；细网格单参数直接用阶段根、共享粗模型，原生分片与重启信息保留。
4. 原生多温度与显式线性化求解保留，删除自适应 Tc 搜索器和双初值／交叉核验入口；源数据链接到正式位置。
5. `native_jobs/process/attempt` 的退出证据写阶段日志；新运行不产生 exitcode。旧标记仅读取兼容，不能作为新输出继续扩散。
6. `stage_results/combined_plot/delivery` 将图片与必要绘图数据直接写 results，不复制原生数据、不新增 index／manifest。绘图失败独立登记并报错；普通重入不自动重画，显式绘图才重试。
7. 文档按审计逐项集中，删除目录专属设计，保留非目录科学约束和历史实测事实。归并内容只在本目录保存，不在旧位置留下替代跳转链接。
