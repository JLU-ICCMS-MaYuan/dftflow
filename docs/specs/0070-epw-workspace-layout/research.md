# 实施研究与取舍

- 单份正式数据不等于共享可写 out。NSCF／PH／EPW 可能改写其工作输入；只读模型用相对链接，必要可写输入按实际原生格式准备。
- SCF 原生 out 自身作为正式来源，不能再完整复制 snapshot。小型验证证据继续使用已有阶段日志；不能增加原始密度或波函数的存在／大小／集合检查。
- q2r 原生显式文件列表可消除 dyn_q 与 dyn 编号命名导致的复制；Γ 首项及 XML 模式须验证。
- postw90 需要同一种子名的输入与模型；DOS 参数变更与拟合输入的科学身份分开，不通过再复制 chk/mmn 实现隔离。
- results 旧发布框架以自包含包和索引为核心，与新要求冲突；新编号工作区直接发布请求图及必要图参／数据，旧图包只读兼容不成为新默认。
- 图失败必须与科学状态分开。失败标记写已有阶段日志；重入不因 pending 自动重画，显式绘图请求可以重试。
- 配置编号快照继续保留；不以删除日志或放宽源身份规则让旧数据误判为可复用。
- 本机原生读取支持须由源码及最小执行验证；不能以合成夹具代替科学数值验收。

- PH 与 NSCF／路径能带必须区分：PH 的线性响应需要 SCF 波函数，使用可写的临时完整保存树，成功交接后删除；NSCF／路径能带只准备必要基态输入并重新生成电子态。原生替身直接读取 PH 的波函数验证交接，不把原始波函数加入核验记录。
