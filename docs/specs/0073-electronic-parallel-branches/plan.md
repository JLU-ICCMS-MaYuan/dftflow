# 实施计划

复用现有八日志、配置快照、原生任务执行与 Slurm 提交解析；增加仅用于第 3 步的分支调度模块。

1. 准备阶段核验直接 NSCF 输入，固定配置版本和阶段批次，生成两个独立脚本。
2. 两分支依次调用 sbatch 取得回执，不等待科学执行；收尾使用 afterany 依赖，以便失败也能记录原因。
3. 分支进程持本分支目录锁，状态更新复用 epw-state 目录锁；不持全工作区锁等待科学计算。
4. 能带只写 qe_eband；DOS 与投影只写 qe_eledos。收尾确认原生产物后走既有阶段核验和绘图。
5. 活动作业和未知提交禁止覆盖；恢复复用各子任务原生检查点，只补失败或不相容任务。
6. 已有分配内不额外提交，保持 12 MPI 资源约定；其他阶段不变。
